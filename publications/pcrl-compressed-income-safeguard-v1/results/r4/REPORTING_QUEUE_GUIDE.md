# Metadata planner and freeze order

The private R4 helper `r4/build_reporting_specs.py` prepares configs and queue specs. It hashes JSON and code text only; numerical pins come from admitted manifests and completed worker receipts. ROOT owns enqueue, shared locks, reporting truth admission, and execution. The helper does not change scientific code.

Forty-two trajectory V2 specs have been generated. They carry actual two-seed training checkpoint pins, admitted source geometry pins, full FIT feature/task pins, manifest, original SCIENCE_LOCK, corrected scheduler, and amendment D. The original V1 metadata templates are preserved. Use only `GENERATED_TRAJECTORY_V2.json`. Each trajectory forwards full FIT in canonical batches of 1024 before slicing fold2. The units depend on their actual completed source-seed training jobs. Public output is under `r4/trajectory_v2`; private probabilities are under `trajectory_v2`.

After all required trajectory and reader jobs finish, run the helper with `--phase nomination`. It creates `CIS_NOMINATION_V2` with 32 four-arm checkpoint records and the two unchanged RAW_HYBRID starts. The actual nomination worker writes only `r4/NOMINATION_RESULT.json`. ROOT reviews the deterministic frozen rule, includes the result in `NOMINATION_LOCK.json`, commits that shared lock, and uses `--phase packages` to emit `r4/FINAL_PACKAGE_INDEX_V2.json`. This private index carries the 18 selected service/seed packages, checkpoint and geometry pins, all ATT/FIT2/INNER release and score pins, model pins, and trajectory pins for independent workers.

Independent refit targets and their frozen attempts must be complete before the new INNER assessment. The 54 target identities remain registered even for literal aliases. The independent verifier uses its own arithmetic.

ROOT's public REPORTING_LOCK must have `status: ALL_READERS_FROZEN`, `owner: ROOT`, true `candidates_frozen` and `readers_frozen`, `reader_freeze_sha256` containing the exact complete bank list, `endpoint_registries.compressed_income_safeguard.sha256` for the K240 registry, and `role_label_sha256.INNER_SELECTION` with income, occupation, and sex hashes. Bind the nomination lock, independent target/refit freezes, source and geometry/checkpoint identities, code pins, original science lock and amendment D as additional provenance. Commit exact reporting-lock bytes at HEAD before any queue admission that hashes truth.

The private seal JSON supplied through `--seal` contains the committed canonical reporting lock's `path` and `sha256`, `reader_freezes` as exact `{path,sha256}` records matching the public list, and `roles.INNER_SELECTION` copied from ROOT's safe `INNER_TRUTH_SOURCE_INDEX.json`. No label byte needs to be opened to construct that metadata. The inherited SEX custody entry in the public lock is `inherited_label_custody.sex`, with its hash and repository-relative path `.private/task_conditioned_representation/r5/reporting_label_custody/INNER_SELECTION_SEX.npz`; income and occupation use their inherited exact role export paths. Keep absolute source paths only in private metadata.

After committing the seal, run the helper with `--phase report --seal PRIVATE_SEAL_JSON`. It generates `CIS_INNER_REPORT_V1` for all18 packages and registers every label supplement, feature/reference pin, frozen release/score pin, reader receipt, code pin, and registry. ROOT enqueues and runs this one INNER report. It writes safe aggregates under `assessment` and private endpoint inputs under `reporting/RUNNER_INNER_REPORT_V1`.

Then run `--phase inference --seal PRIVATE_SEAL_JSON`. The helper consumes the completed private report input index, retains the same registry and committed seal, and registers every input table. ROOT runs `CIS_INNER_INFERENCE_V1` to produce all240 endpoints under the shared paired duplicate-group bootstrap. The independent final replay, deployment, custody, and claims use those same frozen definitions.

All generated units explicitly bind amendment D and corrected scheduler text. No helper generated spec is automatically enqueued. Preserve failed and superseded metadata and units. Never regenerate nomination from INNER outcomes.
