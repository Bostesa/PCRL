# PCRL incumbent and complete-view study

This is the public file export of the completed exploratory study at local execution commit `320c07c81beba3a82ad4d1f9fe0adc490f65c043`. It is published on a separate branch from already-public GitHub main. The unpublished local execution ancestry is not uploaded. Original reports and locks are copied byte-for-byte. Their local-only statements describe the execution closeout; this export adds publication provenance.

## Result

Exact P0 preserved useful predictions at the point estimates. All eight arms passed all 24 original point utility clauses against both U0 and Ucal. Simultaneous confidence preservation remains unresolved: 80 utility clauses passed, 112 were unresolved and none demonstrated a violation.

The best new point result was sequential 2→1: coalition SEX AUC **0.800789**, versus P0 **0.803141**, a **0.002351** reduction below the required **0.020**. Complete-view joint was **0.001073 worse** than that sequential control. No competitive method, objective-package, joint-design or randomness advantage was established.

Six native roles completed 14 policy fits and 40 fresh attack instances covering 120 complete views. Independent replay matched all 948 endpoint slots. Twelve selected readers were independently refitted in a disclosed post-outcome diagnostic. Raw83 deployment and versioned snapshot-only wire and representative-reader checks passed.
