# Attacker access: what each source says versus what its code gives

Adversary and methodology reviewer, PCRL mechanism-design campaign, 2026-10-16. Read-only review of papers, code and
published aggregates. "MISMATCH" marks a place where the paper and the code disagree; "UNVERIFIED" marks a statement I
could not check. Code lines are `file:line` at the commit named in each block.

**Terminology hazard.** "Defense-aware" has three meanings across these sources:
- AAAI Tier 2: a Gaussian LRT that knows the noise law and clean auxiliary representations (QDA for deterministic defenses).
- The combined study: the cell-conditional attacker (`oar/study.py:180`).
- The TCR1 service: a feature transform (`task_conditioned_representation/attacks.py:114, 168`).

The ACS code never uses the term; there, every reader is simply refit to the defended releases. Define the term once, or
avoid it.
