# Fresh complete-view attack contract

Status: design and data-free implementation pending R0's sealed attack-stage admission. This document fixes the intended readers and accounting before any new attacker fit. It does not assert that a protected policy is utility eligible.

## What a reader sees

The service is an output release. A recipient receives one global ten-bit public code, its fixed W_TSTAR decoded task probability vector, and the first-tie argmax decision. Recipient 1 is income (two classes); recipient 2 is occupation (six classes). The pair reader receives the aligned union of both recipient wires. The public bank table, routing and policy descriptions, and deployed weights are public side information. An attacker may use them to compute deterministic functions of an observed code. It does not receive a person's private teacher scores, source/fine bank tokens, local action index, original permitted raw predictors, protected SEX, sampler coin, stream key, or unsent mean probability. R1 will pin the precise deployed metadata; any transmitted flag, version, length, fallback, branch indicator or policy ID is added to every affected local and pair view before a fit. A constant public field is recorded in the wire schema even when it has no person-varying column.

R2's private integer code arrays are only custody format. R4 reconstructs the exact emitted little-endian ten-bit code and replays its probability and decision from the frozen table. Any unexpected code, byte-different probability, decision discrepancy, wrong table/source/role, changed ordered row/group ID, or extra/omitted wire field blocks the unit **before ATT SEX is opened**. Row IDs and duplicate-group IDs align people but are not attacker features. Duplicate people sharing a group must receive the same cached wire for a given role/seed/arm/realization. Every arm uses the same fixed decoder and public-state ceiling; no private input-local action number is an output code.

One cached release per person and recipient is the threat contract. For stochastic T/P/L/J/S12/S21, register realization IDs 0, 1, 2 and fixed source stream commitments before fitting. Fit and score each realization separately. They are dependent repeated evaluations on the same people, not extra people or a repeated-query service. D and B0 are deterministic and need one realization. The two recipient coins are independent for P/L as R2 declares; R4 never reads coins. Pair joins require one shared role/seed/arm/realization identity and identical row/group order. Do not concatenate draws or attack an averaged probability that was not sent.

## Fresh readers and label roles

Use `results.pcrl_latent_and_sampled_methods_v1.r02.protocol.run_three_view_attack` and its inherited shared evaluator. `ATTACK_FIT_NEW` has 4,064 rows/4,061 groups; a fixed label-free group split gives 3,046 train groups and 1,015 tune groups. All models, reader selection and orientation use this role only. `INNER_SELECTION` has 2,235 rows/2,234 groups and is opened for SEX only after all three reader banks, tuning choices, predictions and custody receipts are frozen. No other task or sensitive label is needed by the attack worker.

Each recipient and pair view has the same eight fixed fresh readers: `LR_C1`, `MLP_64x32`, `HGB_15x200`, `DA_MLP_64x32`, `CELL_A1`, `CODE_BIT_LR_C1`, `PROB_LR_C1`, and `PROB_HGB_15x200`. The complete numeric matrix includes the emitted code bits, ATT-vocabulary categorical global code ID with unknown-Inner indicator, all probability coordinates and the decision. The probability specialists use only transmitted task probabilities. Public derived features include log probabilities and pair bit products. `DA_MLP_64x32` consumes the complete view plus these public derived columns. The smoothed categorical cell reader keys the local global code or ordered pair of global codes. The coalition additionally transports every fitted recipient reader as a **zero-fit ignore-the-other-recipient** option. A numeric ordinal ID by itself is never the sole code reader.

The old `Q_POST_LR_C1` specialist uses a uniform grid of **fine score centroids** as channel inputs. This campaign conditions its policy on **bank codes**; that inherited specialist is therefore not an exact source-compatible alias and is **not in the fixed 30-fit slate**. The policy and bank tables remain public, and the fixed defense-aware MLP receives code, probability, decision, log probability and pair interactions. A prospective exact public-law specialist would require its own sealed implementation, budget and separate identity before ATT labels; no empirical FIT/ATT/INNER input-code frequency or per-person private input may be inserted silently. If absent, disclose the narrower defense-aware attack capability.

Two real V2 engineering probes run per view: group-shuffled ATT labels evaluated against independently group-shuffled INNER labels, and an isolated planted leak. The constant reader is checked at AUC 0.5. A failed null or planted probe makes that arm's recovery evidence incomplete. All fitted models, ATT-tune/INNER predictions, view matrices and control arrays remain owner-only private. Public receipts contain aggregate AUCs, reader/control status and hashes only. R5 independently replays representative fitted readers and numerical endpoints without importing R4 scoring/view code.

The public recovery number is the preregistered finite reader envelope on INNER with orientations fixed by ATT tune, plus every reader and the validation winner. The envelope is a strong attacker capability, not a way to choose a method or realization. The pair envelope includes transported local readers. Report each seed and realization, then an equal-weight dependent summary under R0/R3's sealed simultaneous interval family. At a cap, PASS requires the proper bound beyond the inclusive threshold; a crossing bound is UNRESOLVED. Point improvement alone is exploratory.

## Admission and resource units

Each distinct eligible arm/seed/realization is one queue-controlled compound attack unit: 3 views × (6 core + 2 probability) = 24 reader fits, plus 3 × 2 V2 probes = 6, total **30 fresh fits**. Transported local pair readers cost zero new fits. B0 is mandatory even if every protected arm fails its original point utility gate. All point-eligible fixed protected arms enter; noneligible arms have no new SEX attack. Compatible P* and W_Q references require fresh fits unless exact release, row, view, reader, realization and source hashes prove an alias. Exact identity checkpoints may alias B0 only if their actual transmitted wire and attack contract match; a shared score or similar prediction is insufficient.

At most six stochastic arms × two source seeds × three cached draws = 36 release instances, plus D × two seeds and B0 × two seeds = 40. Thus the pre-eligibility ceiling is **1,200** reader/control fits. A two-seed distinct W_Q or P* reference adds 60 fits each, for a **1,320-fit** ceiling across all ten registered arms. These are ceilings, not a promise to fit ineligible arms. The previous conservative role-sized anchor of 2,660 CPU seconds for 384 reader/control fits gives 6.927 CPU seconds/fit: 1,200 fits forecast 8,312.5 CPU seconds (2.31 CPU-hours), and 1,320 fits forecast 9,143.75 CPU seconds (2.54 CPU-hours), before inference. Twofold stress on all ten arms would take 5.08 CPU-hours. A closer score-release source completed a synthetic 33-fit unit in 10.521 charged CPU seconds and several real 33-fit references in about 8–10 seconds each; those observations suggest considerably lower actual cost but are not a guarantee for this bank. R0 must update reservations from the first role-sized smoke and respect the **12 aggregate CPU-hour campaign ceiling** and at most two machine-wide heavy processes. Numerical BLAS/OpenMP thread counts are one. An incomplete unit remains incomplete; no reduced reader slate is silently treated as the same comparison.

Queue spec identity must bind: campaign/stage lock hash, worker and transitive reader code SHAs, role manifest, bank table and source binding, policy/action-map hash, arm/source seed/realization/stream commitment, ATT and INNER release package hashes, reader slate, attacker seed, private output destination and public receipt path. Every worker verifies the active queue stage and pinned bytes before a role label read. R0 records stage amendments before affected reruns, preserving failed outputs.
