# R1 bank and deployment specification

The primary source is frozen `W_TSTAR` for source seeds 0 and 1. It is the inherited stronger useful task-only compression reference and was chosen before any new channel fit. `W_Q` remains a historical reference. The provider receives the ordered 83 permitted preprocessed predictors for one person, runs the admitted frozen U encoder and both task heads privately, routes each task score through its frozen FINE-TASK fine partition, and obtains the existing bank's global token ID. For a protected arm, its selected policy may replace that ID with one of its admitted same-class W_TSTAR output IDs. The H-GLOBAL-TEMP decoder table is fixed throughout.

Purpose 0 is binary income; purpose 1 is six-class `occupation_group`. Each seed's public bank has 16 income IDs and 321 occupation IDs, all unique probability/decision vectors. IDs are 0-based global table indices and include the predicted class. Ten little-endian bits encode each ID; neither a class tag nor an input-local action number is transmitted. A recipient gets only its `code` (`uint8[n,10]`), `prob` (`float64[n,K]`) and `decision` (`int64[n]`). Probability and decision are deterministic functions of the emitted code and the frozen public table. The aligned coalition gets both recipient wires and the public tables/policy. Fixed arm/seed/source hashes are public metadata. The provider's raw predictors, latent, teacher scores, fine cells, original bank token, hidden action slots and sampling coins stay private. The adapter has no fallback flag or hidden extra output state.

`B0` is the exact identity checkpoint: for every input, emit the original global W_TSTAR token and its table-decoded task output. The data-free `verify_identity_pair` checks both complete recipient wires, including code bits, probabilities, decisions, dtype and keys. For protected policies, the provider may read both private scores and fine cells if the arm contract permits it; local and product arms must honor their narrower R2 sampler contracts. The runtime never reads SEX or a true task label. The selected arm's `sample_public_pair` returns global public IDs. R1's output adapter rejects out-of-bank IDs and tables with duplicate output vectors, so each emitted code has exactly one public meaning.

The old assessment and new HEAD_VALIDATION labels remain closed. R1's static admission read model/policy/decoder hashes and public tables only. Before an Adult fit, R0 must seal source roles, action support, training, sampling, evaluation and compute. R1's later raw deployment replay may use role-only permitted `X` without labels. Common INNER utility remains the original accuracy, NLL and summed multiclass Brier caps against both U0 and Ucal; B0-relative fitting tolerances are R2's prospective optimization proxy and do not replace these external caps.

Source loader: `code_witness.bank_deploy.load_bank_service` verifies frozen U model/heads, policy fingerprint, embedded decoder digest, public table bytes and ordered schema. R1's static admission distinguishes the decoder's file SHA from its embedded content SHA. The previous independent seed-one 32-row raw replay matched saved W_TSTAR code, probability and decision exactly. Both-seed current-campaign raw identity replay remains a separate queued verification unit.

The ten-bit bank is an output release with private teacher computation. It does not provide a purpose-feature service or a general privacy guarantee. All comparisons with P* concern a compatible score/output contract with different bank states and historical SEX-trained routing; P* cannot be treated as an action alias of W_TSTAR.
