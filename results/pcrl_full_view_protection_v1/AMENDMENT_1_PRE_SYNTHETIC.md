# Amendment 1 — control selectors fixed before suite outcomes

2026-09-22, before running the registered synthetic suite. This amendment fills in control level/selector details omitted by the first protocol commit `63f288382`; it changes no budget, target or fixture.

For each fixture and budget, enumerate all `2^|T|` deterministic binary maps and choose the feasible one with the lowest nominal Hamming cost, breaking ties by lexicographic output vector. Use the same exhaustive map with lowest *unconstrained* cost as the randomized-response and withholding base. Include a constant best-action channel. Randomized response flips that base output with probabilities `1/4`, `1/2`, `3/4`; withholding replaces the base token by the nominal best constant action with probabilities `1/4`, `1/2`, `3/4`. Among each family, select the feasible member with the lowest nominal cost, then the smallest mixing probability; print every member whether selected or not. `max` over all listed laws and both full views is the feasibility statistic. No coarse-only or nominal-only channel that violates this statistic is a same-target winner. The unprotected deterministic optimum and zero-budget channel are printed separately.

For each optimized positive-budget channel, print objective primal cost and a Lagrangian supporting-hyperplane lower bound with a `1e-7` numerical guard; if the gap exceeds `1e-5`, do not describe it as tight or optimal. Zero-budget equality problems use an affine dual lower bound. `I(Y;Z|H_A)` is an additional exact finite-law information metric. A CLARABEL status is never a substitute for the lower bound. If the solver fails after one numerical retry, quarantine that cell and count it, without changing the budget or fixture.
