# Guarantee card

| Item | Exact scope |
|---|---|
| Protected targets | Marginal SEX and RAC1P separately in the intended ACS interface; finite fixtures use binary S. No joint-attribute guarantee. |
| Authorized task | Residence Y; finite fixtures use a declared binary task. |
| Existing side information | Local `H_A`: all four unrounded frozen service probabilities. Coalition `H_AB=(H_A,H_B)`: all six. The finite fixtures use full discrete H states. Other external side information is covered only by the all-input radius bound when the Markov premise holds. |
| New release | One sampled categorical Z from fixed public Q(.|T), with independent private randomness. T and Q row are not transmitted. A persistent token is returned on repeated requests for the same person. Independent redraws, multi-token composition and adaptive future releases are outside the attribute-specific guarantee. |
| Distribution | Exact finite-law CMI holds only for the specified known law. Robust CMI holds if the true entire joint law is one of the explicitly listed laws in U. The nine-law prior sensitivity is exploratory. No ACS true-law membership claim exists. |
| Training | Encoder, action decoder and Q treated as fixed. This is a release information bound, not training-data privacy or a guarantee against model inversion through parameters. Original T0 used residence supervision. |
| Exact mathematical statement | For each law P in U and declared role, independent re-evaluation verifies `I_P(S;Z|H_r)<=δ` within `1e-7` numerical tolerance. The full-view statement uses the actual finite H state, not B. |
| Distribution-free control | For any fixed Q and any view W satisfying `(S,Y,W)->T->Z`, `I(S;Z|W)` and `I(Y;Z|W)` are at most `R(Q)`. A listed reference r supplies the explicit upper bound `max_t KL(Q_t||r)` over all allowed T rows. For public-state Q, a separate bound is required in each state already in W. |
| Continuous H bridge | Conditional theorem: if `TV(P(S,T|h),P0(S,T|h))<=ε` at every h, actual CMI is bounded by a per-h reference ceiling plus `f_|S|(ε)+f_|Z|(ε)+f_|S||Z|(ε)`. No verified ACS ε or uniform coverage proof is available. |
| Confidence | None for ACS. Household dependence, survey weights, fitted T, sparse class/H support and mechanism selection would enter a separate coverage proof. The finite list is not a statistical confidence set. |
| Actual 2018/2016 evidence | 2018 Q/D17 radius upper bounds are aggregate diagnostics of unchanged channels. 2016 is read-only prior evidence; no mechanism fitting or new scoring on 2016 occurred. The historical `CE_J−CE_M<=+.001` empirical comparison is not a CMI guarantee. |
| Numerics | Small finite convex fits have independent primal feasibility checks and supporting-hyperplane lower bounds, with a stated `1e-7` floating guard. These are numerical, not formal interval-arithmetic certificates. Wide objective brackets remain flagged. |

The guarantee is useful only if its stated law/envelope assumption holds. On the current ACS evidence the strongest unconditional all-view bound comes from radius, which is 1.762–1.968 nats for archived Q and 2.639–2.773 for D17, much larger than the `.01` illustrative target. The finite selective results cannot be exported as a continuous-H ACS population certificate.
