# D (baseline fairness) — early flags

- **LAFTR-hard-R² full outputs exist on the drive only** (`wt-PCRL-superpowers-laftr-hard-r2-2026-05-17.tar::.../results/laftr_hard_r2_{adult,hmda,diabetes}_LAFTR_HARD_R2/per_seed_results.json`). Recount: strict R²<0.05 = Adult 0/24, HMDA 17/18, Diabetes 18/18 = **35/60**; adj 18/60; clean 0/60. Adult is scored at Cotter-fallback epochs 11/15/17 of 200 (the same early-epoch fallback that gave PCRL R4 Adult 0/24 on best.pt vs 20/24 on final.pt); no final.pt eval stored. "LAFTR-hard" is PCRL's stack plus an adversary, i.e. the only R²-trained comparator, but not LAFTR.
- **No baseline in the submitted tables was trained against R² ≤ 0.05.** INLP stops on val LR accuracy within 1pp of majority; LAFTR on adversarial CE; SPLINCE/LEACE are closed form. Both INLP and LAFTR *train* their encoders while PCRL's backbone is frozen random.
- **SPLINCE is applied on top of PCRL, per single attribute.** The R5/R7 code has no separate LEACE buffer (added in 940912cb9 after R7), so "pre-LEACE features" = PCRL's trained final.pt h_p. Each SPLINCE cell erases only the audited attribute.
- **By-product for check A:** SPLINCE `pre_health` is the health of PCRL final.pt h_p → single-checkpoint final.pt clean count **6/60** (paper 7/60 mixes final R² with best.pt health; best.pt-only 5/60).
- **LEACE-on-raw "0/20" linear leg is numerically fragile:** stored R² reproduced exactly from drive tensors, but 18/20 failures sit in directions with relative singular value 1e-7..1e-4; with a 1e-3 cutoff 20/20 pass and held-out LR is exactly at majority on 20/20. Robust failure is nonlinear (Δ≥2pp on 17/20). App. P's "reduces task accuracy to majority on all three datasets" is contradicted by the stored per_task JSON (above majority on 8/9 tasks).
- **INLP stored R² come from a float32 solve:** float64 recompute from drive reps gives 42/60 (vs 43/60), max |Δ| 0.030.
- **LAFTR HMDA/Diabetes (36/60 rows of Table 13) are unreproducible:** values joined from an S3 FINAL_BENCHMARK.csv in the 7-day-lifecycle bucket; no per-seed file in any ref or the drive.
- **Utility not "comparable":** INLP 0.815 vs PCRL 0.779 (best.pt) on the same 27 cells; INLP > PCRL by >1pp in 14/27.
- **"R-LACE" is INLP-style**, on a trained backbone; one-shot official LEACE there gets R² 0.004–0.009 on 8/8 Adult pairs with ≤3.3pp task drop (but MLP Δ 0.09–0.46).
- **In-house `LEACEEraser` (pcrl/models/baselines.py) is not LEACE** (orthogonal OLS-null projection; fixture leaves R² 0.58–0.65). Used only by legacy pre-v2 scripts; v2 and durable-guarantees use concept_erasure.
