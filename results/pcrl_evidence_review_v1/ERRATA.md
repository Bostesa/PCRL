## Not corrected, and why

* **The F1 pass itself.** The registered rule is reproduced exactly and stands. E4 does not retract it; it removes an interval reading the rule never made.
* **The disclosure that no directional prediction was registered.** This is already stated correctly in `RESEARCH_DECISION.md` and should be kept verbatim. Prespecified contrasts, endpoint families and decision rules still fix the multiplicity, the estimand and the stopping point before the outcome; a run without a called shot is not thereby exploratory.
* **The numerical-recovery disclosure.** The write race (amendment 1) and the load-dependent prediction corruption (amendment 2) are reported honestly, with the originals preserved. This audit adds only that memory pressure is the *observed condition*, not a demonstrated cause, which the study already says.
