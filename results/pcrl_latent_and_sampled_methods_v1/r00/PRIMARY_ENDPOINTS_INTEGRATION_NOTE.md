# Primary endpoint table integration

`PRIMARY_ENDPOINTS.csv` has 7,676 unique public rows: 665 D rows from R19's independently sourced proposal, 72 fixed-A absolute task/reference rows, 54 fixed-A absolute r1/r2/pair AUC rows, and all 6,885 prospectively registered A signed clauses. A's 1,161 estimable clause rows retain their numerical bounds with status `BOUND_ONLY`; 5,724 missing fitted-arm rows retain blank numerical fields and `INCOMPLETE_MISSING_ARM`. No A full conjunction or protected-policy comparison is inferred from fixed-only rows.

The public-only builder `r00/build_primary_endpoints.py` pins the five source hashes, requires R04's independent fixed endpoint PASS and counts, then joins public aggregates without private person arrays. A absolute task rows use candidate-minus-U0/Ucal signs: accuracy delta is larger-is-better; NLL/Brier excess is smaller-is-better. The A signed K6,885 clauses use `first-minus-second` for their named utility or AUC contrast. Absolute AUC intervals are not computed; the registered signed intervals are separate rows. D's 567 signed contrasts retain their previously sealed conventions and independent replay.

The fixed A point gate in this integration is descriptive: each seed, task and both reference comparisons require accuracy delta ≥ −0.010, NLL excess ≤ 0.010 and Brier excess ≤ 0.005. It does not grant an inherited reference a new method claim or turn point feasibility into a simultaneous PASS. P* meets those point caps in both seeds; class-only does not. The full A K6,885 family is incomplete because no fitted protected policy was selected.
