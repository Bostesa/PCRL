## D: feature-code service

The provider runs the pinned 83-column input through the matching frozen purpose encoder, FIT-only affine scaler, ten-bit hard mapper, code-only head and one fixed H-GLOBAL-TEMP calibrator. Recipient 1 receives its income ten-bit vector, calibrated two-class probability vector, argmax-first decision and fixed public source/model/head/calibrator metadata. Recipient 2 receives the analogous occupation code, six-class probabilities and decision. Bit zero is least significant; the integer code ID used in attacks is deterministically derived as the sum of bit `j` times `2^j`. It is not a separately transmitted field. The coalition sees the aligned union of both wires. Each recipient needs only its own permitted predictors at runtime. SEX, task truth and teacher scores are fitting inputs only.

Public code, scaler, encoder, head and calibration parameters are available to defense-aware readers. A reader can derive the categorical ID, every bit, probability and decision from the wire. It does not receive private raw predictors, source latents, soft bits, original teacher scores, decoder residuals or a fallback. All task outputs must be reproducible solely from the transmitted hard bits and fixed public parameters. Nonfinite input and schema mismatch cause an error; they do not route to a second public channel. Fixed metadata has no person-varying state; any added variable field needs a pre-release amendment and complete-view attack update.

The unchanged-latent F diagnostic has a different actual wire: each recipient receives its 16-dimensional scaled frozen latent, its retrained head's calibrated probability and decision, plus fixed metadata. F is attacked as that full continuous view. U0 and Ucal anchors are attacked on their actual transmitted score/decision contracts. Their capacities differ from the ten-bit D arms and comparisons are identified accordingly.

## A: sampled score service

The central provider uses both pinned frozen score vectors and a private fine-cell lookup to sample a *joint* pair of public output codes. It may use both scores; matched central A controls have the same scope. Recipient `r` receives its globally canonical code ID, its fixed bank probability vector and decision, one common release ID and exactly the registered fixed public metadata. The coalition gets both aligned recipient wires. The source fine cell, local action position, unsampled mean vector, clean score, private coin, person key and cache digest are never transmitted. Public bank, action maps, gate weights and code tables are defense-aware side information.

One joint categorical sample is cached by a stable private person key and service version; repeat recipient calls return projections of the same pair. A changed input digest under that key errors. The three offline realizations are separate one-release worlds, never three simultaneous observations for one attacker. Offline draws use a sealed private stream; production uses an internal CSPRNG and durable cache. The sampled vector actually delivered is scored for utility and privacy; its average is not substituted for the release. A newly versioned release may sample again, so repeated-version aggregation is outside this fixed contract.

The A stage amendment must bind exact canonical bank hashes, realized metadata dictionary, stream-root hash, action maps and duplicate-unit cache identity before any A fit or release. A score-only result does not establish feature-sharing protection. D and A are reported in separate service tracks.
