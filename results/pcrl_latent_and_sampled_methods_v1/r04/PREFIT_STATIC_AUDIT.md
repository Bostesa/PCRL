## Mathematical and release contract before fit

For D-K, the biased empirical MMD includes diagonal terms. It is computed on **hard bits** for each recipient, and on aligned hard-bit pairs with a **product** recipient kernel. Fixed multiscale bandwidths and the relative local/pair weights must be sealed. An XOR fixture has identical individual SEX-conditional bit laws and a distinct pair law; the pair MMD is positive. MMD is a fitting surrogate with no AUC bound. The task heads must receive hard-forward straight-through bits during training and only hard bits in deployment. A ten-bit code has at most 1,024 states per recipient; each additional variable class tag, flag, scale, fallback, or length is extra capacity. Every transmitted probability and decision must be reproduced from the code and fixed public parameters alone.

For A, the actual transmitted code ID is global to the fixed public output probability/decision, never an input-local action index. Action probabilities must be merged over identical public identities. Expected NLL and Brier are weighted **losses of sampled bank outputs**, not losses of the weighted mean probability vector. The three prescribed draws are three complete single-release realizations, not three independent people. A cached response and private coins define the evaluated service; a fresh draw per query would be a different contract. The exact joint-law compiler into both sampling orders is an equivalence check, not evidence of joint novelty.

The independent finite arithmetic implementation is in `independent_arithmetic.py`. Its tests cover the XOR pair kernel, biased MMD diagonal convention, sampled expected-cost discrepancy, duplicate public-action aggregation, and tie-correct AUC. They do not import candidate or runner code. They await R03 queued execution after R00 seal, as the campaign requires for numerical tests.

The now-proposed D-K kernel is the equal mixture `0.25 * sum(exp(-gamma * Hamming))` for gamma `0.25, 0.5, 1, 2`, with the coalition kernel equal to the product of the two local mixtures. The three biased hard-code MMD-squared values have equal weight before multiplication by one frozen protection coefficient. R04's XOR fixture tests this exact four-scale law.
