The inherited D-C preprocessing currently divides each centered coordinate by `max(std, 1e-6)` (`teams/d/prototype.py:42–65`). When `std<1`, this amplifies that coordinate; a tiny `std` can produce a very large factor. The new prompt calls for **non-amplifying** scaling shared across comparable arms. D-C needs a prospectively corrected common transform or an explicit incomparable-preprocessing label before it is treated as a matched optional arm. Its inherited shared VQ codebook/centroid-decoder interface is also structurally different from D-K's sigmoid-bit mapper. D-C does **not** satisfy mandatory ordinary adversarial C coverage. This classification follows the implementation, not its prior name.

No D claim follows from 10 bits alone. There are at most 1,024 local code states and at most 1,048,576 code pairs; occupied state counts, entropy, singleton mass, and utility reveal the effective behavior. Extra per-person tags, flags, independently appended teacher classes, or fallbacks enlarge the wire alphabet. An invertible transform before the hard code has no information-removal effect by itself. Under a fixed wire with only code-determined head outputs and constant metadata, the code and the full view generate the same information for an ideal observer; row-varying metadata invalidates that equivalence. Fresh readers still attack the full wire, including code identity and pair cells.

## Exact D-K premise and its limits

Let `C_r∈{0,1}^10` be the transmitted hard bits and `S∈{0,1}` the sensitive label on fitting rows. For view `V∈{C_1,C_2,(C_1,C_2)}`, let `I_s` be the indices with `S=s`, `n_s=|I_s|`, and `k` a fixed positive semidefinite kernel. The **biased empirical squared MMD** is

`MMD_b² = n_0^-2 Σ_{i,j∈I_0} k(V_i,V_j) + n_1^-2 Σ_{i,j∈I_1} k(V_i,V_j) − 2(n_0 n_1)^-1 Σ_{i∈I_0,j∈I_1} k(V_i,V_j)`.

It equals the squared norm of the difference between the two empirical kernel mean embeddings, hence is nonnegative. Self-pairs cause positive null expectation at finite sample size. This is the relevant *biased* estimator, rather than the unbiased U-statistic used for some two-sample tests in [Gretton et al.](https://jmlr.org/papers/v13/gretton12a.html) and [MMD-B-Fair](https://proceedings.mlr.press/v206/deka23a/deka23a.pdf). The latter optimizes test **power**, accounting for test variance, whereas D-K's fixed-kernel raw empirical MMD is a simpler surrogate. It must not be described as reproducing MMD-B-Fair's algorithm or significance test.

For the prompt's fixed positive multiscale Gaussian kernels on bounded binary vectors, a local kernel can be written `k_r(c,c')=Σ_b w_b exp(-||c-c'||²/(2σ_b²))`, with sealed positive bandwidths and nonnegative weights of positive total mass. The coalition kernel `k_12((c_1,c_2),(c'_1,c'_2))=k_1(c_1,c'_1)k_2(c_2,c'_2)` sees aligned joint configurations. On these finite code domains, strictly positive-definite Gaussian kernels (and their product) distinguish probability laws: population MMD zero would mean equality of the corresponding two group-conditional code laws. If `S` is binary and both groups have positive probability, equality of the **pair** law would imply independence of `S` and the pair and Bayes AUC 0.5 from this wire. A small **fitted, minibatch, or held-out empirical** MMD gives none of those population or finite-reader AUC guarantees. Finite bandwidth, finite samples, optimization error, coding metadata, and attacker side information remain material. A fixed kernel also cannot bound the performance of arbitrary readers from a reported scalar MMD without additional assumptions.

The training definition `c_ST=p+stop_gradient(1[p≥0.5]−p)` has hard transmitted values in the forward pass and gradients as if the discontinuous threshold were identity. Task and MMD values must be computed on those hard forward codes. The straight-through gradient is a heuristic direction, **not** the derivative of the hard-code population objective; numerical loss decrease does not alone establish changed hard assignments. Report actual code changes and fresh hard-code attacks. The task-only zero-privacy path should exactly match a same-seed continuation, because otherwise a D-K versus T difference is confounded by training implementation.

### Exact complementary-clue witness

Let `U,V` be independent fair bits, release `C_1=U`, `C_2=V`, and let `S=U⊕V`. Each conditional local law is Bernoulli(1/2), so both local population MMD terms are **zero** and each local Bayes AUC is 0.5. The pair laws are `P_0={(0,0),(1,1)}` and `P_1={(0,1),(1,0)}`, each with probability 1/2 per listed point, so the pair reveals `S` perfectly (AUC 1). For one-bit kernel factors with diagonal value 1 and cross-bit value `ρ_r<1`, direct expansion gives

`MMD_pair² = (1−ρ_1)(1−ρ_2) > 0`.

For a multiscale one-bit Gaussian, `ρ_r=Σ_b w_b exp(-1/(2σ_b²))` when weights sum to one. With independent bit-flip noise `N∼Bernoulli(ε)` and `S=U⊕V⊕N`, local MMD remains zero, while pair `MMD²=(1−2ε)²(1−ρ_1)(1−ρ_2)` and Bayes AUC is `1−ε` for `0≤ε≤1/2`. This is an analytical oracle for the **aligned product-kernel** diagnostic. If pair records are independently shuffled across recipients, the diagnostic loses the witness; preserving person alignment is a mathematical prerequisite.

## Exact A premise and its limits

Let `X` denote the provider-private pair of frozen score vectors and derived summaries, `Z=(Z_1,Z_2)` a pair of **global public** bank identities, and `q_θ(z\mid x)` the central gate law after duplicate action outputs are aggregated. For observed task labels `y_{ir}` and fixed decoded bank vector `p_{r,z_r}`, the fitted expected losses are exactly

`L_NLL,r = n^-1 Σ_i Σ_z q_θ(z\mid x_i)[−log p_{r,z_r}(y_{ir})]`,

`L_Brier,r = n^-1 Σ_i Σ_z q_θ(z\mid x_i) Σ_k(p_{r,z_r,k}−1[k=y_{ir}])²`.

The sums may be streamed over each person's at-most-16 actions. They use observed labels and exact fixed public vectors, and must be compared with the unchanged mean caps against both frozen references on the same role. They are **expected costs of one sampled output**, not realized costs for every draw and not losses of an average probability vector. For any person's random bank vector `P`, Jensen gives `E[−log P_y]≥−log E[P_y]`, and the Brier identity is `E||P−e_y||²=||E[P]−e_y||²+Σ_k Var(P_k)`. Replacing the expectation of loss with loss of expectation can therefore falsely certify utility. An admitted identity action witnesses an unprotected feasible point only if that identity's comparable-role losses meet the caps.

For any locked finite-law privacy score, first compute `P̂_s(z)=n_s^-1 Σ_{i:S_i=s}q_θ(z\mid x_i)` over **actual public output identities** for each local and pair view. If the selected score is empirical mutual information, its precise finite-law form is `Î(S;Z)=Σ_s π̂_s Σ_z P̂_s(z) log[P̂_s(z)/Σ_t π̂_t P̂_t(z)]`, with `0 log 0=0`; a Bayes-accuracy/TV objective has a different formula and guarantee. The objective family and local guards must be sealed before fits. In either case, an input-local action index or source-specific bank ID cannot serve as `z`: it creates or conceals a different disclosure channel. Globally deduplicate identical public probability/decision entries and aggregate coincident joint actions. An extra per-person flag or source identifier must be modeled as part of `Z` if emitted. A fitted finite law is not a population law; parameterized gates and alternating optimization can be nonconvex and supply only the reported numerical/heuristic scope.

The central provider's two-score access is an **input advantage** relative to the inherited local `Q_r(z_r|t_r)` channels. Matched central product and sequential design controls should get the same two-score information; local controls answer a narrower architectural question. Any fixed joint kernel factors in either sampling order: `q(z_1,z_2|x)=q(z_1|x)q(z_2|z_1,x)` and symmetrically in reverse, with a fixed convention on zero-mass prefixes. Exact compiler/replay in each order should reproduce the same joint output law and utility/privacy values. Those compiled policies are aliases of the fitted release. S12/S21 become scientific controls only when the **first policy is learned and frozen before the second design**, with the second fitted using the actual fixed first-release contract. Thus a favorable A result can concern design/training order, not greater expressive power of joint sampling.

Each realized A release is one cached sample per person under the prompt's service contract, including duplicate groups and aligned recipients. Three precommitted complete realizations report mechanism variation; they are not extra independent people and must not be selected by best draw. The primary recovery assessment must use the actual sampled code/full view, not `E[P]`. A decision-only code is a privacy floor for a decision-preserving channel, but may fail NLL/Brier utility; a toy law need not improve below an already zero-leakage floor. Unlimited fresh resampling is outside this claim.

## Prior-art boundary and official-source compatibility

| Primary source | What it establishes here | Boundary for this portfolio |
|---|---|---|
| [Gretton et al. 2012](https://jmlr.org/papers/v13/gretton12a.html) | MMD as an RKHS distribution discrepancy and two-sample statistic; characteristic kernels and biased/unbiased estimates. | A D-K training penalty alone is not a tested significance or privacy certificate. |
| [Deka and Sutherland 2023, MMD-B-Fair](https://proceedings.mlr.press/v206/deka23a.html) and [official code](https://github.com/namratadeka/mmd-b-fair) | Non-adversarial kernel fair representations using test-power objectives, with target preservation. | Its learned-kernel/power formulation and representation setting are not identical to frozen-latent, two-recipient hard-code D-K. A faithful run would need compatible input/output/utility and capacity treatment; otherwise cite as close method, not a renamed implementation. |
| [Gitiaux and Rangwala 2022, SoFaiR](https://www.ijcai.org/proceedings/2022/97) and [author code](https://github.com/Gitiauxx/SoFaiR) | Rate-distortion framing and deterministic multi-resolution fair quantization. | Supports quantization antecedence, not this fixed 10-bit pair-MMD solver or a matched Adult control without adaptation. |
| [Chen et al. 2025, PASS](https://proceedings.mlr.press/v267/chen25h.html) | Stochastic data substitution trained from an information-theoretic objective; paper highlights limitations of ordinary adversarial training. | A score-bank gate is an adaptation, not PASS itself. Do not label a generic stochastic score channel a faithful PASS baseline. The PMLR page gives the paper; no verified official PASS code was identified in this bounded check. |
| [Cai, Zhang and Khalili 2024](https://proceedings.mlr.press/v244/cai24a.html) | Randomized finite quantization optimized through linear programming under an unbiasedness and differential-privacy formulation. | A's score-bank mean NLL/Brier and empirical SEX-recovery formulation is different. This is a quantization antecedent, not a DP guarantee or a directly compatible baseline. |
| [Taylor, Vippathalla and Coon 2026 v2](https://arxiv.org/abs/2601.21859v2) | Adaptive sequential releases under collusion with privacy measured by mutual information; expected-distortion formulation has a global optimization result in their finite known-law setting, while mutual-information utility is nonconvex/local. | A's freeze-first learned neural channels and D's local deployment maps are not their online known-law algorithm. No Taylor optimality transfers to fitted score-bank NLL/Brier constraints or an AUC endpoint. |
| [Bertran et al. 2019](https://proceedings.mlr.press/v97/bertran19a.html) and [author code linked by PMLR](https://github.com/MartinBertran/AIOI) | Earlier adversarial information obfuscation using stochastic transformations while retaining utility. | An ordinary adversarial hard-code C is established-method coverage, not a new D-C identity. Its image-oriented implementation is not a drop-in ten-bit frozen-latent control. |

The new D and A studies can report a useful empirical tradeoff or a tested interaction under matched controls. They cannot claim kernel fairness, stochastic substitution, quantization, or collusion-aware sequential privacy as new ideas. In particular, the inherited D-C already uses local/pair MMD on hard IDs, and earlier PCRL A already fitted finite stochastic token channels. A future candidate needs complete-view fresh attacks, paired seeds, utility eligibility, strong controls, and held-out confirmation before any stronger statement. Finite-reader AUC, mutual information, demographic parity, and formal privacy guarantees are different endpoints.
