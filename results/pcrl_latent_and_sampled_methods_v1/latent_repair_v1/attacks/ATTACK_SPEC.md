# D complete-view attack handoff

Status: pre-fit adapter and synthetic invariants, 2026-10-09. R00 owns the effective lock and unit registry; R02 owns the shared reader runner and endpoints; R03 owns every numerical slot. No Adult attacker has been fitted by R09.

## Public wire and views

The R07 service emits exactly `code` (`uint8[n,10]` hard bits), code-head `probabilities` (normalized `float64[n,K]` after the fixed held-out temperature), `decision` (argmax-first) and scalar constant `metadata`. Bit column 0 is least significant; the exact categorical ID is `sum_j code[:,j] * 2**j`. It is a deterministic alternate encoding of the ten transmitted bits, with 1,024 possible states per recipient. The adapter refuses a soft bit, latent, teacher vector, decoded latent, residual, hidden routing field or extra top-level wire member. It binds aligned int64 row/group order and literal metadata across ATTACK_FIT_NEW and INNER_SELECTION.

`adapter.prepared_d_views` produces R02 `PreparedViews` for `r1`, `r2` and `pair`. Each includes a category one-hot ID (ATT vocabulary plus explicit unseen cell), all ten bit columns, every emitted probability coordinate, decision and all scalar metadata. The pair has both complete recipient wires in order. Defense-aware readers also get public-only log probabilities and 100 row-major bit products for the pair. The exact ID tuple is the categorical lookup key; integer IDs are never passed as ordinal features. R02's schema receipt binds field order, category vocabulary, column widths, public transforms and role-view hashes. Probability-only specialists consume the *emitted* vector, not a teacher output.

Metadata is arm-constant in this D contract, so it adds no within-arm recovery signal. It is still represented and checked. If a later release adds varying length, fallback, routing or flag, its wire must be amended before a fit and every variable must enter the attack. Pair IDs are packed in int64 for diagnostics; `uint16` would alias e.g. `(0,1)` and `(64,1)`.

## Frozen primary slate and role separation

R00 and R02 fixed eight readers **per complete view**: inherited `LR_C1`, `MLP_64x32`, `HGB_15x200`, `DA_MLP_64x32`, `CELL_A1`, `CODE_BIT_LR_C1`, plus `PROB_LR_C1` and `PROB_HGB_15x200`. The full-view LR, HGB and MLP read ID one-hot, bits, probabilities, decisions and metadata. The DA MLP reads public transforms. `CELL_A1` is a smoothed exact code or pair-code lookup, with unseen-code prior fallback. The bit LR and probability-only readers guard against categorical/bit/probability blind spots. The pair bank includes every frozen local reader transported as an ignore-recipient candidate, with zero additional fits. The winner and its orientation are chosen only on the inherited SHA-ranked group-disjoint `ATTACK_FIT_NEW` train/tune split (historical 3,046/1,015 rows); INNER labels score frozen predictions and never select readers, alpha, architecture, orientation or a defense.

`cell_reader.py` retains alpha 0.5/1/5 direct code readers as an **unrun diagnostic implementation**, including fixed prior fallback for unseen local IDs and mean-of-marginals fallback for unseen pair IDs. These are outside R00's frozen primary slate and must not enter the winner envelope unless a dated pre-fit amendment applies to all comparable arms. The synthetic XOR case verifies that direct pair-code reading can expose complementary clues when each local code is null.

## Engineering controls

R02's V2 runner performs exactly two real-role engineering fits per view: a group-shuffled-label LR null and an explicit planted-leak LR, using the inherited V2 thresholds and role splitting. Six V2 fits per arm-seed are mandatory, private, and never candidate arms. A failed null or positive plant is a technical attack-audit failure, not evidence of low leakage. `control_wires.py` supplies additional group-coherent shuffled/noisy and XOR diagnostic wires for independent checks; its augmented 11th bit is explicitly a control fixture, not a D 10-bit release. It preserves duplicate groups, and the planted category can vary while its original code-only probabilities stay identical. Do not fit these extra fixtures on Adult without R00 registration.
