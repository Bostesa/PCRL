## Primary D-K objective

On an aligned FIT minibatch use the transmitted-forward hard-bit `c_ST` values. Define `H(a,b)=sum_{j=1}^{10}(a_j-b_j)^2`, which equals Hamming distance in forward arithmetic. The fixed multiscale kernel is

`k(a,b)=(1/4) Σ_{γ∈{0.25,0.5,1,2}} exp(-γ H(a,b))`.

The coalition kernel on aligned `(a1,a2)` and `(b1,b2)` is `k(a1,b1) k(a2,b2)`. For each of recipient 1, recipient 2 and pair, calculate the **biased**, nonnegative empirical squared MMD between SEX 0 and SEX 1: within-group means include diagonals, and the cross-group term is subtracted twice. Evaluate pairwise kernels in float64 cast from float32 ST bits so gradients still flow to mapper parameters; clamp a tiny negative roundoff result at zero. No soft-bit MMD is an endpoint. No group-balanced resampling; the same aligned people and fixed batch permutation are used across arms, and each batch must contain both SEX groups. The D-K full loss is `(task_1+task_2)/2 + λ_s (MMD_1²+MMD_2²+MMD_pair²)/3`.

The **one strength** `λ_s` is calibrated once per source seed from the deterministic first valid 256-person internal-fold training batch at selected warm checkpoint `e0`, before any protection update. Compute separate L2 gradient norms on the two mapper parameter sets for the joint task loss (`g_task`) and unweighted mean-three MMD (`g_priv`) and set `λ_s=min(10,max(0.1,0.5*g_task/(g_priv+1e-12)))`; if `g_priv=0`, use 10 and record it. No parameter update occurs in this diagnostic; charge it as FIT compute. Persist the batch row/order hash, both norms, unclipped ratio, cap event and constant coefficient in a pre-continuation receipt. L, S12 and S21 use that same `λ_s` for their relevant terms; no per-arm adjustment. This fixed FIT-only ratio targets privacy gradient magnitude at half the task gradient at the shared start and prevents an uncalibrated MMD scale from making the comparison vacuous. It is a surrogate-strength convention, not a guarantee of utility or AUC.

The hard forward and ST backward are explicit approximations to a discontinuous quantizer. The biased MMD has a finite-batch null baseline and can favor collapse; kernels do not upper-bound recovery, and a fresh hard-code attacker may exploit differences MMD misses. Check a zero-privacy D-K path against T bitwise with identical seed/batches/optimizer, tiny independent enumerated MMD cases, and complementary local clues with strong pair signal before admission. Do not require a synthetic *win* to start the real comparison.

## Complete controls and D-C classification

`T` is the task-only hard-bit mapper/head with the identical warm/refit/continuation and no SEX input in its trainer object. `L` clones the same warm state, has two separate purpose fits and uses each purpose's task term plus its **local** MMD only, scaled to match the D-K per-purpose task/local coefficients: `task_i/2 + λ_s MMD_i²/3`. `S12` first fits recipient 1 by that local objective, freezes its full public hard release, then fits recipient 2 with `task_2/2 + λ_s(MMD_2²+MMD_pair²)/3` against the actual frozen recipient-1 bits on aligned rows. `S21` reverses the order. The first-stage fit may be an exact L-purpose alias only with equality of source, split, initialization, batch order, optimizer, selected epochs and release bytes. Each recipient still receives its own `e_c` continuation updates. The pair objective never uses a floating first-stage proxy.

`C` is a separately implemented ordinary **adversarial hard-code compressor**, using the same warm state, bit mapper, head and `e_c` continuation. It has three SEX critics on the two local 10-bit codes and aligned 20-bit concatenation, each `Linear(d,64)→ReLU→Linear(64,1)`. For each mapper update, take exactly two critic-only Adam `0.001` updates on the same FIT batch, then freeze critics for one mapper/head Adam `0.001` update with joint task loss minus `1.0 ×` arithmetic mean of the three group-balanced binary cross-entropies. Critic initialization/seeds and reset are fixed before fits; report both local and pair training losses. It is a strong applicable ordinary adversarial comparator with an extra critic compute budget disclosed, never called an independent invention. The inherited prior D `trainer.py` is **not C or optional D-C**: it already uses nonadversarial hard-ID frequency/sketched-pair MMD with a 1,024-centroid VQ and a decoded-vector wire. Its objective, architecture and wire differ from this new D-K and from ordinary adversarial C. If separately run, label it a historical VQ variant, not an alias or a mandatory C replacement. There is no D-C candidate in the initial package.

`F` is the unchanged scaled frozen 16-D latent per purpose, with separate serious `16→64 GELU→K` task/distillation heads. For this continuous diagnostic only, train each task head on the same internal FIT task-train fold for 40 epochs; inspect epochs 5, 10, 15, 20, 25, 30, 35, 40 and choose minimum task-specific validation NLL, earliest tie. Reinitialize from its fixed seed and refit each task head on full FIT for that selected `e_F,i` count, then apply H-GLOBAL-TEMP on CAL. Thus F has at least the same maximum task-head optimization opportunity as a 20-epoch warm plus 20-epoch continuation code arm but can select its own task-optimal epoch. Its recipient wire includes its actual 16-D feature and head probability/decision, so it is a continuous feature reference with different capacity. No final LEACE is mandatory. Source U0/Ucal are additional fixed utility and privacy references with their actual historical wires. All comparator and candidate outputs use fresh complete-view attacks and common eligibility tests; an ineligible nearly constant comparator cannot manufacture a lead.
