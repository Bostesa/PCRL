## Observed service

Each recipient receives exactly one seven-key `SCV1-score-release-v1` wire: schema, recipient, global canonical code ID, the sampled code's full float64 probability vector, strict decision, shared paired `release_id`, and the seven fixed public metadata fields in R11's mechanism spec. The attacker receives the actual sampled wire. It never receives a private source fine cell, score, gate input, action position, random coin, HMAC key or unsent mean probability. Public bank, action map, gate weights, fine-cell centroids and algorithms are defense-aware side information. The two-recipient view is an aligned union of the actual two wires.

`PublicBank` refuses duplicate output vectors, noncanonical/signed-zero probability bytes, a non-strict decision, mismatched canonical-bank SHA, and any metadata outside the trusted seven-key registry. The materializer refuses byte-different or non-native-float wire probabilities and any person-varying metadata. Recipient batch duplicates sharing a private `unit` must have the same full cached wire. `CacheIdentity` binds seed, admitted role, realization, paired arm, source binding and verified joint-cache SHA; the pair builder requires identical private cache receipts and equal public release, source and mechanism identities before R02's row/group join. This dataclass comparison does not itself prove the cache artifact's SHA; the release custodian and R04 must independently hash and replay it.

The complete `WireBatch` includes categorical global code identity, explicit code bits, the vector and decision, all literal top-level fields, each metadata field, and an exact canonical JSON metadata category. R02's ATT-only encoder creates one-hot vocabularies with a separate unseen-Inner indicator. Public Q features, if sealed, are added separately to the defense-aware view. Every actual variable wire component remains in the primary complete view. Constant fields are still listed and hashed.

## Public-prototype Q specialist

`q_aware.py` defines an **approximate** defense-aware specialist. It uses a fixed uniform prior over every pair of publicly released fine-cell centroids, not an empirical Adult/FIT prior. At each pair it evaluates the published sparse channel law and aggregates probabilities by actual global output IDs. Local and coalition code lookup tables contain output mass, prototype posterior entropy/support and moments of the public centroid score vectors. This is a deterministic function of public mechanism artifacts and the emitted code; it cannot use an individual's hidden input. A zero-support emitted code blocks this specialist. The table identity binds the public centroid artifact, source, mechanism, two banks, shapes and uniform-prior declaration; its content hash must be sealed before ATT fitting. The full 64×641 grid compilation is heavy preprocessing and requires R03's slot. R04 independently replays the table and release-to-feature mapping.

`Q_POST_LR_C1` fits a C=1 regularized LR on those lookup features using only ATT train groups. It predicts ATT tune and INNER once, saves the private fitted model, exact feature matrices, ordered row/group IDs and predictions, and returns R02's external-reader record. Its function has no INNER SEX argument; R02 opens that label only after all banks and receipts are frozen. The helper rehashes the full table arrays, checks the sealed table SHA and requires R03's actual running A-stage unit ID before ATT label access and before its numerical fit. The outer A runner must still verify that the callback, centroids and table came from the published mechanism and R00's effective A amendment; R04 must independently replay them. The same Q feature and reader construction applies to every compatible protected and matched control arm. If public centroids, pure gate evaluation, bounded grid cost or a prospectively sealed table are unavailable, mark Q_POST inapplicable for the comparison; do not derive a private FIT-frequency table silently.

The prefit A amendment binds the Q compiler and reader source hashes and declares applicability. A fitted policy's exact Q table does not exist at that time. Its later private source receipt and immutable attack queue unit must bind the exact compiled table artifact and content SHA before any ATT label read. This postfit identity is a custody check under the predeclared algorithm, not an opportunity to choose a table after seeing attack outcomes.

`q_artifact.py` stores the compiled public-prototype table as one owner-only, write-once NPZ plus `Q_TABLE_RECEIPT.json`.
