# Sampled confidence channel: prefit design

Status: **R11 design for R00 review; no real-data fit or release admitted**. This is a score-track method on frozen Adult task scores, not a feature-sharing privacy claim. Prior Adult outcomes motivated the design, so every later result is exploratory.

## 1. Source, public bank and action support

For model seeds 0 and 1, the central provider receives the permitted 83-column input, runs the frozen U0 teacher, and obtains income and occupation score vectors `u_1∈Δ²`, `u_2∈Δ⁶`. The inherited qpc partition assigns private fine cells `t_1,t_2` from those **U0** vectors. Ucal is an unchanged utility reference. `fine_to_hcal_token[t_r]` from the fixed hcal T* policy names the **identity** decoded vector in the fixed H-GLOBAL-TEMP bank. No source teacher, partition, decoder, temperature or bank vector is refitted here. The provider may read **both** U0 vectors; the two recipients receive only their respective sampled releases. SEX may supervise the fit, never this runtime.

Canonicalize separately for each `(source seed, recipient)` over the entire decoded T* bank **before protected fitting**. Validate every float64 vector as finite, nonnegative, positive-sum, within the common normalization tolerance and with strict argmax equal to its frozen token class. Normalize signed zero to `+0.0` for the eventual wire; perform no other rounding or near-duplicate merging. Equality is exact little-endian float64 vector bytes **and** decision class. Sort unique `(decision,vector-byte-string)` pairs lexicographically and assign contiguous public IDs `0..Z_r-1`; save old token ID→canonical ID and SHA-256 of canonical ordered table. R01's read-only fixed-bank identity audit found **Z_1=16 and Z_2=321 in both seeds**, with zero exact duplicate old output tokens. Fine inputs number 64 and 641 respectively; many distinct cells share an identity output. Code ID `z` always names the same transmitted vector and decision across all source fine cells; its namespace includes seed and recipient. Exact duplicate source vectors merge globally if encountered in another source revision. Every possible predicted class must retain a canonical bank entry or deployment is blocked; there is no raw-score fallback or post-outcome bank enlargement. R04 independent source decoder replay remains pending.

For each fine cell `t_r`, let `i(t_r)` be its canonical identity code. Define distance between two existing bank vectors as half the sum of both KL directions after flooring every component at `10^-12` and renormalizing **for distance only**. Within `i(t_r)`'s strict predicted class choose the two distinct nonidentity codes with smallest distance, ties by lower canonical ID. The fixed class representative is the existing canonical code minimizing the unweighted sum of these distances to all canonical codes of its class, ties by lower ID. The ordered action list is identity, two neighbors, class representative, with repeated IDs removed at first occurrence. It has 1–4 entries; missing neighbors are omitted. No task/SEX outcome chooses representatives, and no action position is transmitted. This construction and all distances/maps are hash-bound before protected fitting. The actual bank vector is never changed by distance clipping.

For a person, enumerate the Cartesian product of the two action lists, at most 16 pairs. The gate receives `x=[u_1,u_2,H_c(u_1),margin(u_1),H_c(u_2),margin(u_2)]` (12 float64 inputs), with clipped entropy summary `H_c=-Σ_k p_k log(max(p_k,10^-12))` and margin `top1-top2`. One shared affine layer `12→16`, `tanh`, then affine `16→16` produces logits indexed by **fixed** padded action slots `4*a_1+a_2`, `a_r∈{0,1,2,3}`. Mask invalid positions and softmax only over valid pairs; do not compact valid logits to positions `0..N-1` when a recipient has fewer than four actions. The unpadded action order is the preceding fixed order. There are `12×16+16+16×16+16=480` trainable scalar weights/biases per source seed for JOINT-STOCH. Public parameter bytes and action maps are available to defense-aware attackers. There is no dense 16×321 joint bank or independent parameter per rare fine-cell pair. If source admission shows a different task dimension or unsafe gate memory, amend before fit; do not silently resize after outcomes.

Let `q_i(z_1,z_2)` sum all action probabilities on row `i` that result in the **same global public code pair**. Even if action-list dedup makes this sum trivial, every utility/privacy/release path uses that aggregation. `Σ_{z1,z2}q_i=1` is checked after masking/dedup. Recipient marginals are sums of the paired law. This is a genuinely sampled information-changing output: the source fine cells and clean U0 scores are not released.

## 2. Exact fitted-law quantities and optimization scope

Use uniformly weighted OSF_DEFENSE_FIT people under R01's paired-group conventions; declare any weighting difference in R00's lock before fit. For task `r`, expected mean NLL is `n^-1 Σ_i Σ_{z1,z2} q_i(z1,z2)[-log(max(p_{r,z_r}(y_{ir}),10^-12))]`. This is the repaired common NLL clipping convention; it never changes a transmitted bank vector. Expected summed multiclass Brier replaces the bracket with `Σ_k(p_{r,z_r,k}-1[k=y_{ir}])²`. The bank vectors are fixed. The operation is **not** NLL/Brier of `Σ_z q_i p_z`. The two task accuracies are structurally the frozen decisions only if source and every action class validate; report actual sampled accuracy and per-class recall anyway. Enforce NLL excess ≤0.010 nats and Brier excess ≤0.005 against **both** U0 and Ucal on identical FIT people, class order, clipping and weights; algebraically each loss cap is `min(mean U0,mean Ucal)+allowance`. Also apply the inherited accuracy cap, with strict/non-strict and interval rules from R00's common protocol. The identity arm is a utility witness only after its comparable-role measured costs pass.

For a view `v∈{r1,r2,pair}` and binary SEX, aggregate the emitted-code law `P_v(s,o)=n^-1 Σ_i 1[s_i=s] q_i^v(o)`. The **exact finite empirical-law** Bayes SEX accuracy is `G_v=Σ_o max(P_v(0,o),P_v(1,o))`. Minimize `J=G_pair+0.5(G_r1+G_r2)` under the utility caps and hard fitted-law local guards `G_r≤G_r(identity)` for each recipient. The identity law is a privacy-guard reference even when it is utility-ineligible. Decision-only class outputs give structural floors for `G_v`; no constraint asks below a disclosed-decision floor. Exact `G` values are for this fitted finite law and public code identities only. They are not held-out privacy, AUC, a population guarantee or global optimum of the nonconvex 480-parameter problem. Public per-person metadata is constant within `(arm,seed,recipient)` or a registered deterministic function of emitted code, so it adds no state beyond `o`; any additional varying field requires amendment of this law and all attacks before fit.

Optimization uses a prelocked small number of deterministic starts/updates, fixed utility feasibility tolerance, and one matched total CPU ceiling per arm, as R00/R03 bind after synthetic timing. Report every start, fitted utility residual, `G` by view, objective, solver/optimizer status and output checkpoint; a feasible nonconvex local solution is not a global certificate. A protected solution can be point-feasible but interval-unresolved. A fresh attack fit on ATTACK_FIT_NEW and report on INNER_SELECTION is the scientific recovery check, with all transmitted components and public mechanism available to readers.

## 3. Actual wire, cache and three realizations

Each recipient's exact wire is `{schema:'SCV1-score-release-v1', recipient:1|2, code_id:int, probability:[float], decision:int, release_id:str, public_metadata:dict}`. Both recipients share one paired arm `release_id`; `code_id` uses that seed/recipient's global canonical bank and `probability` is its fixed exact vector. `public_metadata` has **exactly** `{model_id,source_binding_sha256,canonical_bank_sha256,mechanism_sha256,code_length_bits,fallback,sampling_contract}`. `model_id==release_id`, `code_length_bits=ceil(log2 Z_r)` for the actual canonical recipient bank, `fallback=false`, and `sampling_contract='cached_one_joint_draw_v1'`. Each value is fixed within `(arm,seed,recipient)` and externally bound in R00's trusted interface registry. The mechanism hash binds gate parameters, action map and canonical bank; source binding comes from R01's admitted receipt. Recipient-specific constants may differ across recipients; no source cell, coarse source token, local action position, unsampled average, clean teacher score, coin, private person key or per-person route is transmitted. Public weights, bank, seed/hash identities and algorithms remain defense-aware side information even when absent from the per-person wire. The coalition sees the aligned union of both complete wires. R14's view builder must reject any unregistered metadata field or mismatch against trusted public constants.

The service issues **one joint categorical sample per stable provider person key and service version**, caches the paired output and input digest durably, and returns that same pair to repeat requests. A mismatched input digest under the same key fails closed. Recipient calls project the same cached pair; they do not sample independently. The private offline cache key is `(release_id,source_seed,role,realization,unit)`. R01's read-only duplicate audit found zero bitwise U0/fine-cell mismatches inside every duplicate `unit` group in FIT/ATT/INNER for both seeds, so that key is input-unambiguous for these sources; every duplicate member receives the same pair. The input digest binds both U0 score vectors and both fine cells, with exact byte serialization bound in R00's lock. A new-input provider service requires its own stable private person key and persistent cache; absent that capability it refuses this contract rather than promising sticky behavior from row order. Group labels/row IDs never appear on wire. A new service version can draw anew; this contract does not claim protection against unlimited newly sampled versions or recipient-triggered resampling.

Precommit exactly **three independent complete mechanism realizations**, indexed 0,1,2, for both source seeds and each ATTACK_FIT_NEW/INNER_SELECTION role. Each realization is a separate virtual one-release deployment, never three simultaneous observations given to one attacker. The offline generator uses **three distinct private 256-bit HMAC-SHA256 roots**, one per realization, with canonical UTF-8 domain-separated message `(schema,source_seed,role,realization,unit)`; interpret the first eight digest bytes as unsigned big-endian `v` and set `u=(v+0.5)/2^64`. Their public hashes are fixed in `STREAM_ROOT_HASH_MANIFEST.json`; private bytes are kept in its write-once ignored file and versioned custody. The complete pair is sampled once by right-sided inverse CDF on the ordered global output-pair law; a numerical CDF tail maps to the final positive-support pair, never an off-class global last code. The mandatory freeze-first sequential arms use a **fourth distinct private root and separate OSF_DEFENSE_FIT first-stage draw domain**, fixed before their second-stage training and distinct from the three ATT/INNER evaluation realizations. Public root hashes and exact stream/role identities are locked; key bytes, uniforms and cache rows remain private. Reuse the same uniform across matched arms only as predeclared common randomness, with arm-specific immutable caches. Production uses an internal CSPRNG once and a durable cache rather than accepting recipient-supplied coins. ATT attackers fit **separately per realization**, each seeing one release per training person; mechanism-aware augmentation from public `q` is reported as a separate reader, not extra observed releases. No best realization is selected. Report each draw and a paired/group uncertainty analysis that includes realization variability without treating draws or source seeds as new populations. All emitted IDs/vectors must restore bitwise from checkpoint, private stream/cache, canonical bank and role order.

For exact cache identity, hash ASCII `SCV1-input-v1` followed by one zero byte, contiguous little-endian float64 bytes of the two U0 vectors (lengths 2 and 6), two little-endian signed int64 fine-cell IDs, and the 32 raw bytes of the admitted source-binding SHA-256. The evaluation HMAC uniform message is compact ASCII JSON of `['SCV1-uniform-v1',source_seed,role,realization,unit]` with `separators=(',',':')` and no newline, keyed by that realization's root. The separate SEQ FIT message is compact ASCII JSON of `['SCV1-seq-fit-first-v1',source_seed,order,unit]`, keyed by the fourth root. These encodings are private service inputs and never wire fields. Fixed bank and provider score vectors must arrive as finite nonnegative **float64**, never be silently coerced from another dtype, and have absolute simplex residual ≤`10^-12`; neither is renormalized for release. The wire probability is an array of native finite JSON floats (not booleans, integers or numeric strings), parsed back to float64 bytes exactly matching its canonical bank row.

## 4. Scientific controls and interpretation

All new A controls use the same canonical bank, fine cells, four-action maps, mean utility caps, two source seeds, complete wire and frozen score features unless a restriction is the scientific point. Central product protection uses both U0 vectors but factors `q_1(z1|x)q_2(z2|x)`. Strictly local channels use only their own U0/fine input and are labeled narrower. Central TASK-STOCH and TASK-DET also see both scores but receive **no SEX labels** in their fitting process. TASK-STOCH minimizes empirical `I(X;(Z1,Z2))=H(mean_i q_i)-mean_i H(q_i)` under caps, with global output-pair aggregation. TASK-DET and JOINT-DET receive a serious equal-budget deterministic same-bank search; one rounding pass is inadequate. Freeze-first SEQ-12/SEQ-21 fit their first central-score release and freeze its checkpoint; **then** each FIT person receives one precommitted cached first-code draw (duplicate units share it). The second gate trains on both scores and that already sampled first public code, never a chosen favorable draw. Final exact expected utility and finite-law privacy are independently replayed by integrating the full frozen first-stage output law and second-stage conditionals; only an exactly feasible final checkpoint is selected. A joint kernel can factor in either sampling order; exact compilers in both orders are **engineering aliases**, never separately trained controls or evidence of extra expressiveness. The inherited T* `FINE-TASK` objective is task-oriented, but R01 found that its historical fit call chain accessed FIT SEX to build stratified fine tables; it is an immutable source, **not** a substitute for a new genuinely SEX-free task-only control. R13's controls document must bind starts, parameter counts, total effort and failure rules before R00's seal.

Historical T*, P*, compatible D0/local/sequential and original stochastic/compression controls require their own admitted exact wire and fresh ATT→INNER attack slate; similar names or output counts do not make them aliases. U0 and Ucal continuous-score anchors transmit their actual probabilities/decisions, without invented code IDs. The class-only diagnostic emits one fixed **existing canonical bank medoid per frozen predicted class**, with that code ID, bank probability and decision in the ordinary score wire. This is a deterministic function of the disclosed decision and gives its information floor; its actual confidence utility and eligibility are measured, not presumed. The strongest eligible comparator is selected only within the same score service under R00's predeclared rule. A method advantage over matched controls and a further JOINT-versus-best-central-product/both-design-orders advantage are separate claims. This family transfers known randomized quantization/privacy-funnel ideas to a central paired-score service; no generic finite-channel or joint-sampling novelty is presumed.

“Task-only” for TASK-STOCH/TASK-DET means **their incremental channel fit receives no SEX**, conditional on the inherited fixed score bank. It does not mean the whole source pipeline was historically sex-blind: the prior FINE-TASK partition fit accessed FIT SEX while building its fine table. Report that inherited exposure for every A arm.
