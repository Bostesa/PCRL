# Post-outcome replacement for the shuffled-label engineering control

**S1 design freeze, 2026-10-08. Status: SPECIFIED, NOT ADMITTED OR RUN.** This is an additional development protocol after B-TASK, B-JVIB, B-DVIB, B-RAW-TASK and B-LOCAL seed-0 outputs were observed. It is not a reinterpretation of the original lock, a fresh confirmation experiment, or a change to utility/privacy targets, release methods, attack readers or model selection.

The original control trained LR on group-shuffled ATTACK_FIT_NEW SEX, scored against **true** INNER_SELECTION SEX, took the maximum of two orientations, and required AUC at most 0.60. This is not a sound null: if a public feature equals SEX, any nonzero coefficient learned by chance ranks true SEX perfectly in one orientation. The predeclared control failures and passes remain in the historical ledger. S4's proof is in `S4_SHUFFLE_CONTROL_PREMISE_REVIEW_005.json`.

The V2 control keeps the original ATT groupwise shuffled-label LR fit. It then constructs an **independent** INNER groupwise shuffled SEX label vector with salt `pcrl-method-portfolio-v1|independent-inner-sex-null|20261008|v2`. The same-size-group vector permutation preserves duplicate-person groups and uses the frozen INNER row order. It computes max-oriented AUC against these permuted INNER labels, requiring at most **0.60**. The original shuffled-fit prediction AUC against true INNER SEX is still reported descriptively and never used as the mandatory null. Constant-reader AUC must equal 0.5; the planted true-SEX engineering-copy LR must achieve at least 0.99 against true INNER SEX. All labels and predictions stay private. Each view and arm/seed must pass all three V2 gates.

The independent INNER shuffle is fixed by the declared salt and PCG64DXSM implementation before any V2 Adult probe; it is not chosen from several permutations to obtain a pass. The V2 test suite must demonstrate the original X=SEX counterexample, verify ATT/INNER row/group alignment and both SEX classes, and prove that no forbidden role is read. Actual V2 probes use the same ATTACK_FIT_NEW/INNER_SELECTION roles, complete transmitted views and two fresh LR fits per view as the original probe. All eight B arms, two seeds and the feature anchor require the same V2 control if they enter the amended comparison. Original probe results are preserved with their original status, and every V2 probe gets a new ID, private attempt and CPU charge.

S1 and S4 must seal the exact code hashes, runtime, accepted historical fit-lock SHAs, attempt-index identities, unit list and S3 queue admission before any V2 Adult read. Existing B screens may be reused after S4's read-only static hash, role, source and complete-view identity audit; the full independent numerical endpoint replay follows V2 probing. A separate S4 parity unit that does not require V1 probe PASS may supply stronger pre-V2 evidence. No V1 PASS is inherited, and there is no after-outcome model retraining or change of seed. A future B fit uses the same frozen scientific design under a dated lock amendment. Changing the shuffled null is an acknowledged extra exposure and cannot establish independent confirmation.
