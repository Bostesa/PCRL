# Team D: post-hoc nonlinear repair of frozen task features

Status: pre-lock design, 2026-10-08. Adult fitting is authorized by the continuation but remains gated on S2's admitted role-only export, source checkpoint verification, S1's effective lock, revised-source numerical checks, and S3 compute admission.

## Question

Can a finite, group-blind repair of already task-trained latent features preserve both task confidence vectors under the common **mean** utility limits while lowering SEX recovery from each recipient and their coalition beyond matched compression and sequential controls?

The proposed information-changing operation is hard vector quantization. A frozen 16-dimensional purpose latent is replaced by one of 1,024 public centroids. The recipient sees one 10-bit code ID and a task head whose probabilities are a deterministic function of that ID. A continuum of distinct latent inputs therefore has the same released code. The fitted code also has at most 1,024 distinct values, fewer than the 15,434 fitting people, although its actual singleton-person mass must be measured. This is nonlinear, many-to-one, and can erase information even for a reader who knows the mechanism. It offers no general SEX privacy guarantee: a code may remain highly predictive of SEX, and useful predictions can disclose SEX by themselves.

One pooled codebook is trained on both purposes after fit-only, purpose-specific standardization. Pooling may encourage the same sensitive distinctions to be compressed consistently across recipients; the code pair, however, can reveal complementary clues and has up to 2^20 distinct identities, enough to be nearly unique on the fitting rows. Separate purpose encoders have no known coordinate alignment, so a pooled codebook may instead cost utility or create an artificial comparison. Equal output-bit separate-codebook, local, sequential, and pooled task-only controls decide whether pooling and privacy-aware repair add anything. Full-code and pair-code singleton-person mass must be measured; theoretical many-to-one mapping is no empirical privacy finding.

This differs from Team B's end-to-end stochastic Gaussian bottleneck: the upstream task encoders are frozen; the map is a post-hoc deterministic finite quantizer; and no input features, teacher clean output, or latent residual are appended. If Team B later implements the same quantizer on retrained latents, classify D as a frozen-upstream ablation rather than an independent invention.

The primary empirical target is within the FEATURE track only. A score-only comparator does not provide the same feature service. A successful D arm must retain actual accuracy, NLL, Brier and per-class usefulness against U0 and Ucal, reduce coalition recovery against the strongest eligible feature control, avoid a worse local view, and beat both sequential orders to support a joint-design claim. All results on reused Adult roles would remain exploratory.

## Stop conditions

Stop a real-data D screen if no lawful role-specific frozen latent and label export exists; if the quantized output violates either task's utility caps; if a fresh complete-view attack removes the gain; if the gain is explained by task-only quantization, a local or sequential arm, or the ordinary raw adversarial control; or if only an invertible pre-map changes a weak attack. Synthetic capability checks do not establish Adult prevalence.
