# Team D matched controls and comparison rule (pre-lock draft)

Status: design only. No Team D real-data fit has run. The campaign lock and S2's common protocol control the final seed IDs, calibration rule, attack slate, resource ceiling and endpoint definitions. If those differ from this draft, resolve the design before the first fit; preserve this draft in the record.

## Scientific contrast and disclosure

The D candidate is a **post-training, pooled, group-blind hard vector quantizer** of two frozen task-trained 16-dimensional latents. The revised pre-fit transform has one shared 1024-centroid full-vector codebook and a 10-bit code per recipient. Frozen, purpose-specific mean/standard-deviation normalization is learned on defense-fit rows and shared by every D quantizer arm; there is no learned cross-purpose alignment. Squared Euclidean nearest-centroid ties go to the lowest index. The codebook learns from fitting-role task and SEX labels, but at deployment the same public transform is evaluated separately on each recipient's own latent. Recipient `i` gets its code ID, its decoded code vector (or a public lookup of that vector), the retrained head's probabilities and decision, and every flag/length/fallback value. The coalition gets both complete recipient views. The frozen latent, clean teacher output and the other recipient's private per-person input are unavailable to a single recipient. The code ID is categorical, never an ordinal feature. Hard quantization makes the transform many-to-one even if the continuous decoded vector is also sent.

All feature-track controls disclose features with their protected heads and complete metadata. A score-only result is historical context, not a feature-track privacy comparator. A public model lets a defense-aware reader compute transformations of the *received* data; it does not give them an untransmitted person's raw input. S2 must freeze the actual side-information contract. Compare utility to both U0 and Ucal and privacy to the strongest eligible **feature-track** control. A control is eligible only if its deployed outputs pass both tasks' point utility gates against both references, has complete-view attacks and a matching allowed-input contract. Report ineligible controls without letting their near-constant releases set an easy benchmark. S1's locked strongest-control rule governs final ranking.

`D_VQ_TASK` is the generic pooled compression arm; counting a second identical pooled compressor as an extra control would be cosmetic duplication. **D currently lacks a prelocked realized-distortion-matched pooled compression fit.** Equal reconstruction coefficients and code capacity do not force equal realized distortion. Before any eventual Adult fit, S1 must specify and charge a realized-distortion-matching procedure or leave compression/component and joint-novelty attribution unresolved; do not tune a comparator to screen outcomes. If existing compatible continuous nonlinear repair or FARE gives a stronger eligible feature-track control under the same inputs and complete interface, add it to the baseline registry with its exact immutable ID and costs before screening. Existing `RAW-J`, LEACE and FARE releases from hcal/lra can inform priors, but their historic score/feature contracts and old attack roles are not silently equated to the new D views. Source JCV's neural `S12/S21` controls are **not** Taylor et al.'s algorithm; the new D sequential arms are likewise labeled by their actual construction.

## Resource and implementation matching

Use the same two frozen encoders and fitting rows across all post-training arms of one seed. Source-model artifacts are aliases only when source SHA, seed, schema, row order and preprocessing match exactly. Use the same 1024-centroid full-vector quantizer, per-recipient 10-bit code cardinality, 16→64 GELU→classes head, 20-epoch Adam final iterate, no checkpoint selection, and fixed calibration family for `D_VQ_TASK`, `D_VQ_JOINT`, `D_VQ_LOCAL` and both sequential orders. Each trained VQ fit includes its head. The protected prototype adds the mean of three SEX-conditioned hard-code discrepancies: exact squared difference of the 1024-cell code-frequency vectors for each local view and squared difference of a fixed 128-feature factorized Rademacher sketch of aligned pair IDs. Hard one-hot codes are used in the forward loss, with a temperature-1 distance-softmax straight-through gradient to codebook centroids. The task-only VQ removes these terms while keeping task loss, Ucal teacher distillation and the 0.25 normalized reconstruction term unchanged. The pair sketch has a nullspace; fresh direct pair-ID attacks are mandatory. Record how many people's deployed hard IDs change from seeded k-means initialization. If decoded vectors shift but hard IDs do not, or direct hard-ID readers erase the apparent gain, D has no protected-release result. The joint shared codebook has fewer total parameters than two local codebooks; report both per-recipient and total capacity. A sequential first stage is a cache alias only if its complete objective, initialization, data order, update count, checkpoint and output hash equal the local stage. No comparison is won by reducing a control's tuning/restarts, attacker bank, or optimization time. Charge all fitting, preprocessing, forward and attack work to the global queue, including failed attempts.

These prior findings motivate measurement; they do not predetermine D's result.

## Strongest-control verdict

Report each arm's task accuracy, mean NLL, multiclass Brier, per-class recall, retained gain, local SEX AUCs and coalition SEX AUC on every seed, with the complete-view attacker bank. The primary D method comparison is `D_VQ_JOINT` against the eligible control with the *lowest* coalition AUC under S1's frozen tie rule, including `D_VQ_TASK`, `D_VQ_LOCAL`, `D_VQ_SEQ12`, `D_VQ_SEQ21`, `D_LEACE`, `D_RAW_J` and `D_U_FROZEN` where eligible. Joint-design credit also needs a benefit over both sequential orders and the strongest non-joint arm with no local AUC worsening beyond the common cap. A deterministic compression win can be useful without supporting a new joint mechanism claim.
