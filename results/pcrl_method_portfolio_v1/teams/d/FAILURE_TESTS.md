# Team D failure and validity tests (pre-lock draft)

Status: design only; no real-data fit or attack has run. Synthetic laws and their expected outcomes belong in the shared pre-lock law file, owned by S1/S4. These tests specify D's checks without changing that shared file.

## Before any fit

1. Confirm all input features are the pinned 83 permitted columns, with SEX, task labels, race, IDs, fnlwgt and hidden role indicators excluded. Use only S2's role-specific safe exports. No old assessment array or HEAD_VALIDATION label may be materialized, even transiently. Confirm 15,434 defense-fit rows, 4,064 new attacker-fit rows, 2,235 inner-selection rows and the pinned group hashes.
2. Verify a fresh deployment call takes only that recipient's permitted input and public artifacts. It must not branch on true SEX, the other recipient's per-person latent, task labels, fitting-role membership or an unavailable global batch. Shared model parameters and a shared fixed codebook are allowed; per-person cross-recipient coordination is not. A deterministic single-person replay must equal the batched release.
3. Freeze the frozen source-model hashes, quantizer width/code count, head class, calibration, loss weights, update ceiling, seeds, attack slate and every planned control in the campaign lock. Run tiny tests showing a code collision changes information, an invertible control leaves recoverability possible, and the decoder cannot reconstruct a hidden raw latent from an exposed untouched teacher score. A tiny law result is capability only.
   Also keep an engineering counterexample in which decoded centroids move and decoded-vector dependence drops while every hard public ID is unchanged. The hard-ID loss and direct ID readers must expose this failure. It is a correctness fixture, not a scientific-law outcome.
4. Run unchanged-latent and shuffled-SEX engineering controls. The shuffled-label fit should not be given a protected-recovery claim. A constant/null reader and a planted local and XOR coalition leak must behave as registered under the same serialization and attack path. Failure blocks D's affected result.

## Transform and view checks

- Assert the deployed code has fewer distinguishable outputs than the continuous frozen latent and record occupied codes, code frequencies, **singleton-person mass**, pair-code occupancy, collision rate, reconstruction distortion and exact codebook/decoder hashes. The revised 10-bit single code caps each recipient at 1024 identities, but the aligned pair can have up to 1024² identities and could still be sparse. Formal collisions alone do not establish protection. Merely passing a latent through an invertible flow, permuting coordinates or adding a head that attackers fit poorly is not erasure.
- Check hard one-hot forward IDs and the temperature-1 distance-softmax straight-through backward path separately. On a locked tiny fixture, the task and code-identity discrepancy terms must give nonzero codebook gradients, and the protection term must be capable of changing a hard ID. Count actual hard-ID churn from k-means initialization on fit and inner roles; a moving centroid with unchanged IDs is not demonstrated privacy repair.
- Recompute both heads from the released code/decoded feature and public parameters. Forbid appended original teacher probabilities, clean logits, original latent, residuals, reconstruction errors, nearest-neighbor distances or preprocessing statistics computed per person unless explicitly declared and attacked.
- Give local readers the complete recipient tuple: categorical code ID, decoded vector, probabilities, decision, fallback/exception flags and any code length or mask. Give coalition readers both tuples and both ignore-the-other-recipient alternatives. Include direct smoothed hard-ID and pair-ID readers, defense-aware codebook lookup and adaptive nonlinear readers. The exact code ID and public table may carry more than a lossy display of rounded probabilities. Prelock unseen-code and unseen-pair fallback plus structured marginal alternatives; tune smoothing/restarts only inside ATTACK_FIT_NEW, never from INNER_SELECTION labels.
- If the implementation has out-of-vocabulary, empty-cell, abstain or fallback paths, count them on each role and attack the flag and fallback value. A raw-latent or raw-score fallback that dominates deployment invalidates the claimed protected channel.
- Test local and coalition views independently. An improved marginal AUC with unchanged coalition AUC is a D no-go; so is a coalition benefit created by moving leakage to one recipient beyond the common +0.010 cap.
- The factorized 128-sign pair sketch has a nullspace. An apparently small training pair discrepancy does not substitute for direct fresh pair-ID recovery. If hard-ID and pair-ID attackers remove the claimed benefit, stop the D protected-release claim.

## Utility, inference and attribution

- On every screen seed and task, report accuracy, mean NLL and mean multiclass Brier against both U0 and Ucal, with the common 0.010 accuracy, 0.010-nat NLL and 0.005 Brier caps. Report actual decisions, per-class recall and retention. A retrained head has no structural decision-preservation claim.
- Use S1/S2's simultaneous intervals and conventions: a loss/local-AUC cap passes only when its upper bound is at or below the cap; coalition benefit needs its lower bound at or above 0.020; an interval crossing a boundary is unresolved. A favorable point estimate can support promotion, never a passed clause by itself. Pair people across seeds and label all intervals conditional on selected fitted models.
- Compare D joint to task-only pooled compression at identical code cardinality and to both sequential orders. If the task-only quantizer matches the candidate, assign any observed benefit to compression. If an independently trained local or sequential arm matches it, no joint-design credit follows. If the raw adversarial control wins, report that directly.
- Keep official LEACE's linear guarantee scoped to its exact fitting-row quantity. Nonlinear AUC after LEACE is a separate empirical fact. Do not describe a fitted attacker AUC as Shannon information, differential privacy or a proof of irrecoverability.
- If codebook training uses both latent distributions, verify that at runtime each recipient calls the transform on its own latent only. If the transform needs paired latents to choose a code, it violates the declared interface. If D's frozen-latent post-processing collapses algebraically to B's end-to-end bottleneck, record a cross-team duplicate and test it only as a named ablation.

## Stop and record

Stop D's competitive claim if no arm satisfies useful mean-utility point gates on both tasks, a fresh nonlinear complete-view attacker removes the apparent gain, the coalition sees the same signal, a deterministic/task-only/local/sequential arm explains the gain, or the method is invertible or routes by true SEX. Preserve all attempted IDs, failed units, timings and outputs privately. An incomplete control or unreadable safe role export yields `INVALID_OR_INCOMPLETE`, not a negative scientific result. Do not open old assessment rows to repair it.
