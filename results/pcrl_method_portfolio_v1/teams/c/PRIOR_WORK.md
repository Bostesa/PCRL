# Team C primary prior work and novelty boundary

Read on 2026-10-08. This is a mechanism-specific note; the shared campaign prior-work file may add other families.

| Primary source | Actual setting and relevance | Boundary for Team C |
| --- | --- | --- |
| Khodadadian et al., [Information Theoretic Measures for Fairness-aware Feature Selection](https://arxiv.org/abs/2106.00772), 2021 | Subset-level information-theoretic accuracy and discrimination measures, with Shapley-style marginal feature contributions for fairness-aware selection. | Particularly close conceptual prior: correlated features and subset effects are already recognized. Team C's additive leave-one-out score is a cheaper heuristic, with no Shapley or information-theoretic guarantee. The paper's discrimination objective is not this raw-view SEX recovery endpoint. |
| Xing et al., [Fairness-Aware Unsupervised Feature Selection](https://arxiv.org/abs/2106.02216), 2021 | Unsupervised selection using kernel alignment to preserve information in the original features while reducing correlation with protected attributes. | Shows feature selection as a preprocessing fairness method predates this campaign; its utility target and release interface differ from Team C's supervised two-task raw-feature views. |
| Quinzan et al., [Fast Feature Selection with Fairness Constraints](https://proceedings.mlr.press/v206/quinzan23a.html), AISTATS 2023 | Fast feature selection under downward-closed fairness constraints, with approximation claims under its assumptions for parametric models. | It establishes constrained feature selection as prior art. Team C does not inherit its approximation theorem and must implement a compatible arm before naming it as a reproduced control. Its fairness criterion is not SEX inference AUC from two disclosed raw views. |
| Ling et al., [Fair Causal Feature Selection](https://arxiv.org/abs/2306.10336), 2023 | Local causal-graph/Markov-blanket feature selection intended to block sensitive-information paths while retaining classification performance. | Sensitive-aware feature removal is established. Team C makes no causal graph or path-blocking claim. A causal selector is a separate compatible control only if its assumptions and available inputs can be matched. |
| Duan et al., [Fair Streaming Feature Selection](https://arxiv.org/abs/2406.14401), 2024 | Sensitive-aware selection for a stream of arriving features and a fairness objective. | Team C is static and purpose-specific. The paper is evidence against a generic novelty claim for sensitive-aware selection, not proof about this coalition release. |
| Makhdoumi et al., [From the Information Bottleneck to the Privacy Funnel](https://arxiv.org/abs/1402.1774), 2014 | Probabilistic privacy mappings under log-loss, with mutual information for private and useful variables. | Motivates task/privacy trade-offs. Team C uses fixed masks and finite SEX attack AUC, so its surrogate or outcome is not a Privacy Funnel optimum or information-theoretic certificate. |
| Taylor, Vippathalla and Coon, [Adaptive Privacy of Sequential Data Releases Under Collusion](https://arxiv.org/abs/2601.21859), 2026 | Sequential release under collusion with expected-distortion or mutual-information utility and mutual-information privacy, using an adaptive algorithm. | Both sequential mask orders are required comparators. Their information-theoretic optimality result does not apply to this fixed-mask, raw-feature, finite-attacker setting. Do not label a generic greedy mask as Taylor's algorithm. |

The candidate's potentially useful contribution is empirical: a transparent raw-feature release that meets the task/confidence criteria with less complete-view SEX recovery than strong matched alternatives. Its joint selection score gives an explicit union term. That alone is a known objective pattern, not a new theorem or established novel algorithm. If fixed common removal explains the result, report the simple finding. If a compatible existing coalition-aware selector matches it, attribute nothing specifically new to this heuristic.

Fairness metrics such as demographic parity, mutual information, and finite attacker AUC answer different questions. We report SEX recovery and task utility directly; no demographic-parity or differential-privacy claim is implied.
