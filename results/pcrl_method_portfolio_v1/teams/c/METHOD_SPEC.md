## Input and disclosure

Use the pinned 83-column, ordered Adult predictor schema from `jcv/data.py` and the admitted hcal schema hash. Numeric groups: `age`, `education-num`, `capital-gain`, `capital-loss`, `hours-per-week`. Categorical groups: `workclass`, `education`, `marital-status`, `relationship`, `native-country`; all one-hot columns of a categorical field are indivisible. Bind `education` and `education-num` as a single `education_fact` atom, leaving nine selection atoms. No `sex`, `race`, `income`, `occupation`, `fnlwgt`, row ID, group ID, or target-derived field can be a predictor. Schema validation must reject unexpected names, missing columns, reordering, and partial atoms.

For each fitted seed, learn two global masks `M_income` and `M_occupation`. They are constant over people and public. The income recipient gets the selected encoded raw values, calibrated income probability vector, decision, mask ID, head ID and any actual flag/fallback. The occupation recipient gets the analogous occupation view. The aligned coalition gets both full recipient views. The two heads consume only their own selected values; each calibrator consumes only its head's probability vector, and the release transmits that calibrated vector. The original teacher's clean scores cannot be appended. Public weights, scaler, masks and calibration parameters are available to defense-aware readers. Public model parameters do not supply per-person unselected input values. No SEX or other protected label is read at deployment.

For evaluation and replay, private release receipts bind ordered `row_id` and `unit` arrays, role identity and hashes for each local and coalition file. The evaluator checks the three orders agree before building a coalition attack. These identifiers are custody fields, not transmitted recipient features; including them in an attack requires a separate declared side-information contract.

The numeric values are the admitted standardized representation; the fixed public scaler permits recovery of the original numeric values to its precision. One-hot groups disclose their category. Thus `raw selected feature values` means all selected encoded columns, with no attempt to hide a category behind a head output.

## Prototype identities

`C-JOINT-GROUP` is the primary selector. `C-INDEP-GROUP` is the structural ablation. Both enforce `relationship` absent from both masks before scorecard fitting. This fixed exclusion is a pre-fit premise. Full-feature and fixed common `drop relationship only` heads remain required controls. Relationship-excluded selector controls use the same eight optional atoms, scorecard, removal budget and final model architecture. Strong unrestricted task-only and independent controls can select from all nine atoms at the candidate's final per-recipient atom counts; their separate full-feature-base scorecard is charged to the budget. Every final head uses the same architecture and calibration rule.

For the draft cheap selector, let `B` be the eight remaining atoms. Make a group-disjoint 75% fit / 25% selection split wholly inside `OSF_DEFENSE_FIT`, fixed by the registered seed identifier. If the fit side lacks a task or SEX class, move the smallest selection-side group containing a missing class into fit, tie-breaking by numeric `unit` ID; repeat until fit has the full declared vocabularies, keep groups intact and do not replenish selection. Require nonempty selection with both SEX classes for AUC; task selection need not contain every class. Record moved group IDs by private hash/count. Use this one repaired split for every scorecard mask. On the internal fit part train one standardized `LogisticRegression(C=1.0, solver=lbfgs, max_iter=300)` task proxy for each task and two fixed SEX proxies on the raw selected values: the same standardized logistic family and `DecisionTreeClassifier(max_depth=2, min_samples_leaf=10)`, with random states derived only from the registered seed. For each SEX reader, internal-selection recovery is `max(AUC, 1 - AUC)`; the mask's score is the greater recovery of the two readers. This predeclared orientation and reader envelope prevent an inverted or weak linear reader from appearing private. The tree has the capacity to represent a simple XOR clue, but the registered planted-XOR test showed that this fitted proxy did not reliably learn it; see the dated disposition below. Fit the base mask `B` and each of its eight single-atom removals. The unrestricted controls additionally require the full-feature base and nine single-atom removals; the relationship-only mask is an exact shared alias, making 18 unique masks per seed. Cache exact mask/view identities. Let `dNLL[t,a]`, `dBrier[t,a]`, and `dAcc[t,a]` be the leave-one-atom-out changes from the relationship-removed base task proxy. Let `dAUC[a]` be the base minus removal SEX recovery on raw values. These are empirical surrogate numbers, not information certificates or final endpoints. Reader choice uses only the internal OSF defense-fit selection partition, never `INNER_SELECTION`.

Enumerate all pairs of optional removal sets `(R_income,R_occupation)` with each set a subset of `B` of size at most two (37 possibilities per recipient, 1,369 pairs). Admit a pair only if the additive proxy costs for each task satisfy `sum(dNLL) <= 0.010`, `sum(dBrier) <= 0.005`, and `sum(dAcc) >= -0.010`, with non-strict boundaries. These are selection heuristics against the relationship-removed proxy base; final common criteria are separately measured against U0 and Ucal. `C-JOINT-GROUP` maximizes

`sum_{a in R_income ∩ R_occupation} dAUC[a] + 0.25 * (sum_{a in R_income} dAUC[a] + sum_{a in R_occupation} dAUC[a])`.

The intersection is what disappears from the raw coalition union. The local terms discourage moving all leakage to one recipient. Ties choose fewer total removed atoms, then the lexicographically first ordered pair of atom-name tuples. The empty sets are feasible. No post-outcome multiplier, cap or removal-count tuning is allowed. `C-INDEP-GROUP` uses the same scorecard and constraints, fixes each recipient's removal count to the candidate's fitting-role-selected count, then maximizes each recipient's local `sum dAUC` separately, with the same tie rule and no overlap objective. It is always attacked as a coalition after selection. Its union count may differ and is reported. The additive card can still miss feature interactions and higher-order complementary clues; this is a union-overlap heuristic, not a coalition-optimality claim. Fresh nonlinear attacks and actual retrained heads determine whether the idea survives.

After selection, retrain each task head on its selected values on the allowed fitting role. The proposed common Team C head for S3 timing is a two-hidden-layer ReLU network of width 64, with 2 or 6 logits, Adam at 0.001, zero weight decay, batch size 512, at most 30 epochs and one numerical thread. A group-disjoint 15% internal OSF split (seed plus 17,001) chooses the epoch by natural-log NLL, patience 5, minimum improvement 0.0001 and first-minimum tie handling. Apply the same class-safe group move as above if the early-stop fit side lacks a task class. Reinitialize from the same seed and refit on all OSF rows for the chosen number of epochs, with fixed per-epoch shuffles. This makes two neural training stages per final task head. S3 must time this exact path before S1 freezes it; it remains a draft until the shared science seal. All selector and fixed-mask controls receive the same architecture, training schedule, seed treatment, calibration role and output interface. S2 fits the single fixed H-GLOBAL-TEMP scalar separately for each task head on CALIBRATION_HELDOUT; the transmitted probability is the calibrated vector. The mask fitted for one seed is not selected by another seed's inner result. `HEAD_VALIDATION`, the old assessment and new attack-fit labels are outside selection and defense fitting.

## Structural premise and failure interpretation

If both heads are deterministic functions of their own released raw values, then `I(SEX; X_M1, X_M2, head1, head2 | public fixed parameters) = I(SEX; X_(M1 union M2) | public fixed parameters)` for the same fitted mechanism law. This equality concerns ideal information, not a finite reader's AUC; calibration and decisions are also deterministic functions if they read only the selected values. If a runtime adds stochastic metadata or a fallback, the identity must be reconsidered and all transmitted components attacked. The selector itself is learned with SEX, but its fixed public mask is not a per-person signal at inference.

The candidate is killed if utility fails, fresh complete-view recovery removes the gain, or a simpler matched control explains it. A common removal win is still a potentially useful transparent baseline. It carries no algorithmic novelty by default.
