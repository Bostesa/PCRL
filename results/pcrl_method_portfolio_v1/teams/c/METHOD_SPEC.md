# Team C method specification — draft for campaign lock

Status: Phase I design, not a frozen campaign lock. S1/S2 must reconcile the exact shared endpoint and calibration contract before any real-data fit. S3 must smoke-time the unit plan.

## Input and disclosure

Use the pinned 83-column, ordered Adult predictor schema from `jcv/data.py` and the admitted hcal schema hash. Numeric groups: `age`, `education-num`, `capital-gain`, `capital-loss`, `hours-per-week`. Categorical groups: `workclass`, `education`, `marital-status`, `relationship`, `native-country`; all one-hot columns of a categorical field are indivisible. Bind `education` and `education-num` as a single `education_fact` atom, leaving nine selection atoms. No `sex`, `race`, `income`, `occupation`, `fnlwgt`, row ID, group ID, or target-derived field can be a predictor. Schema validation must reject unexpected names, missing columns, reordering, and partial atoms.

For each fitted seed, learn two global masks `M_income` and `M_occupation`. They are constant over people and public. The income recipient gets the selected encoded raw values, calibrated income probability vector, decision, mask ID, head ID and any actual flag/fallback. The occupation recipient gets the analogous occupation view. The aligned coalition gets both full recipient views. The two heads consume only their own selected values; each calibrator consumes only its head's probability vector, and the release transmits that calibrated vector. The original teacher's clean scores cannot be appended. Public weights, scaler, masks and calibration parameters are available to defense-aware readers. Public model parameters do not supply per-person unselected input values. No SEX or other protected label is read at deployment.

The numeric values are the admitted standardized representation; the fixed public scaler permits recovery of the original numeric values to its precision. One-hot groups disclose their category. Thus `raw selected feature values` means all selected encoded columns, with no attempt to hide a category behind a head output.

## Prototype identities

`C-JOINT-GROUP` is the primary selector. `C-INDEP-GROUP` is the structural ablation. Both enforce `relationship` absent from both masks before scorecard fitting. This fixed exclusion is a pre-fit premise. Full-feature and fixed common `drop relationship only` heads remain required controls. Relationship-excluded selector controls use the same eight optional atoms, scorecard, removal budget and final model architecture. Strong unrestricted task-only and independent controls can select from all nine atoms at the candidate's final per-recipient atom counts; their separate full-feature-base scorecard is charged to the budget. Every final head uses the same architecture and calibration rule.

For the draft cheap selector, let `B` be the eight remaining atoms. Make a group-disjoint internal fit/selection split wholly inside `OSF_DEFENSE_FIT`, fixed by the registered seed identifier. On the internal fit part train a fixed logistic task proxy for each task and two fixed SEX proxies on the raw selected values: logistic and a depth-2 decision tree, with the tree's random state derived only from the registered seed. Score on the internal selection part, taking the greater SEX AUC of the two readers for each mask by the same fixed rule. This proxy pair can represent simple complementary/XOR clues that logistic alone misses. Fit the base mask `B` and each of its eight single-atom removals. The unrestricted controls additionally require the full-feature base and nine single-atom removals; the relationship-only mask is an exact shared alias, making 18 unique masks per seed. Cache exact mask/view identities. Let `dNLL[t,a]`, `dBrier[t,a]`, and `dAcc[t,a]` be the leave-one-atom-out changes from the relationship-removed base task proxy. Let `dAUC[a]` be the base minus removal SEX AUC on raw values. These are empirical surrogate numbers, not information certificates or final endpoints. Reader choice uses only the internal OSF defense-fit selection partition, never `INNER_SELECTION`.

Enumerate all pairs of optional removal sets `(R_income,R_occupation)` with each set a subset of `B` of size at most two (37 possibilities per recipient, 1,369 pairs). Admit a pair only if the additive proxy costs for each task satisfy `sum(dNLL) <= 0.010`, `sum(dBrier) <= 0.005`, and `sum(dAcc) >= -0.010`, with non-strict boundaries. These are selection heuristics against the relationship-removed proxy base; final common criteria are separately measured against U0 and Ucal. `C-JOINT-GROUP` maximizes

`sum_{a in R_income ∩ R_occupation} dAUC[a] + 0.25 * (sum_{a in R_income} dAUC[a] + sum_{a in R_occupation} dAUC[a])`.

The intersection is what disappears from the raw coalition union. The local terms discourage moving all leakage to one recipient. Ties choose fewer total removed atoms, then the lexicographically first ordered pair of atom-name tuples. The empty sets are feasible. No post-outcome multiplier, cap or removal-count tuning is allowed. `C-INDEP-GROUP` uses the same scorecard and constraints but maximizes each recipient's local `sum dAUC` separately, with the same tie rule, ignoring overlap. It is always attacked as a coalition after selection. The additive card can still miss feature interactions and higher-order complementary clues; this is a union-overlap heuristic, not a coalition-optimality claim. Fresh nonlinear attacks and actual retrained heads determine whether the idea survives.

After selection, retrain each task head on its selected values on the allowed fitting role, using S2's common feature-track architecture, training budget and calibration family. All selector and fixed-mask controls receive the same architecture, training schedule, seed treatment, calibration role and output interface. Final head capacity and calibration settings are shared lock fields; this Team C draft does not change them. The mask fitted for one seed is not selected by another seed's inner result. `HEAD_VALIDATION`, the old assessment and new attack-fit labels are outside selection and defense fitting.

## Matched controls and evaluation

Required controls: full-feature task heads; fixed common `relationship` removal; utility-only masks at each candidate's actual atom counts with all nine atoms eligible and a separate relationship-excluded structural version; independent local privacy masks with all nine atoms eligible and a relationship-excluded structural version; both sequential mask orders using the relationship-excluded scorecard, search space and budget; common shared-mask selection; and any compatible established coalition-aware selector. A stronger all-atom sequential implementation should be added if budget and a faithful matching rule permit it. All-atom controls use a scorecard built from the full-feature base and its nine single-atom removals. Relationship-excluded selectors use the relationship-removed base and its eight further single-atom removals. Candidate and controls must report their different base conditions. A source method is named only if faithfully implemented in its own setting. Retrain heads and calibrate every eligible arm equally. Score all arms on `INNER_SELECTION` after fresh attackers fit on `ATTACK_FIT_NEW`; never optimize masks or heads on `INNER_SELECTION` labels. Attacks receive selected raw values, head probabilities, decisions, mask IDs and all transmitted metadata. Include linear, nonlinear, complete-view, local, ignore-one-recipient and defense-aware readers in the shared slate. Check mask and metadata leakage. The union raw-value-only reader is especially important because it isolates the selection mechanism.

Task accuracy, NLL, Brier, per-class retention and SEX recovery use S1/S2's frozen feature-track definitions. A point-feasible proxy search candidate is not a passed clause. The candidate needs the final simultaneous intervals and strongest-control comparison specified by the campaign. The selection is exploratory on reused Adult outcomes.

Capacity reporting records selected semantic atom counts and transmitted encoded-column counts for each recipient and their union. Unrestricted task-only and independent controls match the candidate's realized per-recipient atom counts; any union or encoded-column mismatch is displayed and limits causal attribution. A single shared mask cannot usually match two distinct recipient masks and their union simultaneously; show its attainable matched points without presenting an unequal interface as equal capacity. Within the eligible matched feature-track controls, the strongest privacy comparator is the one with the **lowest** complete-view coalition SEX AUC under S1/S2's frozen rule; a higher-AUC control cannot set an easier threshold.

## Structural premise and failure interpretation

If both heads are deterministic functions of their own released raw values, then `I(SEX; X_M1, X_M2, head1, head2 | public fixed parameters) = I(SEX; X_(M1 union M2) | public fixed parameters)` for the same fitted mechanism law. This equality concerns ideal information, not a finite reader's AUC; calibration and decisions are also deterministic functions if they read only the selected values. If a runtime adds stochastic metadata or a fallback, the identity must be reconsidered and all transmitted components attacked. The selector itself is learned with SEX, but its fixed public mask is not a per-person signal at inference.

The candidate is killed if utility fails, fresh complete-view recovery removes the gain, or a simpler matched control explains it. A common removal win is still a potentially useful transparent baseline. It carries no algorithmic novelty by default.
