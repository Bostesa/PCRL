# Team B: premise and failure tests (pre-lock draft)

The team records outcomes for every test. A failed validity control blocks the affected result; a valid unfavorable outcome is retained as a scientific no-go. No Adult fit starts before the shared lock and S2's safe-input guard.

## Before real data

1. **Input and deployment locality.** Scientific workers read only S2-admitted role-specific exports. Probe the entire **scientific** loader call chain with a forbidden-array sentinel; it must neither read nor materialize old-assessment task/SEX arrays or HEAD_VALIDATION labels. The one isolated S2 custodian exporter may transiently deserialize mixed-role storage only under the continuation's narrow mechanical exception; it must never emit, log, inspect or scientifically use excluded values. Prove all model and calibration training rows are in allowed roles. Reject any task label, SEX, race, ID, or source target column in the 83 input predictors. The deployed encoder/head/calibrator must work from permitted `X` and its own randomness, without per-person SEX or task labels.
   Before Team B fitting, compare the in-memory data against S2's independently recorded role-only export and admission manifest digests, exact ordered fit row/group memberships, ordered permitted schema, source ID, role ID and Ucal teacher IDs. A mismatch must fail before a private attempt is created. A private attempt must use mode `0700`.
2. **Actual release dependency.** Replace `z_i` with a constant while holding all public parameters fixed. The raw head logits and calibrated recipient probability must change or become the corresponding constant-head output; any clean-teacher bypass fails. Enumerate exactly the tensors and flags transmitted, and show the attacker view contains them.
3. **Stochastic contract.** Seed a person-specific fixed draw and reproduce it bitwise from a committed seed/counter plan without using protected labels. Check one disclosed draw per person, no hidden best-draw selection, and score NLL/Brier on that draw's probability. Test whether repeated calls resample; if so, preregister query count and aggregate attack before lock. If the contract is one fixed release, do not claim repeated-query protection.
4. **Small laws, frozen first.** On independently specified finite laws test feasible null, removable SEX distinction, complementary coalition clue, no complementarity, and confidence-useful versus class-only. Check that the pair reader can ignore either local view. Class-only sets an ideal-reader privacy floor but may fail confidence. Analytic premise checks precede running algorithms. Neither a tiny-law win nor a variational KL bound proves Adult attack recovery.
5. **Objective/gradient correctness.** Verify task CE and teacher distillation reach both encoder and head; local critic gradients reach only their corresponding encoder, pair critic gradients reach both for `B-JVIB`, and frozen first-stage parameters receive none in sequential arms. Critic ascent/descent signs, KL formula, sampling reparameterization, finite gradients and checkpoint hashes must pass. `B-DVIB`'s KL is labelled a regularizer only.
6. **Matched starts and aliases.** Compare seed, initial tensor, row order, preprocessing, architecture, optimizer updates, distillation teacher and calibration recipe for every claimed alias. If any differ, count a separate unit. No retrospective alias from similar outputs.

## Real-data controls and scientific kill rules

- **Null and shuffled SEX.** A constant/majority SEX reader and a fixed shuffled-label attack use the internal attack-fit/tune split and score on INNER only after reader/orientation freeze. A failed null calibration or above-threshold shuffled recovery invalidates the affected attack pipeline.
- **Planted leak.** On a separate engineering copy, inject a strong local signal and an XOR-like complementary pair clue into the complete view; the LR/MLP/HGB/defense-aware bank must detect the intended pattern. This never changes candidate releases. If the bank misses a planted pair clue, coalition comparisons are not valid.
- **Public metadata and transform.** Remove and restore each public field only as a diagnostic; the primary attack always sees `z`, raw head logits, calibrated probabilities, decisions, sampler/fallback flags and other transmitted fields. Test a defender-aware reader with public weights. A lower AUC from excluding any field is not a privacy gain.
- **Ignore-recipient coalition.** Pair recovery must be at least the strongest included local candidate on the same fitted predictions, subject to identical scoring rows. A failure is an implementation error. Report synergy separately; when complementarity is absent, a joint method may have no room to improve except local leakage.
- **Utility.** A task that misses either NLL/Brier allowance or usefulness/accuracy on either reference is not a common-criterion pass. Wide intervals are `UNRESOLVED`, not violations. A valid point-estimate shortfall can end the lane without repeating strengths or changing caps.
- **Recovery.** Fit nonlinear and defense-aware readers on the ATTACK_FIT_NEW fit partition; tune and freeze on its group-disjoint tune partition. Score the fixed-slate AUC envelope on INNER once. The local-cap anchor for all feature controls is S1's fixed `FEATURE_REF_RAW83_U`, not a candidate-dependent task-only arm. If the pair gain vanishes, a local AUC worsens by more than `0.010`, or a public-field attack restores leakage, the candidate fails its stated privacy objective. If `B-DVIB`, either task-only arm (`B-TASK`, `B-RAW-TASK`), `B-LOCAL`, either sequential order, or `B-RAWJ` matches the result at eligible utility, the attributed component or joint advantage is unsupported.
- **Variance and exposure.** Preserve paired people across model seeds and stochastic draws. Report mechanism draw variance separately from row uncertainty; never treat seeds/draws as new populations. Development intervals are conditional on fitted models and search history.
- **Invalid premise.** If S2's role-specific export cannot be created and admitted, mark Adult fit units `BLOCKED_SAFE_INPUT`; continue synthetic correctness and docs. The CCM scientific-loader transient read must be described as such; post-load masking does not repair it. A compliant isolated exporter is a distinct custody operation, not permission for scientific workers to use the old loader.

No-fallback selection: report failed arms, incomplete stages, skipped units and all seeds; never select a seed, noise draw, checkpoint or comparator by observed inner performance except the frozen rule.
