# Team A: premise and failure tests

Status: prelock specification. Run synthetic correctness checks before Adult fits, then freeze the law bytes, tests, arm list and rejection rules in the campaign lock. A synthetic win is a capability check, not evidence of Adult prevalence. A failed required control blocks the affected result as invalid; it is not an unfavorable scientific result.

## Mechanism and arithmetic checks

1. **Locality and class.** For each recipient `r`, sample `z_r ~ Q_r(. | t_r)` using only its own frozen fine score bin `t_r`, public frozen channel and permitted random stream. No true SEX, task label, other recipient's private input, or unavailable predictor enters deployment. Every nonzero channel edge and every output-bank vector belongs to the input's predicted class. Verify row sums exactly one within solver tolerance, nonnegative entries, fixed dimensions, fixed bank hash, and no raw-score fallback or unregistered metadata.
2. **What is disclosed.** Serialize one actual sampled output and all public code identity, decision and flags; deserialize into the three attacker views. Verify the scored vector equals the recipient vector byte for byte. Check that no hidden clean teacher output is appended. Expose channel matrices and public lookup tables to defense-aware readers. If a sampling seed, counter or random bit is transmitted or inferable, include it in the view; if it permits inversion, report that result.
3. **Expected utility identity.** On a tiny finite law, enumerate every `(t_r,z_r,y_r)` to recompute expected NLL and multiclass Brier; compare to optimizer coefficients. On Adult fitting rows, independently recompute the exact fitted-law means from saved sufficient statistics. Check the 1e-12 NLL clip and the common Brier convention. Verify both U0 and Ucal constraints for each task, separately. Do not call this held-out or population preservation.
4. **Actual sampled utility.** On `INNER_SELECTION`, generate the fixed one-draw release from the frozen counter plan. Score that release, not its conditional mean. Repeat only the preregistered mechanism-variance replicates, keeping people and model seeds paired; report Monte Carlo uncertainty without choosing a draw. A per-person stochastic loss can exceed the mean budget despite a feasible fitted law. Treat sampled and fitted-law outcomes separately.
5. **Finite-law objective.** Enumerate SEX joint counts on tiny laws to recompute local and coalition Bayes classification accuracy, class-only floor `F_v`, frozen-input upper reference `R_v`, and epigraph inequalities. When `R_v = F_v`, require `G_v <= F_v` instead of dividing by zero. The class-only floor must hold under the exact law for each view; a purported gain below it is an arithmetic/interface defect. The alternating LP receipt is a coordinate optimum at its stopping point, not a global certificate. A deterministic restricted solve needs its own status, gap or exhaustive tiny oracle; never call a heuristic exact.
6. **Probability versus identity.** If two output vectors are numerically equal but their transmitted code identities differ, the attacker sees the identity. The optimization sufficient statistics and simulated view must preserve that distinction. If the code identity is absent by contract, prove the public output makes it inferable or collapse indistinguishable states consistently. No ordinal use of token IDs.
7. **No disguised old method.** Compare the new Q matrices and one-draw deployed outputs against the old ACS finite mixture and hcal/lra frozen partitions. If Q is one-hot everywhere, or if a decoder changes but the transmitted fine token is unchanged, record a deterministic/decoder-only alias or ablation and withhold stochastic novelty. The old ACS Q is a frozen-code/decoder-law design; this candidate is a channel from frozen score bins to sampled public probability/code output under mean task-loss caps. The algebraic comparison must be written before a result claim.

## Fixed tiny-law suite

- **Feasible null:** SEX independent of frozen score bins; a feasible utility-preserving channel should not create recovery, and shuffled SEX should return null behavior within the fixed threshold.
- **Removable distinction:** bins differ in SEX but share useful label/confidence behavior; a many-to-one or randomizing channel can remove the distinction under the expected utility cap. The deterministic control must also be evaluated; if it ties, no randomness increment.
- **Complementary coalition clue:** neither local release suffices but the aligned pair improves recovery; pair reader must detect it, and the joint objective must count it.
- **No complementarity:** pair leakage equals the strongest local view; ignore-other readers must tie the full coalition reader, showing no artificial coalition gain.
- **Confidence needed:** decision-only passes accuracy but fails the fixed NLL/Brier cap. The class-only floor remains an information bound but is not a utility-eligible comparator.

Define each law independently and freeze counts, labels, output bank, roles, exact oracle result and expected assertion before running candidate algorithms. Prelock analytic premise checks are recorded separately from algorithm outcomes; never edit a law in response to a losing result.

## Real-data controls and stop rules

| Test | Required interpretation |
|---|---|
| Role guard | Trace loader calls and file reads. `HEAD_VALIDATION` labels and any old assessment person-level array may never be materialized. A post-load mask does not cure a forbidden read. Only approved row-specific exports are admissible. No fit if S2's guard fails. |
| Task and SEX label separation | SEX may enter privacy-channel fitting and new attacker fitting, never inference. Task labels may enter only permitted defense or calibration roles; no task label column is among predictors. |
| Shuffled SEX, constant reader | At least one null control per representative interface; a non-null selected recovery after shuffle is a technical attack-pipeline failure. |
| Planted local and coalition leaks | On a separate engineering copy, plant detectable SEX signals in each recipient and an XOR-style complementary pair. Require the full-view slate to recover them; plants never enter candidate selection. |
| Metadata/fallback leak | Read only code identity, class, flags, code length and fallback fields, then read the full view. A hidden fallback to original scores or unique-person token invalidates a privacy claim. No raw fallback is part of the Team A contract. |
| Strong ignore-other attack | Coalition AUC is at least the selected ignore-recipient attack under the registered common selection rule, subject to finite-reader sampling noise. Report the ignore arm separately. |
| Both references and complete criterion | Accuracy within 0.010, mean NLL excess at most 0.010 nats and Brier excess at most 0.005 against **both** U0 and Ucal, plus retention/per-class results. Passing one reference never stands in for both. Apply S1's frozen interval boundary rule, not an outcome-chosen threshold. |
| Local shift | Any local AUC increase over the locked strongest eligible control exceeding 0.010 fails the local protection clause, even if pair AUC improves. |
| Coalition benefit | Require at least 0.020 pair-AUC benefit over the strongest eligible matched control under the locked simultaneous interval rule. A point estimate alone may support pilot promotion, not PASS. |
| Independent and sequential controls | If an independent, deterministic or either sequential arm matches the candidate under the same bank and effort, attribute no joint or stochastic increment. Keep a useful simple method result if it still beats the rest. |
| Model and release variance | Keep people paired across source seeds. A fixed one-draw release does not imply protection against repeated queries. If repeated fresh sampling is part of the deployed query contract, freeze query count and add the aggregated reader before fits. |
| Resource/quality | A solver timeout, infeasible LP, unmatched work ceiling, weak failed attacker control, missing seed, missing baseline or skipped required view makes that comparison incomplete. Preserve every stopped attempt and receipt. |

**Kill this lane** if no protected channel is mean-utility feasible, nearly all outputs reveal original scores through fallback or unique code, complete-view recovery erases the gain, or a matched deterministic/sequential arm explains it. No threshold tuning after outcomes. The score-only lane makes no feature-sharing privacy claim.
