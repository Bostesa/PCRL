# Team A independent skeptical review

Status: **premise review of Team A's revised preregistration; no Adult fit reviewed**. The reviewer did not implement the channel or approve its results. The design is two independently sampled local channels on frozen Adult task scores, with a same-class output bank and no raw-score fallback. This review is independent of the implementer and is not S4's independent replay.

## Scientific scope and prior overlap

The information-changing operation is sampling a bank code from a probability law conditional on a private input score bin, then withholding the input bin and original score. Replacing only the decoder while disclosing the original bin would remove no information. The public output code ID must be part of the attack view, even if it has the same displayed probability as another code.

This is a **finite stochastic channel transfer to Adult confidence releases**, not a first finite-channel invention. The earlier ACS Q line already fitted a supervised private 32-state-to-17-token stochastic channel with an exact expected-token task cost, retained attack cuts, a public sampled token and a same-bank deterministic comparison; it did not establish a competitive advantage. Its data, 2018 residence task, 32-state input, unchanged public service, constraints and coalition side information differ from this Adult two-task score contract. Those differences motivate a new empirical comparison but do not create a new LP, quantization or randomization algorithm. The Adult dpc/qpc/lra/hcal score releases were deterministic token partitions and decoder variants. In particular, hcal's decoder-only result cannot support protection if the old token is still sent. [ACS method](https://github.com/Bostesa/PCRL/blob/2ce5d171f079f759eb755a21ab415765ea234479/results/pcrl_adaptive_release_v1/METHOD.md), [ACS decision](https://github.com/Bostesa/PCRL/blob/2ce5d171f079f759eb755a21ab415765ea234479/results/pcrl_adaptive_release_v1/RESEARCH_DECISION.md), [hcal decision](https://github.com/Bostesa/PCRL/blob/1baf5bbdaf59cfa6a664cae07d652a4712bdfdc5/results/pcrl_heldout_calibration_v1/RESEARCH_DECISION.md).

The novelty review must also credit established expected-distortion privacy mechanisms, randomized finite quantization, and sequential coalition accounting. These works use different utility and privacy definitions, so their theorems do not automatically certify this Adult AUC/NLL/Brier study: [Kalantari et al.](https://arxiv.org/abs/1708.05468), [Cai et al.](https://proceedings.mlr.press/v244/cai24a.html), [Taylor et al.](https://arxiv.org/abs/2601.21859). The failed CCM hard pointwise guard cannot be cited as infeasibility of this mean-loss design; it did show that transmitting raw scores on most inputs would defeat the intended compression. [CCM decision](https://github.com/Bostesa/PCRL/blob/d85f0a6f44415f2f9e334870f4e68504cd6b6080/results/pcrl_confidence_constrained_mechanism_v1/MECHANISM_DECISION.md).

## Conditions before a real-data fit

1. **Implementable locality.** For local independent sampling, recipient `i`'s sampler may read only its own frozen task score, public channel/bank parameters and its own randomness. The pair law is `Q1(z1|b1) Q2(z2|b2)` conditional on the private input bins. It is valid to optimize these two laws with a coalition objective; that does not give either sampler the other's score. A free joint kernel `Q(z1,z2|b1,b2)` is a different central-service contract and cannot silently be deployed as local samplers. If shared randomness is introduced, state whether the seed is recipient-visible, whether draws are correlated, and how repeated queries work. Include visible randomness and any trace it creates in attacks.
2. **Complete release.** Each local view includes the sampled code ID, bank probability vector, decision, and all transmitted flags/lengths/fallback metadata. The pair attack gets both aligned views, public channel/decoder tables and the allowed side information. The fine input bin, original teacher score and channel row must remain provider-private unless explicitly added to the interface and attacked. A public table alone does not disclose the private per-person input bin.
3. **Utility math and measurement.** With a fixed bank `q_z`, the empirical expected NLL on labeled fitting rows is `sum_i,z Q_i(z|b_i) [-log q_z(y_i)] / n`; expected Brier is the analogous weighted sum of `||q_z-e_y||²`. These are exact expectations under the fitted finite law for **one sampled vector**, assuming fixed label clipping and class order. `-log(sum_z Q_i(z|b_i) q_z(y_i))` scores an averaged probability never transmitted and is invalid here. Neither fitting expectation is a held-out or population guarantee. Evaluate actual sampled releases with a frozen seed/draw plan and include mechanism variance in paired-person uncertainty. Use both fixed U0 and Ucal references and the original 0.010/0.005 caps, plus accuracy and retention. The same-class bank must have at least one strict-argmax output for **every possible predicted class**, including source classes absent in fitting rows; no class-changing or raw-score fallback may be hidden.
4. **Privacy premise.** The ideal coalition can ignore one output, so its optimal recovery cannot be below that of the better recipient. Since disclosed decisions are functions of the released views, the decision pair gives an irreducible privacy floor. State any finite-law information objective as that objective. It does not prove an AUC improvement of 0.020 against the strongest eligible control, nor a local AUC guard of 0.010. Fresh nonlinear, code-aware, defense-aware and ignore-one-recipient attackers are decisive. An apparent gain that vanishes when code IDs are added is not a result.
5. **Solver scope.** The local-product pair law makes a coalition mutual-information objective generally nonconvex in the two channels together. Fixed-bank, fixed-predictor expected losses can be affine in one channel at a time, but a linear program over a free joint kernel would solve a different deployment problem. Report primal feasibility and objective replay; use the word "exact" only for an actually solved tiny law or a fixed convex subproblem with a bound. Heuristic best-response stopping is not an optimality certificate.
6. **Matched controls.** The same fine input discretization, same-class output bank, capacity, calibration, loss clipping, fitting data, attack slate and search budget must be available to task-only stochastic, deterministic task-only/privacy compression, independently private local channels and both sequential orders. Maximizing `H(Z|T)` alone is only a generic noise diagnostic: it need not minimize `I(T;Z)` because it also changes `H(Z)`. Register a serious privacy-blind stochastic rate-distortion or information-bottleneck control under the same utility caps, or mark superiority over task-only stochastic compression unevaluable. The source sequential code is a compatible score control, but its deterministic objective and older outputs need an explicit interface mapping; do not call an adaptation Taylor's solver. A deterministic channel from the same bank is the structural ablation for randomization. If it matches the stochastic arm, attribute the result to compression. If a non-joint or sequential arm matches, do not claim a joint design gain. Register exact baseline identities and aliases.
7. **Data and exposure.** No old assessment person-level array or HEAD_VALIDATION labels may be deserialized. S2 must verify a role-specific input path before any new fit; a loader that reads forbidden arrays then masks them is not allowed. The Adult rows have repeated research exposure, so all screens and finalist intervals remain exploratory even if the protocol is newly locked.

- **Resolved in the method spec and test source; numerical run pending:** shared L2's less-confident `.8` coarsening costs utility, while a same-class `.9` coarsening removes the explicit SEX clue and improves both losses for L2's deterministic task labels. The spec now states that bank choices change. The implementer added a supplementary test of this `.9` map under the actual 0.010 NLL and 0.005 Brier caps without altering S1's frozen law or earlier tests. The queue is closed, so this test is unrun. The toy supports removable information but cannot by itself attribute a gain to randomization.
- **Still to check before a fitted comparison:** `TASK-RD` is now specified as a task-only stochastic minimum-`I(T;Z)` control. Its solver status, compute matching and full output view must be part of the eventual unit registry. The alternating channel LP gives a coordinate result, not a joint global bound.
- **Static implementation check:** `finite_channel.py` builds pair probabilities from the local-product law and counts public bank IDs as separate symbols, including duplicate vectors. Its local and pair absolute-value epigraphs, mean-cost coefficients and class-edge restrictions are consistent with the spec on inspection. The implementer corrected normalization guards that had used NumPy's permissive default relative tolerance; the guards now request `rtol=0`. I have not run the numerical tests or an independent replay, so this is not a test-pass claim.
- **Tie break:** The method spec now predeclares a two-stage block update: minimize normalized maximum recovery, then at `a <= a_opt + 1e-9` minimize local Bayes recovery sum. This can move on a flat primary face. Its effect, solver status and equivalent control treatment need receipts; a coordinate tie break is still not a joint global certificate.

## Synthetic gates to run after the laws are locked

| Law | Required check | Invalid inference to avoid |
|---|---|---|
| Feasible null | Identity or a registered no-change channel satisfies caps; no forced privacy win. | Treating null improvement as solver success. |
| Removable score distinction | Same-class score detail carries SEX but is unnecessary for Y; a channel can hide it under mean caps. | Generalizing existence to Adult. |
| Complementary coalition clue | Each local view can be weak while the pair reveals SEX; pair objective and pair attack detect it. | Calling local protection coalition protection. |
| No complementarity | Pair recovery equals the stronger individual view. | Demanding gain below the better view. |
| Useful confidence | Class-only vectors violate at least one registered confidence cap while a multi-code bank can pass. | Treating decision-only release as an eligible utility control. |

Lock law probabilities, class orders, clipping, output banks, oracle scope and expected checks before running algorithms. A tiny deterministic enumeration is exact only over its enumerated deterministic class. A stochastic result needs an appropriate valid bound to be called globally optimal.

## Current review verdict

**Conditionally coherent as an exploratory score-track transfer.** The mechanism can change information if the input code and raw scores are truly withheld. It has no prior novelty claim and no empirical win yet. The key gates are safe label loading, an implementable local sampler, true sampled-output scoring, complete-view attackers, a matched deterministic ablation and strong sequential controls. Failure of any gate blocks a competitive claim for Team A; it does not imply all stochastic raw-input representation methods fail.
