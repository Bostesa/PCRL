## 1. Input, bank and release

For each pinned teacher seed and recipient r, the provider computes the frozen U0 score vector from the permitted 83-column input. It computes Ucal with the fixed hcal H-GLOBAL-TEMP rule for the utility reference only. The **input bin** `T_r` is the inherited qpc fine partition assignment of that recipient's **U0 score**, with at most 32 bins per predicted class for income and 128 per predicted class for six-class occupation. Public policy JSON metadata for screen seeds 0/1 report actual fine-cell totals of 64 income and 641 occupation each; these counts still require S2 role-only adapter parity before use. The 64/768 synthetic LP smoke deliberately exercised the larger occupation capacity, not an asserted observed Adult count. These fine partitions use score-only KL/Bregman k-means on OSF_DEFENSE_FIT; source IDs and fingerprints must be admitted before use. No task label or SEX is an inference input. The input bin is private and is **never** transmitted.

The source adapter loads the admitted per-seed `fine.json` through `qpc.partition.load_fine` and applies `dpc.partition.assign_fine(U0_score, argmax(U0_score), fine)` separately to each S2-admitted role. Assignment uses KL to the stored smoothed centroids within the predicted class, with the lowest cell index winning an exact tie and an absent fitting class using its reserved cell. It must not read the inherited all-role `assign.npz`. Its role-specific arrays and hashes are private. A pure array-level fitter refuses a missing fine partition, missing U0/Ucal reference, reordered class vocabulary or failed policy binding; a role-name argument alone is not data custody.

The source and channel runtimes are separately pinned because the admitted frozen U0 source uses Torch. It validates fine/policy/decoder hashes, recomputes role-only fine tokens, and writes private role-only token artifacts plus fixed public bank tables. Its receipt binds input/output SHA-256, exact row/order/group identity, class/argmax and embedded-fine fingerprints. `Q_r(z|t)` is a row-stochastic matrix. A row supports only bank IDs whose predicted class equals the class of input bin `t`. The two channel matrices are trained jointly from the aligned fitting law but are **locally executed**:

Before a fitted Q becomes a scored or deployable artifact, copy and validate it with exact zero off-class support. For each row whose NumPy float64 sum differs from 1 by more than `1e-15`, divide its permitted entries by that sum, then require the resulting maximum row-sum residual to be at most `1e-15`. The package loader hashes the stored Q and refuses any row residual above `1e-15`; it never silently renormalizes a deployed model. In particular, any positive off-class entry is invalid even if below a numerical feasibility tolerance. The common inverse-CDF primitive must never redirect a floating CDF tail to global bank ID `Z−1`; its tail guard selects the last **strictly positive same-class** support ID and records tail counts/max residual privately. A forced-tail test and bitwise offline/deployment sampling parity are gates for structural decision preservation. This proposed numeric implementation remains subject to S3 synthetic GREEN and A4/S4 review before Adult use.

An input fine bin with zero defense-fit mass has no fitted privacy or utility coefficient. Before storing any candidate or control channel, its entire Q row is set by the same fixed deployment rule: probability one on the lowest-index bank ID of that bin's predicted class. This makes unseen-bin behavior explicit without fitting from screening outcomes or falling back to the original score. Report how often such bins are reached on admitted evaluation roles.

## 2. Fitted finite-law optimization

On OSF_DEFENSE_FIT only, construct the aligned empirical count law of binary SEX and `(T_1,T_2)`, plus task-label counts per input bin. The **Team A fitting/attack loaders** must never open or materialize old assessment or HEAD_VALIDATION person-level labels. Candidate fitting may use SEX and both task labels from the allowed defense-fit role; no such labels enter deployment. S2 must provide role-only input artifacts containing only allowed rows and labels. The continuation permits one isolated S2 custodian exporter to deserialize mixed-role storage mechanically under its recorded deviation and independent role audit; that exception is not a Team A scientific loading path or permission to use forbidden arrays.

For each view `v in {1,2,12}`, let `G_v(Q1,Q2)` be the exact Bayes SEX classification accuracy under this fitted finite law, using respectively `Z1`, `Z2` and `(Z1,Z2)`. For binary SEX, `G_v = [1 + sum_z |P(S=1,z)-P(S=0,z)|]/2`. The local and pair output laws follow `Q1(z1|t1) Q2(z2|t2)` conditional on the two input bins. `F_v` is the fitted class-only decision floor for that same view. `R_v` is the fitted Bayes accuracy when the corresponding private input bin(s) are fully observed; `F_v <= R_v` by inclusion. If a denominator is zero, use an exact floor constraint rather than dividing by zero.

Fit **one** protected stochastic design by minimizing `a >= 0` subject to **all three** constraints

`G_v <= F_v + a (R_v - F_v)` for `v = 1,2,12`.

This minimax normalization prevents a coalition improvement bought by shifting leakage to one recipient. It is a finite-law Bayes-accuracy objective, not a bound on test AUC, mutual information, other sensitive attributes or the population. The class-only floor is structural for this fitted view; confidence utility of class-only must be measured separately and it is never assumed eligible.

For each task r and each frozen reference `b in {U0,Ucal}`, constrain fitted **mean observed-label** NLL excess at or below 0.010 nats and mean multiclass Brier excess at or below 0.005. In the finite-law solver's single absolute cap per task/metric, this conjunction is `cap_NLL(r)=min(mean_NLL_U0(r),mean_NLL_Ucal(r))+0.010` and `cap_Brier(r)=min(mean_Brier_U0(r),mean_Brier_Ucal(r))+0.005`, with both references computed on **identical** allowed fitting people, class order, clipping and weights. Report the two reference excesses separately on each screening role. Fixed bank vectors make both expected costs linear in each Q. Use natural log, probability clipping at `1e-12`, multiclass Brier `sum_k(q_k-1{k=y})^2`, and the campaign's exact boundary convention. These are fitted-law expectations under one sampled output; they are **not** a held-out or per-person guarantee. Structural class preservation fixes the released decision to the teacher's class for this score-only method; check tie semantics and strict bank argmax exactly.

The joint problem is nonconvex because `P(z1,z2)` contains products of Q1 and Q2. With one matrix fixed, the three Bayes-accuracy epigraphs and all mean costs form an LP. Use SciPy HiGHS `linprog` for stochastic block updates. The two stochastic starts proposed for the campaign lock are the matched-bank TASK-DET pair and TASK-RD pair, both fitted before the protected channel and both independently checked against the mean caps; if one is infeasible, record that failure and do not improvise a replacement. A valid, independently replayed start that violates a mean cap is a **completed scientific infeasibility**, so the other completed feasible start may still be selected. An invalid/missing start, solver/numerical/replay failure, timeout or CPU cutoff makes the required two-start arm **incomplete**: suppress its selected Q and keep any incumbent diagnostic only. Fix the sweep order, at most five full alternating sweeps per start, and a total per-arm CPU ceiling after S3's smoke receipt. The two starts share that **outer process-CPU deadline**; HiGHS per-block wall-clock limits are additional safeguards, not the arm's CPU accounting. Verify primal residuals independently. Each LP block update has a **predeclared lexicographic tie break**: first minimize primary `a`; then hold `a <= a_opt + 1e-9` with all original constraints and minimize `G_1 + G_2`. This permits movement along a flat pair-recovery face without changing the primary criterion. Among feasible completed stochastic starts, choose the lowest **replayed** `a`; ties within `1e-9` use the lowest replayed `G_1+G_2`, then the fixed order TASK-DET before TASK-RD. Save all starts and do not select by seed or sampled draw. Report each start, final objective and any unresolved local optimum. Do not call a stationary point a global optimum. Solver failures are recorded, not silently replaced by a different objective. A fitted-law objective advantage is not a fresh-attack advantage.

For the Adult **JOINT-DET structural ablation**, restrict every row of Q to one hot and use a prelocked same-bank deterministic greedy row-reassignment search. Its five starts, in fixed order, are TASK-DET, LOCAL-STOCH rounded, SEQ-12 rounded, SEQ-21 rounded and JOINT-STOCH rounded; exact duplicates are recorded as aliases. Each rounded start is repaired for the two task mean caps using **defense-fit task data only**, before privacy search; no sensitive or INNER_SELECTION result chooses the repair. Permit at most five full greedy sweeps/start and the same total process-CPU ceiling as JOINT-STOCH. Every candidate reassignment must preserve class and both utility caps. The fitted-law priority tuple is `(a, G_pair, G_1+G_2, summed task NLL+Brier, output token ID)`.

To give the deterministic control the same ability to move on a flat primary face as the stochastic LP, use a **pre-outcome anchored lexicographic rule** for each start. The absolute numeric face tolerance is `ε=1e-10`; `δ=1e-9` labels material versus small changes in the receipt and **does not gate move acceptance**. Retain the minimum achieved `a` as the primary anchor; on its current flat face retain the best `G_pair` anchor; on the current pair face retain the best summed-local anchor; on the current local face retain the best task-loss anchor. For each candidate, scan the four numeric components in priority order against their current face anchors. A component increase above its anchor by more than `ε` rejects the candidate unless an earlier component already improved by more than `ε`. The first component that decreases by more than `ε` accepts the candidate and resets lower-priority face anchors; if all four components are within `ε` of their anchors, a lower output ID accepts it. Retain anchor minima across accepted tolerance ties, so repeated positive tie errors cannot accumulate. Among qualifying same-class moves for one input bin choose the exactly smallest tuple, breaking exact ties by lowest output ID. Reject previously visited full `(Q_1,Q_2)` one-hot assignments, and record each move's before/after tuple, first improving component, size class and face reset. Replay fitted accuracy and utility after every sweep against the incremental values with absolute residual at most `1e-10` on frozen synthetic checks; if this fails, revise numerical tolerance only in a dated pre-Adult amendment based on synthetic precision evidence. Compare the final tuple with every start. Keep the best feasible completed incumbent across all starts; an interrupted required start makes the ablation incomplete. The tiny frozen laws may additionally use a one-hot MILP or exhaustive enumeration as correctness oracles. The Adult search is a heuristic, with no global deterministic optimality claim; a stochastic gain over it is evidence against the **tested control**, not proof that randomness is necessary. If the heuristic produces only a weak incumbent or times out before a serious matched search, mark randomness attribution unresolved.

## 4. Exact toy laws, checks and kill conditions

S1's `results/pcrl_method_portfolio_v1/shared/SYNTHETIC_LAWS.json` is the **authoritative frozen** five-law set, L1–L5.
