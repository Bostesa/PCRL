# Private evaluator arrays and independent replay contract — prefit draft

All paths below are relative to `shared/.private/evaluation_v1/` and remain private. This is a prospective schema; S1 must bind its hash in the effective campaign lock before an Adult fit. A writer creates one immutable package per `(arm_id, model_seed, role, draw_index)`, with SHA256 for every file in a private `PACKAGE_RECEIPT.json`. Public reports contain only hashes and aggregates. Old assessment rows never enter a package.

## Identity and release

`release.npz` has ordered `row_id:int64[n]`, `unit:int64[n]`, `prob_1:float64[n,2]`, `prob_2:float64[n,6]`, `decision_1:int64[n]`, `decision_2:int64[n]`. It also has a field array for every transmitted recipient field, named by a stable field ID in `wire.json`; `wire.json` lists each field's name, role, wire dtype, shape, whether person-varying, and numeric attack encoding. String and constant metadata values are explicit literal entries in `wire.json` even when they add no numeric attack column; the field's numeric binding is `null` only when constant for every person. It lists local r1/r2 and aligned pair field order, complete-view matrix SHA, S2 admitted role-file SHA and row-unit pair SHA. Categorical IDs are saved as integer fields and encoded one-hot in the attack matrix; D ten-bit IDs additionally have ten explicit bit columns. Masks, flags, lengths and fallback values are fields even when constant. No provider-private per-person score can be added to the defense-aware matrix unless actually released. A score output uses the **sampled** code/probability/decision, never an expectation over draws. All transmitted head outputs depend on that protected code/feature.

`readers.npz` has one float64 positive-class prediction vector for each frozen fitted reader, separately for r1, r2 and pair, with stable keys `{view}__{reader_id}`; the sidecar `readers.json` enumerates the fixed reader order, model artifact relative path and SHA, ATTACK_TRAIN ordered row/group SHA, ATTACK_TUNE ordered row/group SHA, orientation and validation winner, view matrix and transformation SHA, and any zero-fit ignore-recipient aliases. For D specialist cell readers the sidecar binds α and unseen-cell fallback identity. Positive/reverse are zero-fit score aliases, not two training jobs. The pair aliases refer to exact local reader vectors on identical rows. `ATTACK_FIT_NEW` packages contain the complete actual draw0 release wire arrays, frozen ATTACK_TRAIN/TUNE view matrices and TUNE predictions/validation metadata; `INNER_SELECTION` packages contain draw0 release/predictions for every arm, and A draws1–7 predictions from the same frozen draw0 readers. `CALIBRATION_HELDOUT` only has release/calibration arrays required by its arm; A has an inherited hcal bank alias and no new scalar fit.

Each fitted scikit-learn reader is saved write-once as a private `joblib` artifact with NumPy 2.4.4 and scikit-learn 1.8.0 pinned; cell readers save full smoothed count/lookup tables and fallback rule in private JSON/NPZ. The package receipt hashes every artifact, release view matrix, ATT fit/tune membership and frozen prediction. S4 loads only these trusted private artifacts in its isolated replay, independently reconstructs ATT/INNER matrices from `wire.json` and public parameters, checks saved-model predictions against saved vectors, and reruns finalist readers from the same ATTACK_TRAIN rows to inspect fit-row identity and training determinism. A model SHA alone or unverified prediction array is insufficient. Reader training code/source SHA and numerical-thread settings are in `readers.json`; S4 does not import runner scoring or selection functions.

The private package binds source model/policy/bank identities, 83-column schema hash, role export file hashes, any private checkpoint/calibrator SHA, S1 effective lock SHA, reader/view builder source SHA, and Team A's stream-seed **hash**. The private seed bytes live in separate versioned custody and never in release files. The writer must refuse a missing or mismatched bind. S4 reads admitted role-only labels and U0/Ucal reference arrays independently, joins exact ordered `(row_id,unit)` and recomputes endpoints without importing candidate or shared scorer implementation.

## Registered margin family and inference

For each candidate/track/control set, use one vector with names in this fixed order:

1. For task `income`, then `occupation`; for reference `U0`, then `Ucal`; margins `ACC = accuracy(candidate)-accuracy(reference)+0.010`, `NLL = 0.010-(NLL(candidate)-NLL(reference))`, `BRIER = 0.005-(Brier(candidate)-Brier(reference))`. This is 12 utility margins.
2. For **every** predeclared potentially eligible matched control in lock order, margins `R1_LOCAL = 0.010-(AUC(candidate,r1)-AUC(control,r1))`, `R2_LOCAL` analogously, `PAIR_BENEFIT = AUC(control,pair)-AUC(candidate,pair)-0.020`. This is three margins per control, including controls later found ineligible; report their applicability and eligibility separately. Including all potentially eligible controls covers observed strongest-control selection without reselecting a control inside bootstrap.

Primary conditional development intervals use 2,048 PCG64DXSM bootstrap replicates and the private 32-byte seed whose public SHA is `d1c3d94b05e449b93ed2ae0b2d705fab36ad5a58516b3b8699de9aceb511b475`, NumPy 2.4.4. Sample the 2,234 INNER groups with replacement; use the same sampled group sequence for every arm, control, reference and paired model seed. A group with two rows contributes both rows each time it is sampled. Compute each per-seed margin on its paired rows, then average over seeds; seeds are not independent populations. Recompute every fixed-reader positive/reverse AUC envelope inside each replicate, including exact ignore-recipient aliases. Critical value is the 0.95 `method="higher"` quantile of the maximum **absolute** studentized deviation over the entire registered candidate margin vector; studentization denominator floor is 1e-12. If `max_b |bootstrap_margin_b − point_margin| <= 1e-12`, set its numerical SE and interval width to zero and mark `NUMERICALLY_CONSTANT`; this is numerical equality within tolerance, never a structural proof. Otherwise use max(SE,1e-12) for studentization and interval width. PASS if lower margin ≥0; VIOLATION if upper <0; otherwise UNRESOLVED.

For A, draw0 is the actual one-shot point release and the only release used in the primary group bootstrap. Draws0–7 are additionally scored as eight actual one-shot realizations with the **same frozen draw0 readers**; show every per-draw utility/local/coalition margin and its descriptive min/max/mean. There is no best-draw selection, no centered-draw correction in the primary interval, no repeated-query guarantee, and no attacker-refit variance in either result. A seed's offline canonical-row PRNG stream is a reproducibility device; deployment uses independent internal randomness once and does not transmit the seed, uniform, row ID or role ID.

The reported intervals are conditional on fitted models and selected portfolio candidates on reused development rows. They are not population guarantees or independent confirmation.
