# Team A staged input admission checks (draft)

This is a review checklist for S1 and S4. It does not grant Team A fit permission.
The ten source-bank jobs are preprocessing units under S3's machine-wide queue.

## Score banks, before any A fit or task capsule

1. The effective committed campaign lock must permit `families.A.preprocessing_admission=ALLOWED` while keeping `families.A.fit_admission=DENIED`. It must bind the ten exact IDs in `A_SCORE_BANK_PREPROCESS_SPEC_DRAFT.json`, the reviewed adapter SHA, admitted data manifest SHA, hcal `MODEL_MANIFEST.json` and `SOURCE_ADMISSION.json` SHAs, lra `MODEL_MANIFEST.json` SHA, and the seed-specific U checkpoint SHAs. The public cache-root field is `../../../PCRL_eval_cache_private` relative to the coordinator worktree; S3 resolves it for a private argv. The B fit scope and completed B outputs remain separate.
2. S3 must admit only `stage=a_score_bank_preprocess`, `family=team=SHARED`, `data_access=A_ROLE_ONLY_REFERENCES_PREPROCESS`, `arm=arm_id=A_SCORE_BANK_PREPROCESS`, exact release/seed unit ID, script SHA, argv and write-once output. Each unit has maximum wall time 300 seconds, reserved CPU 300 seconds and maximum RSS 1.5 GiB; ten units reserve 3,000 CPU seconds (0.833 hours). Its unit receipt must show success and account for CPU, memory and the global semaphore. The runner checks the running child, process group, lock seal, source hashes and role-only `references_s{seed}` before emitting files. No FIT task or SEX label, features, old assessment, HEAD_VALIDATION, all-role assignment, or release archive is an input.
3. For each of five release keys and two seeds, S4 independently compares the producer receipt with its S3 receipt, current source lock, admitted role reference hashes and the six private files (two banks, three role cell/token arrays, receipt). Check exact ordered row/group pairing; recompute fine cells from role-only U0 probabilities and decisions using the pinned fine partition; recompute old coarse tokens from the pinned policy; verify `fine_to_hcal_token[cell]`, class/argmax, strict class coverage, and the bank table/decoder or D0 policy prototypes. Check full source binding and file SHAs. S4 must not import the producer's assignment/scoring functions or open all-role/assessment arrays. A producer status `ROLE_ONLY_BANK_ADMITTED` alone is not independent admission.
4. The per-seed S4 score-bank report must bind all five S3 unit IDs, queue receipts, bank admission receipts, five-file output hash maps and independent parity checks. It also exposes the T* fields required by the deployment frontend: schema `pcrl-s4-a-score-bank-verification-v1`, `status=PASS`, `role_cell_token_bank_parity=PASS`, exact T* `bank_admission_receipt_sha256` and `source_binding_sha256`. Its full report SHA is pinned by the later A fit lock. Report status stays pending until independent role-value replay; the report is not an Adult privacy/utility result.

## Recipient-only task capsules, after score-bank parity

5. A separate staged lock and S3 queue admission must list four exact `S2-A-TASK-CAPSULE-S{seed}-R{recipient}` units with `stage=a_task_capsule_preprocess`, `family=team=SHARED`, and `data_access=A_FIT_OWN_TASK_AND_REFERENCES_CAPSULE`. Bind the source-bank S4 report SHA by seed and exact reviewed producer/loader SHAs. A fitting remains denied during capsule preparation.
6. The S2 producer's fixed call chain may transiently read the combined admitted FIT `references_s{seed}` file and one own FIT task-label export. Its broad `defense_fit` label procedure technically permits other labels, so verify the actual calls and logs; do not claim OS isolation or a narrower SafeRoleStore procedure. The output must be one recipient's write-once 11-member NPZ with only `row_id`, `unit`, `cell`, `task_label`, `U0`, `Ucal`, `bank`, `input_class`, `fine_to_hcal_token`, `token_class`, `source_binding_sha256`, plus a hash-bound receipt. Reject SEX, partner task/score/cell or extra members before value loading.
7. S4 independently checks the capsule's exact FIT row/group order, own task-label equality, U0/Ucal equality, cell/bank/class/map and T* binding, file/member hashes, and absence of partner/SEX fields. The task-only fit worker receives the one-recipient capsule through the pure loader; it imports neither SafeRoleStore nor the producer. Protected channel workers require a later distinct A fit seal. ATTACK_FIT_NEW and INNER_SELECTION access for releases/attacks occurs only under that later seal and the frozen evaluation contract.

Any failed, absent or incomplete unit remains recorded and blocks only the affected A result. These are development inputs on reused Adult roles; independent confirmation is not implied.
