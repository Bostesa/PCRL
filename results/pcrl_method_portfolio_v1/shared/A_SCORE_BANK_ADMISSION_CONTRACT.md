# Team A inherited score-bank admission — prefit contract

`admit_a_score_bank.py` is a custodian preprocessing unit, not a new defense fit. Run its reviewed SHA with the local `.venv` Python 3.13.7/NumPy 2.4.2 after S1's effective preprocessing seal and within S3's global queue, once per source seed and release. Its CLI takes the private cache root, seed, `--release tstar|pstar|lra_seq21|hcal_local_d0|hcal_seq12_d0`, exact campaign-lock SHA and queue root; no mixed-role/all-row NPZ is an input. S4 independently admits each output after its queued run. T* is the frozen task-only bank for Team A; P* is the old JOINT .1 H-CLASS incumbent. The three D0 maps use their original smoothed token prototypes and no decoder. Historical controls receive fresh score attacks, never an alias of an A arm. Old local and sequential D0 releases are contextual controls; they are not capacity/calibration-matched stochastic-channel controls or a reproduction of Taylor et al.'s setting.

The adapter requires `families.A.preprocessing_admission=ALLOWED` while `families.A.fit_admission=DENIED`, the exact unit ID in `admitted_a_score_bank_unit_ids`, the current committed local seal, and a running S3 child with matching script path, lock SHA, seed, release, process group and `A_ROLE_ONLY_REFERENCES_PREPROCESS` data scope. The effective lock binds the exact hcal model-manifest SHA and U checkpoint SHA for the selected seed under `source_model_admission`. A globally effective lock alone does not authorize A role processing. A later dated seal admits A defense fits only after S4 verifies the emitted cells, tokens and banks.

The adapter reads `SafeRoleStore.references_s{k}` for `OSF_DEFENSE_FIT`, `ATTACK_FIT_NEW`, `INNER_SELECTION`, with exact ordered row/group pairs. It reads registered per-seed `fine.json` and policy JSON, plus hcal decoder JSON for T*/P*, only after checking full file SHA and source binding. For lra D0 it checks the pinned lra policy SHA and requires the manifest's decoder identity to be null. For hcal D0 local/SEQ-12 it checks `SOURCE_ADMISSION.json` policy SHAs. It recomputes **fine cell** `cell_r=assign_fine(U0_r,d_r,fine_r)` and inherited coarse `token_r=policy.cell_token[cell_r]`; independently checks `qpc.release.encode` parity. The T* fine cell is A's new channel input. Historical releases transmit the coarse code and their pinned decoded vector. Source `assign.npz`, teacher.npz, release.npz, old assessment arrays and SEX labels are never opened by this adapter.

Each seed/release private write-once `bank_r{1,2}.npz` has exact members `probability:[Z,K] float64`, `token_class:[Z] int64`, `token_id:[Z] int64`, `input_class:[F] int64`, `fine_to_hcal_token:[F] int64`. Each private `tokens_{ROLE}.npz` has `row_id`, `unit`, `cell_1`, `cell_2`, `token_1`, `token_2`, all int64. The private receipt binds admitted reference file SHA/pair hashes, JSON hashes, the actual U0 checkpoint file SHA, teacher/schema binding, fine and token array hashes, bank file hashes, policy fingerprint, decoder identity, interpreter versions and S1 lock SHA. Strict bank argmax and class coverage are gates; no new fallback bank entry is synthesized.

`source_binding_sha256` is SHA-256 of UTF-8 JSON of the receipt's `source_binding` object, serialized with `sort_keys=True`, `separators=(",", ":")`, `ensure_ascii=True`, and `allow_nan=False` (no trailing newline). The object fixes schema `pcrl-portfolio-a-source-binding-v1`, release ID, integer model seed, full teacher-model SHA, ordered 83-name newline-join SHA, full fine/policy/decoder file SHAs, decoder internal SHA and policy fingerprint. Its `recipients.r1` and `.r2` each fix class order `[0,...,K-1]`, fine fingerprint and `sha_arr` identities of `input_class`, `fine_to_hcal_token`, calibrated bank probabilities, and token class. `sha_arr` hashes dtype, shape, then contiguous bytes as defined by `safe_data_guard.py`. The frontend and one-shot sampler must independently compare this binding with the admitted receipt and deployed Q/package before accepting `input_cell`; an old hcal coarse token is never a substitute.

After independent admission, S2's separately queued task capsule producer writes one private 11-member FIT artifact per recipient: row/group, fine cell, own task label, own U0/Ucal, own bank/classes/map and source binding. The producer uses the broad `defense_fit` label procedure but its audited call chain requests only the recipient's task label plus combined role-only references; the task-only fit worker receives only its one-recipient capsule through a pure loader that does not import `SafeRoleStore`. Protected channel workers may use FIT SEX through `SafeRoleStore` after a later A fit seal. Team A's pure channel solver and sampler run under system Python 3.14.3/NumPy 2.4.4. The runtime for a new 83-column input verifies the same U0 teacher, schema and policy in `.venv`, computes each recipient's fine cell, then invokes the system one-shot sampler **separately for each recipient** with only its own cell and bound public Q/bank. It never appends U0/Ucal clean scores to the output.
