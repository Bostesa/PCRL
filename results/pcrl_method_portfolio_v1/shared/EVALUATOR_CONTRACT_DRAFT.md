# S2 evaluator contract draft — requires S1/S4 freeze before Adult fits

This is an implementation draft, not an effective science lock. The public campaign lock binds the final IDs, library versions, hashes, units and control thresholds.

## Inputs and roles

All joins require identical ordered `(row_id, unit)` pairs for recipient 1, recipient 2, task labels, SEX labels, frozen references and every saved view. IDs never enter a transmitted view unless the declared release itself transmits them. Scientific code uses `SafeRoleStore` only. Training uses FIT labels, scalar calibration uses CALIBRATION_HELDOUT task labels, attack fitting/tuning uses ATTACK_FIT_NEW SEX, and reporting uses INNER_SELECTION task/SEX labels. No HEAD_VALIDATION or old assessment person-level access.

Proposed attack split: rank ATTACK_FIT_NEW's 4,061 unique group IDs by `SHA256(UTF8("pcrl-method-portfolio-v1|attack-tune|20261008|" + decimal_group_id))`, ties by integer ID. First 1,015 groups are TUNE; remaining 3,046 groups are ATTACK_TRAIN. Use every row of each group; no split group. Freeze this split before label-based class checks or fits. If either side has one SEX class, stop and amend before outcomes, never silently use INNER for tuning.

## Complete views

SCORE recipient view: actual sampled public probability vector, decision, code identity if transmitted, and all flags, lengths, fallback and sampling metadata. The original source score/input bin/fine token is excluded unless actually transmitted. FEATURE recipient view: actual selected raw values or emitted latent/code, head probability and decision computed from that released feature, plus all transmitted metadata. Code IDs are categorical; for ten-bit codes also expose bit decomposition to attack readers, and pair-code interaction cells to coalition readers. The pair view is the aligned union. Public maps and tables may transform the observed view; they do not confer private provider inputs. Ignore-recipient pair readers use exact local predictions as aliases only if their fit role, preprocessing, seed and view fingerprints match.

## Calibration and utility

For B/C/D feature arms, each arm/seed/task fits one H-GLOBAL-TEMP scalar on CALIBRATION_HELDOUT task labels, no grid: `q_alpha = softmax(alpha * log(normalize(max(p,1e-12))))`, alpha in `[0.25,4]`, NLL-minimizing bounded derivative bisection, identity path returns original `p` exactly. Matched feature controls use the same rule. **A score-track exception:** its fixed finite output bank already consists of hcal FINE-TASK H-GLOBAL-TEMP-calibrated vectors. Every A candidate/control shares that exact frozen bank and inherited calibration identity, counted as an explicit alias. No post-channel temperature is fitted, because that would change the emitted bank and invalidate its locked finite-law utility coefficients. A scores actual sampled bank outputs and reports exact fitted-law expectation separately. U0 is frozen original continuous U; Ucal is its frozen hcal H-GLOBAL-TEMP transform, by source seed. Report candidates against both; do not refit Ucal.

For each task on INNER, accuracy is `mean(argmax(q)==y)` (NumPy first-index tie), NLL is `mean(-log(clip(q[y],1e-12,1)))` in natural nats, and multiclass Brier is `mean(sum_j(q_j-1[y=j])**2)` with **no class averaging or half factor**. The constant predictor is fitted on FIT task labels only. Report gain over constant, per-class recall and retention; an absent class stays unestimable. Inclusive gates: accuracy difference >= -0.010; NLL excess <= 0.010; Brier excess <= 0.005 against both U0 and Ucal, both tasks.

## Fresh readers and primary recovery

The proposed fixed trained bank on each r1/r2/pair view is `LR_C1` (standardized logistic, C=1, lbfgs, 500 iterations), `MLP_64x32` (standardized ReLU 64×32, alpha 1e-4, Adam, 300 iterations, no early stopping, seed bound), and `HGB_15x200` (15 leaves, 200 boosting iterations, rate 0.05, no early stopping). `DA_MLP_64x32` is required when a public defense-aware transformation exists and must be computed solely from observed release plus public parameters. `CELL_A1` is required for A's categorical score tokens, with smoothed exact local or pair cell counts; the pair cell key contains both released IDs and transmitted flags. D instead has three prelocked direct categorical CellReaders at α={0.5,1,5} with a structured pair-marginal unseen-cell fallback, attached as frozen specialist predictions through `add_external_fixed_readers` and charged as three fits/view. D's ten code bits and categorical one-hot must be columns in the main complete x; `CODE_BIT_LR_C1` is an optional diagnostic, not a required extra fit when those columns are present. `META_LR_C1` is required when masks, flags, fallback, lengths or other metadata vary across people. Constant calibration/model identifiers are present in the view declaration but need no metadata-only fit. Required readers are listed per arm/view before fits; an absent required input is an error, never a silent skip. Each fixed reader has one fit per arm/seed/view, with positive and reversed predictions as two zero-fit aliases. Source hcal's full LR×5, MLP×4, HGB×4, DA_LR/DA_MLP slate is stronger; any smaller new slate needs matched-strength rationale and an explicit applicable source-bank check. No post-INNER reader addition.

Fit each frozen reader on ATTACK_TRAIN only. Use TUNE to choose any predeclared tuning option, binary orientation and a separate validation-selected reader. Primary recovery for every release/view on INNER is the predeclared fixed-slate envelope `max_reader max(AUC(p_reader), 1-AUC(p_reader))`. Complements are zero-fit aliases, not extra trained models. This is a conservative predeclared **test-label functional**, not a single deployable reader selected without INNER labels; only the separate TUNE winner is deployable. Recompute the envelope in every paired bootstrap replicate. The pair slate includes zero-fit ignore-one-recipient aliases of all local readers, requiring exact ordered ATT/INNER row/group identities and attack split. Report every reader, validation-selected winner, local views, pair and aliases. First compute each control's fixed-slate recovery; then choose the eligible control with lowest pair recovery under the prefit rule. Do not use INNER to choose hyperparameters/orientation.

The complete-view builder for every arm must supply an exact ordered wire-field list and a nonoverlapping numeric-column binding that covers every field and matrix column. The common evaluator checks these declarations match between ATT and INNER. S4 independently compares each team's builder to its actual deployed release; a team's declaration alone is not proof of a complete view. Publicly derived DA matrices may decode or transform observed code/probability and public tables, but cannot add private provider scores or other-party private inputs.

For Team A competitive comparison, hcal's historical bank is materially broader: its pinned FINAL slate has LR×5, MLP×4, HGB×4, DA_LR and DA_MLP, plus CC and CCpair readers at α={0.5,1,5} and both ignore-recipient banks (`results/pcrl_heldout_calibration_v1/PROTOCOL.md` §5). It used historical AUDIT_FIT including what became CALIBRATION_HELDOUT and selected readers on INNER, so it cannot be silently aliased to the new ATTACK_FIT_NEW fit/tune protocol or the new fixed max-AUC functional. Historical AUC is descriptive. A competitive claim needs old score controls re-expressed under the new complete view and same fresh attack protocol; a smaller new slate may understate absolute recovery, so S4 must review its strength, including a feasible source-slate sensitivity run or an explicit unresolved limitation if budget prevents one.

Engineering control gates are prefit: a constant/null score must give exactly 0.5 AUC in both aliases; shuffled ATT SEX labels (group-preserving fixed permutation, separate control fit) must have INNER complete-view envelope at most 0.60; a separate planted-leak engineering copy with true SEX included as an explicitly transmitted scalar must reach AUC at least 0.99 for `LR_C1`; categorical code/metadata fields must be present and used by their required readers. Failure blocks the affected attack endpoint pending a dated correction, without changing earlier outputs. Shuffled and planted copies are engineering controls, never candidate releases. Each extra reader fit is charged to the queue.

Control utility eligibility is against frozen U0 and Ucal, independent of candidates. A control local-AUC cap, if retained, is against the named frozen unprotected reference: SCORE_REF_U = original U0 complete score view (public Ucal transform available); FEATURE_REF_RAW83_U = exact 83 selected raw values plus Ucal task probability/decision from the frozen U model. This common feature reference is a fixed local-cap anchor only, **not** an architecture/capacity-matched competitive comparator. Candidate local worsening is measured against the selected eligible matched control, <= 0.010 on each recipient. Pair benefit is that control minus candidate, >= 0.020. No candidate-dependent control eligibility.

## Inference and randomness

For each candidate's predeclared gate family, resample exact-record groups jointly across arms and model seeds, preserving paired people. Recompute the max over frozen reader predictions **inside every bootstrap replicate**; do not bootstrap only the observed winner. Then form the registered seed-mean endpoint. Use a simultaneous family/quantile frozen by S1 before fit; report intervals conditional on fitted models and portfolio selection. Upper-cap PASS requires upper <= cap, VIOLATION lower > cap; lower-benefit PASS lower >= target, VIOLATION upper < target. A crossing interval is UNRESOLVED, while point-feasible screens may be promoted under the frozen rule.

Team A's default service is one-shot release, no repeated-query guarantee. Offline reproducible draw0 is the actual release fitted/scored; seven additional predeclared INNER draws report actual-draw point spread with frozen draw0 attackers and no best-draw selection. The primary 2,048-replicate paired group bootstrap resamples draw0 only, which already includes realized per-person channel noise; the seven extra draws are **not** added again to its interval. This remains conditional fitted-model development inference and omits attacker-refit variance. Offline seeds are private versioned custody, not transmitted; new-input deployment draws once from internal randomness. The exact PRNG and stream identifiers must be bound in S1's lock.
