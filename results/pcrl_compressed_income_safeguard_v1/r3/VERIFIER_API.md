# Independent verifier worker interfaces

Every command below must be registered and run by the root-owned queue. Numerical libraries, person arrays, model deserialization and numerical artifact hashes are never accessed by this verifier outside that queue. The `Inputs` adapter authenticates the new queue at stage `verification`; each config and all source pins must be included in the unit's source list. Outputs are immutable fresh paths.

The first queued fixture receipt is `engineering/INDEPENDENT_PREFLIGHT_V1.json`: PASS, ten fixtures, no source artifacts opened. Later source, fitting and assessment evidence is separate from that engineering receipt.

| Worker module | Required config fields beyond `unit_id` and `public_output` |
| --- | --- |
| `preflight_worker` | None for fixtures; optional `endpoint_registry` pin validates the actual K240 registry. |
| `source_worker` | `source_admission` with manifest/roster pins, `source_receipt` pin, inherited geometry `rule`. |
| `release_replay_worker` | Manifest pin, packages with checkpoint/wire contract/geometry binding and FIT2/ATT/label-free INNER releases; continuation packages also require the exact frozen source checkpoint. Optional literal wire alias list. |
| `training_worker` | Eight arm/seed packages with complete update log/summary pins; two normalization receipt/tensor pins. |
| `nomination_worker` | Two source starts and 32 checkpoint records, each with FIT2 inputs and explicit probability keys; checkpoint records also carry ATT release/score pins. Optional runner nomination pin. |
| `refit_worker` (`freeze_targets`) | Eighteen final service/seed banks with ATT release/score, label-free INNER release and freeze pins; fresh private output directory. |
| `refit_worker` (`refit`) | Exact frozen 54-target registry pin; nonempty unique subset of target attempts, copied exactly; fresh private output directory. |
| `final_worker` | Committed canonical reporting lock pin, manifest, separate sealed income/occupation/SEX truth pins and eighteen final release/score/freeze bank pins. Optional runner metric/vector comparisons and fresh private metric-vector directory. |
| `replay` (`assessment`) | Reporting lock, combined endpoint registry, unit input and aligned tables. Optional runner summary and fresh private bootstrap directory. |

Each module is invoked as `python -m compressed_income_safeguard_independent.<module> --spec <config>`, using the compatible executable admitted by the root. The operation is a config field where applicable. No agent launches these commands directly.

The registry requires all 216 original usefulness clauses plus all 24 declared recovery contrasts, 2,048 shared duplicate-group draws, bootstrap seed 2026101401, alpha .05, paired fitted seeds, and inherited Student-t Bonferroni bounds. Utility remains seed-specific. Pair benefit is control minus CONSTRAINED; local worsening is CONSTRAINED minus control. All four real-control gates (U0_FULL/RAW_FULL, both seeds) are mandatory dependencies of each recovery contrast.

Forward arithmetic is separately written Torch functional encoder/head code. New role releases use full-role batches of 1024 before selection slices. The source U0 reference audit explicitly uses its legacy whole-role batching. Factorized projection uses the pinned fixed basis and recomputes the actual own head; it never reconstructs the wire from a full rounded projector.

Independent reader preprocessing retains every strictly positive empirical standard deviation. Target selection recomputes all 18 local/54 pair ATT validation AUCs, retaining frozen orientations. The target freeze contains 54 registered attempts, including repeated exact-target receipts for aliases. Repeated-target identity hashes the actual selected feature tables, people, labels, train/validation split and label-free forwarding inputs, rather than the full unrelated recipient archive.

Training accounting reports accepted nonzero movement separately from feasible accepted rounding-zero proposals; zero-stall counts all zero movements. Normalization medians/coefficient, all proposal counts, ancillary critic updates, arm assignments and matched model proposal draw hashes are independently checked. The complete log audit is stored-log certification; live mixed-dtype engineering checks and independent source/model forwards are separately labeled.

Final metric vectors use runner-compatible names `own__task__metric` and `REF_reference__task__metric`, while deriving values independently. This enables endpoint replay from independent arithmetic without importing runner metric, selection or interval functions. Stored-prediction replay, independent model forwarding and actual reader refitting remain separately disclosed.
