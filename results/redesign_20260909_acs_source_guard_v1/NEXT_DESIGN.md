# One next experiment: fixed source predictions with an A-only auxiliary feature channel

**Proposed, not launched.** Test whether a small purpose-A auxiliary release adds useful residence capability at acceptable measured incremental disclosure when the three required source prediction functions are held exactly fixed. This addresses the present failure to preserve independent source utility with a guard based on native fitting losses. It also respects the observed distinction between residence and commute: guarded F improves residence over matched P, while no condition establishes the .01 commute feature advantage. This does not assume that B's probability alone preserves commute utility.

Use the **original PCA32's three already selected 2,048-label source predictors** as immutable anchors: income and employment probabilities for A, coverage probability for B. Their exact native predictions reproduce the original PCA32 source evidence under both weightings. Do not substitute T's native heads, which have substantially worse coverage loss than its independent probes. Freeze model, preprocessing, selection, label-pool exposure and prediction identities before any fitting. Preserve the anchors' original numerical values/dtypes; do not silently requantize them. A float32 auxiliary vector may be embedded losslessly in a common float64 wire container if needed.

The anchors are public per-person predictions. Their leakage has **not** been measured by the present P-T audits because those are different prediction functions. The next experiment must independently audit the anchor-only release. No augmented method can retract information already available by projecting onto its anchors. Finite selected-auditor gains can violate development ordering through generalization error, so this information-access fact is not a promised numerical ordering of test log losses.

## One fixed six-condition matrix

Use the same three cohort-sharing seeds and household roles, with no new cohort, shuffle, refresh or cross-version composition. There are **12 learned A-only continuations**, plus static/projection controls, giving six named release systems per seed. No coefficient or architecture sweep follows these results.

| Condition | A receives | B receives | Auxiliary training |
| --- | --- | --- | --- |
| H | Two fixed source anchors | Fixed coverage anchor | Anchor projection control of the learned systems; no distinct forward fit |
| H+A0 | Anchors + 16 auxiliary coordinates | Same anchor | Source-only auxiliary baseline |
| H+L025 | Anchors + 16 auxiliary coordinates | Same anchor | Ordinary individual protection + local extra .025 |
| H+L20 | Anchors + 16 auxiliary coordinates | Same anchor | Ordinary individual protection + local extra .20 |
| H+J | Anchors + 16 auxiliary coordinates | Same anchor | Ordinary individual protection + coalition extra .10 |
| H+E_A | Anchors + the existing immutable direct-E coordinates for A | Same anchor | Static teacher control; no auxiliary fitting |

The four learned systems have exactly the same trainable A mapper (32→64 ReLU→16), two genuine affine auxiliary source heads, source labels, optimizer budget, initialization, batch schedules and public anchor functions. This is 3,152 mapper plus 34 head parameters, **3,186 trainable parameters per learned continuation**. The frozen source-anchor models are additional fixed dependencies, identical across all conditions, with their actual parameter counts and original label exposure reported. The static controls are not claimed to have the same learned representation capacity.

H is the literal anchor projection of each augmented learned system. An augmented-versus-H comparison can therefore hold that upstream system's fitting and label exposure fixed while withholding its auxiliary wire. The identical H predictions and their identical data/selection recipe may be represented by audited aliases; do not invent extra “anchor training” fits or count them as independent replicates. Separately report actual source fitting for the 12 continuations, shared warmup, inherited anchor fitting and static-E protected-label exposure. The matched J/local comparison has identical new source training exposure regardless of this projection-control accounting.

All learned auxiliary source-head parameters are public and composable whenever their input coordinates are released. “Training-only head” describes its role in the objective, not secrecy. Its two predictions must be available to expanded auditors alongside the source anchors. Public source-anchor model parameters do not give recipients the original PCA32 person inputs. No raw coordinates, hidden B representation, source ground truth, alternate system/seed or freshly randomized values are supplied. Repeated retrieval returns exactly the same cached values and models; this proposal makes no claim about future model versions.

## Matched training with a meaningful auxiliary objective

Start the A mapper with the original deterministic PCA16 initialization and use the same initialized two source heads across all four learned continuations of a seed. Train one common 60-epoch source warmup, followed by the original 20-epoch observer warmup with no mapper updates. Clone complete mapper/head/observer/Adam/RNG/schedule state into all four 80-epoch fixed-final continuations. Adam .001, original defaults, batch 256, original masks and three detached observer updates per mapper step remain fixed. No preservation, reconstruction, current-displacement guard, noise, validation stopping or reserved-label objective is added.

The trainable base objective is `.25 BCE(auxiliary income) + .25 BCE(auxiliary employment)`; the `.50 BCE(fixed coverage anchor)` component is recorded as the original constant B contribution and has zero mapper gradient. The auxiliary heads are necessary: detached fixed anchors alone give the auxiliary mapper no source-learning signal. All losses use the unchanged original fitting pools, masks and finite handling.

Use the existing normalized observer definitions and nine training roles. A has coverage/SEX/race observers; B has income/employment/SEX/race observers; AB has SEX/race observers. Their actual inputs are A's anchors plus auxiliary coordinates, B's fixed scalar, or their concatenation. A0 has zero protection coefficients. L025/L20 use `base − .10 L_ind − beta*(M_A+M_B)` with the declared beta; J uses `base − .10 L_ind − .10 M_AB`. `M_A+M_B` remains a sum. B-channel terms have zero mapper gradient because B is immutable, but the losses and their observer training remain reported. Log each source/protection component and actual gradient norm so nominal coefficients are not presented as equal gradient strength.

The purpose policy is unchanged: A may perform income, employment and residence; B coverage and commute; AB all five. Opposing source/reserved tasks and SEX/race remain forbidden in their declared views. Residence/commute labels enter only frozen-release heads and audits after **all intended representations and controls are frozen**. They never affect initialization, fitting, coefficient choice or checkpoint selection.

## Evaluation that can falsify the proposal

Keep the existing logistic/MLP utility candidates, 2,048-label budgets, validation-selection rule and all five tasks. Report the unchanged original PCA32+.01 source-probe floors separately for validation/development and U/PWGTP. Also report exact native anchor utility as a distinct functional invariant. Holding the anchors fixed does **not** automatically make newly fitted independent source probes pass their old criterion; selecting or recalibrating another head can change their scores. Do not redefine the old floor, substitute native anchor loss, or admit a method based only on a mean. If H itself fails a probe floor despite exact native source-function parity, report that mismatch explicitly.

Fit complete 120/360 nested audits on **all 18 named systems**, including H and H+E_A, for every A/B/AB forbidden role. Use the existing five fresh candidate families, fitting/validation rows, public-head compositions, singleton inheritance and fixed schedules. Every augmented audit pool must contain its legal anchor projection candidates, with exact prediction and preprocessing parity. Fit them separately or reuse only byte-identical, hash-verified fits on identical inputs/rows; no auditor may require hidden coordinates or another system's additional outputs.

Match the representation-fitting **attacker label exposure** for static/projection controls by fitting fixed-release observer controls for the same declared 20 warmup plus 240 continuation passes, then run their own direct-coordinate saved-start catch-ups with the same reset-Adam/fidelity rule. These are exposure-matched audit controls, not fictitious mapper training. Their fixed-input exposure differs from a learned observer's changing-input history and must be disclosed. Keep fresh, expanded and catch-up-inclusive selections separate, retain epoch 0, all controls, all nine race categories and the missing code-4 assessment. Audit H's own leakage rather than borrowing the present P or teacher audits.

The primary task question is whether **A residence** improves by the unchanged .01 descriptive feature-advantage reference over H while respecting the old independent source floors. The incremental disclosure comparison is the same fixed augmented system minus H, retaining separate A/B/AB SEX/race gains and the .005 extra-attribute-gain references where applicable. Inspect all other forbidden gains without inventing new pass thresholds. Compare J to **both fixed locals** using the same four panels, four utility tolerances, both weights/scopes/budgets and fixed-seed eligibility rules. The small matrix remains published even if utility overlap is absent. A teacher/anchor leakage floor, broad source failure, no .01 residence advantage, independent-audit reversal or an individual-target cost can each falsify a claimed advantage. A source-only auxiliary condition that performs just as well is a substantive counterexample to a coordination claim.

Commute remains an independently measured reserved task and a possible cost of fixing B to predictions. No .01 feature advantage in the current study is not a transfer guarantee. Full race support remains unresolved on this cohort, and no finite audit supplies privacy. Source functions fixed by construction are a control mechanism, not a novel PCRL contribution.

Freeze this exact protocol, all source identities and evaluation order prospectively. Use one numerical thread, a 90-minute scientific ceiling and four-hour total ceiling, with no automatic extension. Train/freeze the whole fixed matrix before reserved evaluation; time the first complete evaluation block, then execute all remaining blocks or publish an explicitly bounded partial result. This is the **only** proposed next experiment and has not been executed.
