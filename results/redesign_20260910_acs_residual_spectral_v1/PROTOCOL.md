## Numerical specification

All representation calculations unweighted float64. Standardize PCA coordinates using representation-fit means and population standard deviations, replacing std<=1e-12 by1. Feature map128=[32 standardized coordinates,96 Gaussian random Fourier coordinates]. Select min(1024,n) rows without replacement with RNG20260910+100s; sigma=median positive pairwise Euclidean distance, failure if none. Fourier omega iid N(0,1/sigma^2), phase iid Uniform[0,2pi), RNG20261910+100s; feature sqrt(2/96)cos(Tstd omega+phase). This approximates exp(-||x-y||²/(2sigma²)). Same expansion for every arm of a seed.

qA: intercept and all degree<=2 monomials in positive-class H_A columns1,3. qAB additionally uses H_B column1. Training-only population centering/scaling of nonconstant columns; deterministic constant/duplicate removal tolerance1e-12; retain intercept. SVD least squares relative singular cutoff1e-10 for T and phi on qA. Explicitly subtract residual means for roundoff. V0 covariance=V0'V0/n; retain eigenvalues>max(1e-12,1e-10*largest). Eigen-whiten, not ridge-whiten. Check V mean0 and V'V/n=I. Teacher R uses original unstandardized PCA T. C_VR=V'R/n, U=C_VR C_VR'. Under Z=VW and W'W=I, reconstruction reduction is trace(W'UW), with error (1/n)||R-ZD||F² (sum of coordinate errors per row). LS intercept handles centering; coordinate-mean MSE would divide both sides by32. Normalize U by positive trace>1e-12; zero is a diagnostic failure.

r=min(16,retained rank), common across all eight arms for a seed. Rank<16 is a documented capacity mismatch. Symmetrize matrices; select descending top-r eigenvectors, largest-absolute coordinate positive for canonical signs. Top eigenvectors optimize only this fixed finite trace objective, not arbitrary privacy constraints.
