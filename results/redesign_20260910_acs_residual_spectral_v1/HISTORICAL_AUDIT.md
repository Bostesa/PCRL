## Interpretation and focused checks

The parent fixed-prediction training uses an A-only mapper and fixed adversarial coefficients: A0(0,0,0), L025(-.1,-.025,0), L20(-.1,-.2,0), J(-.1,0,-.1). These systems are not proxy-Lagrangian fits. `pcrl/training/proxy_lagrangian.py` supplies empirical projected dual ascent and cannot certify feasibility or optimality of a new spectral method. No optimizer is needed for historical reconstruction.

The repository prior-work matrix already identifies task-aware LEACE/SPLINCE erasure. SPLINCE's covariance preservation is not an accuracy guarantee, and its equal-kernel prediction equivalence requires its stated unregularized refitting conditions; a regularized common kernel family can expose coordinate effects. The current SPLINCE implementation may fall back to LEACE when its conditioning criterion fails, so reuse its name only when its actual operation and fallback are reported. A new residual spectral map should be described by its implemented matrix and objective rather than attributed an existing guarantee.

`docs/ACCURACY_CERTIFICATE_RETIREMENT.md` remains controlling: zero affine R² does not bound threshold-classifier accuracy or imply independence. The exact20-point counterexample has zero covariance and90% threshold accuracy. Both former certificate APIs explicitly raise. An affine residual covariance diagnostic is therefore descriptive; finite independent attacks give evidence for the evaluated budget only.

Focused new checks should cover: fit-only input access and label-mask alignment; deterministic map serialization/reload and numerical rank policy; exact anchor/B preservation for every pool; dynamic AB column projections before normalization; all singleton/H candidates available; saved-adversary exclusion from selection; no invented spectral catch-up; unchanged historical predictions and B aliases; kernel candidate full-schema normalization and finite outputs; validation-only deterministic selection common to both weightings; source-versus-reserved task indexing; replaying new predictions from saved state; signed negative disclosure increments retained; unsupported race categories and source-exposure limits visible. Existing examples are `tests/test_acs_fixed_predictions.py`, `tests/test_acs_locked_evaluation.py`, and `tests/test_accuracy_bound.py`. No miniature training test was run as part of this read-only audit.
