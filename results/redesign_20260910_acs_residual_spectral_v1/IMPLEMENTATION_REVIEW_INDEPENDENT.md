# Independent implementation review before fitting

Reviewed `acs_residual_spectral.py`, `acs_spectral_audits.py`, `run_acs_residual_spectral.py`, their focused tests and the protocol including prefit clarifications. This was a source review; no new ACS fit/evaluation or historical replay was run. Findings below describe the reviewed version and require an explicit closure check after fixes.

## Required corrections

1. **PCA scaling differs from the frozen formula.** `fit_spectral` uses `np.maximum(T.std(0),1e-12)`. The protocol requires replacing std<=1e-12 with1. Tiny-variance columns are therefore amplified by up to1e12 relative to the stated map. Use the exact replacement policy and test tiny nonzero and constant coordinates.
2. **Degenerate map cases silently proceed.** No positive representation bandwidth distance sets sigma1 even though the protocol requires failure. Zero reconstruction trace is normalized to zeros and may return rank0/arbitrary penalty-selected maps although the protocol says diagnostic failure. Fail explicitly on these cases; retain fixed r for valid maps, including negative arm-objective eigenvalues.
3. **Completed fit reuse is not bound to the requested inputs/recipe.** `fit_kernel` checks existing file hashes but returns before checking current fit/validation x/y, class count, RNG seed or feature count. `build_audits` returns an existing audit selection before checking input identity or recipe. Fresh candidate reuse validates only fit x/y, without validation hashes, epochs/seed, or persisted state checks. Changed validation inputs can silently reuse an old selection. Bind complete units to all these quantities and reject incompatible resume.
4. **Global freeze does not enforce source identity.** Per-seed `maps_complete` skips without validating protocol/source identities; only the eventual global record stores the then-current source hashes. An interrupted run followed by an edit can therefore mix implementations across seeds and label them all with the latest hash. The evaluation gate checks protocol and map bytes but does not compare its saved source hashes to current source. Bind recipe/protocol/input hashes before each map fit, validate completed-unit files, and enforce the frozen fitting/evaluation source contract before opening evaluation labels. Compatible routine fixes need explicit provenance rather than silent reassignment.
5. **Incomplete saves are not resumable.** `save_extended_audits` creates its directory with `exist_ok=False`. If interrupted after directory creation and before `unit_complete.json`, the next run refits then fails because the partial directory remains. Likewise partial utility candidate directories can obstruct `fixed.utilities` before `utility_state.joblib` is written. Use atomic completed units or explicit incomplete-unit quarantine and counted restarts; never discard valid completed units.
6. **Completed evaluation and runtime accounting are weak.** `evaluate_seed` skips any `complete.json` without checking its saved metric/prediction hashes. `main` writes runtime only after success, losing exceptions/interrupted execution. Validate completed outputs and record process start/status/elapsed in failure-safe accounting. Unique-fit counts should distinguish reused units from refitted incomplete work.

The historical B utility-loader path defect was observed initially and the parent's explicit fallback to historical H was present on the second source read; it is no longer an outstanding finding.

## Correct implementation aspects

- Map fitting reads raw SEX/RAC1P/PUBCOV/SERIALNO only. It passes exactly SEX/RAC1P/public_coverage to `fit_spectral`, whose API rejects other target names. Residence/commute are absent. Evaluation loads their labels only after global map manifest validation. Existing cached PCA/test features do not add reserved target fitting.
- Teacher residual reconstruction uses unstandardized original PCA T, row-summed error and `/n` covariance consistently. Protected moments mask each target, retain full class coding, sum all retained basis columns and class moments, normalize each target separately, and preserve fixed3/3/2 denominators. OOF household folds prevent heldout-fold labels from fitting nuisance coefficients. Heldout nuisance behavior now uses the declared equal ensemble.
- Ridge normal equations correctly implement mean squared fitting loss plus alpha norm: Gram/cross both divide by n. Features are centered; prior acts as the intercept; full-schema output clipping/renormalization and unweighted validation selection are explicit.
- Kernel candidates include all three alphas in the pool for both budgets. Original scopes remove every CID containing `kernel__`; prefixed common scopes use the full legal set. Derived kernels occur only where actual historical public-head-derived views exist. There is no invented spectral own saved observer.
- H inheritance selects raw anchor columns using actual A width before the ancestor normalizer. All A/B singleton candidates, including kernel candidates, are routed to AB. B direct candidates are canonical H aliases; no additional B fits occur. Diagnostic saved-adversary candidates remain excluded by the original pool rule, while genuine inherited catch-up candidates enter catch-up scopes only.
- Historical scoring reuses cached predictions when IDs match. Canonicalizing B changes original `anchor__...` IDs to H IDs, so those equivalent B predictions are recomputed; retain an explicit alias mapping if claiming unchanged historical candidate IDs. Their functions and input values are unchanged.

## Remaining implementation/report requirements

The runner does not yet call `moment_diagnostics`; ensure the promised heldout descriptive moments are produced from frozen state, with source/protected labels only and explicit no-certificate interpretation. The randomized-control code currently supplies expected-loss arithmetic, but the persistent per-person branch routing fixture and full source/sensitive vector comparison logic still need review when implemented. A single A branch must be reused when the same A is observed in AB.

The three new audit tests cover kernel normalization/reload, raw ancestor column indices, and expected weighted loss arithmetic. They do not cover full candidate-scope assembly or compatibility rejection. Add focused synthetic tests for: every H/singleton/derived kernel opportunity; B aliases; no saved-diagnostic selection; old-scope preservation; changed input/validation/seed resume rejection; partial-save recovery; source/protocol tamper before label loading; and completed prediction tamper detection. No extra scientific fits are needed for most such tests.
