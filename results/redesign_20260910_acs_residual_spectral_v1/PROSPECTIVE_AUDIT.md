# Prospective protocol review before new fitting

Read the first protocol draft after completing historical identity verification. No new outcome scores were opened. The following are definitions to settle before implementation/freeze; they are not proposed outcome-dependent method changes.

1. Define protected-moment `b_k` explicitly: which qA/qAB basis, whether the intercept is included, ordering, and use of the same saved fitting centering/scaling. State summation versus averaging across basis functions. The displayed moment formula otherwise leaves the implemented protection matrix underdetermined.
2. Specify the prediction function for descriptive heldout nuisance moments. OOF training residuals use three distinct fold models; evaluation needs a deterministic frozen function, such as their specified ensemble or a separately declared full-representation fit. Record the corresponding fit count/exposure.
3. Fully quantify nomination's strict improvement clause. The noninferiority requirements say every seed and both weightings; the final strict benefit clause needs to state whether the same is required, whether a single endpoint must improve consistently, and whether different seeds may satisfy different alternatives. Define coordination's “outperform” using exact utility, sensitive-role, strictness and scope rules.
4. Enumerate exact common scope identifiers and candidate membership. Original scopes should retain their original no-kernel choices. Common independent scopes should include the declared new wire/derived kernel candidates; catch-up scopes additionally retain only genuine historical saved-start continuations, including legally inherited H/B ones. Spectral systems have no own saved observer. Add all H kernel candidates and all sensitive singleton kernel candidates to AB before validation selection, rather than adding only alpha winners. The kernel-alpha best may be one selected family candidate but all prespecified raw candidate opportunities and lineage must remain auditable.
5. “All legal ancestors” means H projection and available public compositions, not historical E/A0/etc auxiliary channels unavailable from a given spectral release. B is unchanged and can reuse historical candidates and one new kernel fit per role/seed. Dynamic AB projections depend on actual A width.
6. Keep fixed rank r even if an arm's objective has negative top-r eigenvalues; dropping those dimensions would change the optimization problem/capacity. Report spectral ties and rank mismatch; canonical signs resolve sign ambiguity but not an arbitrary eigenspace rotation at repeated eigenvalues. Save the matrix rather than require cross-library bitwise eigensolver identity.
7. Kernel ridge's fit objective normalization must be reflected in the solve: `(F_centered.T @ F_centered / n + alpha I) B = F_centered.T @ (onehot-prior) / n`. Output conversion, prior, feature centering, fitted standardizer and both bandwidth/RFF draws are immutable saved state. `alpha` is selected by unweighted validation log loss; PWGTP does not choose a second candidate.
8. The visible randomized branch is one persistent draw for the person's A release, shared when that same A is combined with B; it must not redraw when queried through AB. Expected routed losses are exact for the specified two-branch candidate family. They do not bound all attackers of the stochastic release. Endpoint p=0/1 identities and per-person weighted arithmetic are natural exact checks.

The protocol appropriately excludes residence/commute from map fitting, retains both original class columns, uses global map freeze, and states development provenance. Conditional moment suppression, finite fixed rank trace optimality and finite-source LP facts remain distinct from empirical attack scores and population privacy claims.
