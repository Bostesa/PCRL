The predeclared capacity escalation fitted both T0_B16 seeds after the
ten-bit point failure. The replacement unit IDs followed the dated memory
reservation amendment; their model, loss, selection rule, sources, roles,
calibration and utility caps remained fixed. R2's queued
`R2_T0_B16_GATE` used the same code-only restoration and 24-clause
INNER_SELECTION point procedure as B10. The queue unit finished with
return code zero; all saved probabilities and decisions reconstructed
exactly from the disclosed sixteen hard bits. This is a valid scoring unit,
whose scientific result is **POINT_FAIL**.

seed-one income pass all their U0/Ucal clauses. Seed-one occupation fails

not just the occupied states. Useful prediction remains above the constant

point cost, so interval precision cannot make this candidate eligible.

The locked ladder tested both two-seed learned T0 capacities and neither
passed. The protocol therefore stops **new kernel-protection fits for this
recipe**. This is a learner-recipe utility shortfall, not an information
capacity impossibility: the historical ten-bit W_Q/W_TSTAR score-routed

internal bank-routing construction. Those banks remain runnable utility
