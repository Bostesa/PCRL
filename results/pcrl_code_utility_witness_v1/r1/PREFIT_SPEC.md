This is exploratory development on reused Adult people. No old assessment person arrays are opened. R0's committed effective seal controls all real-data reads and fits. R1 workers require an active `witness` queue slot before role-only files are read. The bank stage is frozen historical restoration; the learner stage is a new task-only fit.

## One learner recipe

Arm IDs are `T0_B10` and reserve `T0_B16`. Each recipient has a 16→64 ReLU→b sigmoid mapper, exact hard bit threshold at 0.5, and a b→64 GELU→K code-only head, K=2 or 6. The straight-through surrogate changes backward derivatives only; fitting, validation, export and deployment forward paths always use hard bits. The loss is the arithmetic mean across tasks of true-label CE plus 0.5 KL from frozen Ucal teacher probabilities. No SEX, bank-code target, learned decoder table, original teacher score, latent, soft bit or residual enters the public output.

FIT-only grouped outer validation selects a single epoch by uncalibrated mean task NLL from actual hard bits; strict improvements use a 1e-12 tolerance and ties keep the earlier epoch. Maximum 200 epochs, patience 20. The full 15,434-row FIT role is then refit from the identical seed initialization for exactly that selected count. Fixed optimizer: Adam learning rate 0.001, default betas and epsilon, zero weight decay, batch size 256. Initialization, fold-batch and full-batch seed offsets are 370001, 370003 and 370007; inherited batch-plan shuffle adds 104729 internally. The fixed non-amplifying scaler is fitted on all FIT latents once per seed and shared with later arms. No new hyperparameter grid or INNER checkpoint selection is permitted.

The task-only point ladder tests ten bits first on INNER against U0 and Ucal for each task and seed: accuracy loss at most 0.010, NLL excess at most 0.010, summed multiclass Brier excess at most 0.005. If any point clause fails, the predeclared sixteen-bit arm is tested with the same recipe. If both capacities fail, new kernel protection is not run. A passing point gate permits conditional development but is not a simultaneous interval pass. The same numerical loss and class conventions are owned by R2; R1 produces releases and fit receipts, not endpoint claims.

The inherited `H-GLOBAL-TEMP` calibration implementation has SHA-256 `fd5016ee0c041ffc18fc8d02fc31f57eb270bdc9977298efd9958f43cff5851e`; one inverse temperature per task/arm/seed is fitted on actual CALIBRATION_HELDOUT labels, then fixed. T0 is immutable after this fit. The complete recipient wire is exactly hard code bits, calibrated code-head probabilities, argmax-first decision and fixed model/version/calibration metadata. Private role-release archives include row/group IDs solely for alignment. They contain `row_id,unit,code0,prob0,decision0,code1,prob1,decision1`; no class tag outside the bits.

## Worker and output contract

Run `python -m code_witness.worker --stage bank|fit --seed 0|1 --unit-id ID` with `--role-manifest`, `--role-manifest-sha256`, `--source-root`, `--source-sha256`, `--private-out` and `--receipt`. Bank additionally requires `--qpc-root`, `--public-table` and `--public-table-sha256`. Fit additionally requires `--bits 10|16` and `--common-eval-sha256`. The private output directory and public receipt are write-once. The public receipt pins each entire private release and every member-array hash, source/schema/class order, calibration, fitting updates/history, exact service package/model hashes and public wire version. The private service manifest uses `code-witness-service-package-v1`; `code_witness.service.load_service` restores it with byte checks. No person arrays, teacher scores or model bytes enter public Git.

Prior D's paired T/D-K production units each charged about 14–19 CPU seconds at their much shorter 20+20-epoch allowance. That is not a measured forecast for the present 200-epoch maximum. R0 should time the first admitted role-sized witness fit and scale its queue plan within the 8 CPU-hour witness reservation; no baseline is weakened to use spare capacity.

R1 data-free tests: `python -m pytest -q code_witness/test_model.py code_witness/test_bank.py code_witness/test_service.py code_witness/test_worker.py` (13 passed before any new real-data read).
