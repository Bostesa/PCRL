## Fixed criteria and inference

Point utility caps are inclusive for every task, seed and required U0/Ucal reference: accuracy loss ≤0.010, natural-log mean NLL excess ≤0.010, summed multiclass Brier excess ≤0.005. All three must pass on both tasks and both references for the learned-code ladder. Point feasibility permits conditional development, but is not a simultaneous statistical pass. Coalition SEX AUC benefit must be ≥0.020 versus every eligible required matched control; either recipient's AUC worsening must be ≤0.010. Constant-reference gain, class recall, occupied/global code states and exact output interface are also reported.

The entire predeclared finite capacity/candidate/control family, including both capacity outcomes and potential nominees, remains in the simultaneous interval adjustment even if downstream stages are not triggered. People and duplicate groups are paired across arms; seeds are repeated fits on the same people, not separate populations. Accuracy PASS requires its lower bound ≥−0.010; NLL/Brier PASS requires upper bounds ≤0.010/0.005; pair-benefit PASS requires lower bound ≥0.020; local-worsening PASS requires upper bound ≤0.010. A crossing interval is UNRESOLVED. Inference is conditional on fitted models/readers and reused development rows. It cannot supply confirmation after the adaptive study history.

The fixed attacker slate uses regularized linear, serious nonlinear, small neural, categorical/bit and public-defense-aware readers as applicable, plus transported individual readers in the coalition bank. It sees every transmitted code/probability/decision/variable metadata field and public tables. ATT-only roles choose readers; INNER never chooses a reader or training epoch. Real null/shuffled and planted-leak controls must pass for a recovery result. A code ID treated only as an ordinal number is insufficient.
