# Bounded utility interval worker

`python -m results.pcrl_code_utility_witness_v1.r4.utility_interval_worker --config <owner-only-json>` runs only inside an R0 `verification` queue unit. The unit must register the config, worker source, `utility_intervals.py`, campaign seal, inference randomness lock, role manifest, all four INNER role-only label/reference archives, and every candidate receipt/release/service or public bank table by byte SHA. The config path and parent have owner-only permissions. The public output is a new file in `r4/`; it contains aggregate clause values and no person arrays.

Config schema is `pcrl-r4-utility-interval-config-v1`. It binds `unit_id`, `worker_sha256`, `utility_source_sha256`, `{path,sha256}` records for `seal`, `inference_lock`, and `role_manifest`, a `candidates` list, and `output`. Each candidate specifies `arm_id`, `kind` (`learned` for T0_B10/T0_B16, or `bank` for W_Q/W_TSTAR), `seed` 0/1, `source_model_sha256`, and pinned `receipt` and `release` records. Learned entries add `service_manifest`; bank entries add `public_table`, `policy_sha256`, and nullable `decoder_sha256`. The service weights are taken from the service manifest and must also appear in the queue source list. Candidate releases and learned service packages stay owner-only under `.private`; the admitted `DATA_ACCESS_MANIFEST.json` is the public file in the repair worktree so its sibling role exports resolve correctly.

Before opening INNER labels, the worker validates queue registration, source and lock identities, every candidate receipt, release row/group SHA, wire member inventory, and probability/decision replay from the sole transmitted code and public head/table. It opens only INNER task labels and references U0/Ucal. It computes the fixed 2,376-clause family with 2,048 shared PCG64 paired-group draws at seed 24681357, the full-K t critical, and equal-weight paired seed means. F and privacy clauses remain null unless separately admitted sources support them; an absent branch also remains null. The worker does not open the old assessment or ATT SEX.
