# R4 complete-view attack and inference plan

Status: data-free prefit implementation. R0's committed stage seal and the global queue are prerequisites for every real fit or INNER read. R4 owns only this namespace; R5 independently verifies results using separate code.

## Admission and wire

For each distinct seed/arm, the producer provides role-only `ATTACK_FIT_NEW` and `INNER_SELECTION` public release packages plus hash-pinned service manifest. The recipient wire is exactly a ten- or sixteen-bit hard code (or its canonical global integer ID), code-derived calibrated task probability, first-tie decision, and all metadata/flags. R4's `code_views.py` accepts both equivalent code encodings. It supplies local `r1`, local `r2`, and aligned `pair` views with bits, ATT-frozen categorical IDs and unknown category, all probability coordinates, decisions, metadata, public log probability, and all pair bit products. No source latent, protected label, teacher score, private per-person provider input, soft bit, or extra raw head output is admitted. The pair bank retains each complete local reader as a zero-fit ignore-recipient alternative.

The queued worker must verify exact ATT/INNER row/group hashes against the role manifest, public release SHA, code width, source/arm/seed identity, and each probability/decision by replaying the pinned code-only decoder/head. `code_views.py` checks within-wire code-only consistency; that check alone is not a deployment replay. W_BANK is a separate inherited representability witness and joins this attack bank only if R0 admits the same source-input/service contract and its public decoder table can be restored. Any output flag, code length, fallback, or variable routing metadata enters both local and coalition views.

## Frozen fitting protocol to reuse

Reuse the validated `r02.protocol.run_three_view_attack` and inherited shared attack evaluator. Each hard-code view fits `LR_C1`, `MLP_64x32`, `HGB_15x200`, `DA_MLP_64x32`, `CELL_A1`, `CODE_BIT_LR_C1`, `PROB_LR_C1`, `PROB_HGB_15x200` with the fixed ATTACK_FIT_NEW group-disjoint ATTACK_TRAIN/ATTACK_TUNE split. The pair additionally carries zero-fit transported local readers. The two V2 engineering controls per view are group-shuffled SEX and planted leak. Reader selection and orientation occur on ATT tune only; INNER labels open lazily after the frozen-reader receipt. A failed null or plant blocks the affected arm result. No numeric ordinal code-ID-only reader substitutes for categorical/bit/probability views.

One distinct hard-code arm/seed costs 3 views × 8 reader fits + 3 views × 2 engineering fits = **30 fits**. The protected-stage registry `T0,T+,L,J,S12,S21,C` across two seeds therefore costs at most **420 fits**, plus **60** if a compatible W_BANK is freshly attacked on both seeds. Exact aliases require matching source, role, seed, wire, reader contract and hashes. The task-only ladder is dependency-gated: unused capacity arms and conditional protected arms are `NOT_RUN`, not fabricated attack results. A role-sized smoke updates wall/CPU/RSS reservations before full attack units; every numerical job holds the global queue slot with one numerical thread.

## Recovery and simultaneous inference

Each seed/arm reports fresh complete-view SEX AUC for `r1`, `r2`, and `pair`, the ATT-tune-selected reader and oriented alias, full reader bank and controls, code occupancy/unseen mass, and all task endpoints against U0 and Ucal. R0 seals a finite clause order before affected fits covering both ladder capacities, all potential protected nominees and required controls, two paired seeds and their equal-weight mean, both tasks/references, and all three views. If a conditional arm is unrun, retain its registered clause ID with `NOT_ESTIMABLE_DEPENDENCY`; do not shrink the family after outcomes. For the run subset, use one 2,048-draw duplicate-group paired resample across both seeds and all arms, fixed max absolute studentized critical value, and account for selection over the full predeclared family. R5 recomputes the arithmetic independently. The point gate is separate from simultaneous PASS/VIOLATION/UNRESOLVED rules; a pair benefit needs lower bound ≥0.020 and each local worsening needs upper bound ≤0.010.

The old D 567-family interval was conditional on fitted models/readers and comprised a fixed seven-arm ten-bit registry. Its bounds and critical value cannot be copied to this study or narrowed to a selected candidate. Keep seed results separate because they share the same 2,235 INNER people/2,234 groups. W_BANK may have different state occupancy and historical fit effort even if its public service matches; report those distinctions rather than treating it as a matched architecture ablation.

## Stop conditions and verifier boundary

No protected D attack starts before a learned T0 passes the sealed both-task/both-reference point ladder and R0 seals the selected capacity and comparison stage. A failed ten-bit rung can proceed to the predeclared sixteen-bit rung; failure of both stops new protected D fits and their attacks. R0 may separately authorize a bounded descriptive T0/W_BANK attack under a sealed unit. The independent R5 verifier must not import `code_views.py`, the queued R4 worker, R4 scoring, or the inherited endpoint implementation when certifying complete views, model restore, points and intervals. R4 may reuse the validated attack runner as the implementer; R5's numerical code is a separate boundary.
