# Inherited public-bank attack input contract

Status: data-free worker only. R0 must first establish current-role point utility and compatibility, then hash-seal bank attack units and admit them to the `attacks` queue. This path does not turn W_Q or W_TSTAR into a new latent method or architecture-matched kernel control.

Each bank unit names `W_Q` or `W_TSTAR`, seed 0 or 1, and exactly ten transmitted bits. It pins the R1 `code-utility-witness-worker-v1` bank compilation receipt, the corresponding `r1/W_BANK_PUBLIC_TABLES_S{seed}.json` bytes, source model and role manifest, historical policy SHA, optional T* decoder SHA, and two private role-only releases. The releases use the same eight NPZ members as learned codes: `row_id`, `unit`, `code0`, `code1`, `prob0`, `prob1`, `decision0`, `decision1`. Their source receipt paths/hashes must match exactly. The public table contains `table0/table1` and token classes; no source fine token or teacher score is transmitted.

`bank_service.py` validates the table/source/policy/decoder identities, 1,024-state ceiling, normalized probabilities and class decisions. It reconstructs each saved `prob{i}` and `decision{i}` solely from the recipient's ten-bit public ID and fixed table; any unknown ID or altered saved probability fails before ATT labels open. The R4 complete-view adapter then exposes the code identity/bit pattern, public probability, decision, fixed bank/version/table/policy metadata, and the aligned coalition. ATT-only reader tuning, three-view slate, null/plant controls, lazy INNER access and private custody are the same as for learned codes. The fixed policy and public table may be known to the attacker, but the private per-person provider score remains unavailable.

The bank is eligible as a strong inherited reference only under R0's sealed source-input/service and both-task/both-reference point rules. Different historical fitting effort, state occupancy and score routing must be reported. If it is ineligible or no protection stage runs, its registered finite-family slots remain `NOT_ESTIMABLE_DEPENDENCY` or descriptive as applicable. This worker has not fitted an Adult attack and has no complete-view recovery result yet.
