# PCRL task-aligned constraint exchange: executable finite method

This is a new **2018 development** method, not a continuation or amendment of the closed 2016 evaluation. Its initial channel uses the frozen supervised T0 encoder, 32 states, and the historical 17 token labels. The code receives PCA32 `X_A` and four public `H_A` coordinates. It never receives `H_B`, the current person's residence label, protected label, or outcome-derived bin. An A wire contains the unchanged `H_A` and one sampled integer token. A coalition may also hold its unchanged `H_B`. The hidden T0 state, its channel row, unused random draws, and RNG seed are not on the wire.

## Exact fixed-predictor coefficients

Let `i` index **original people** in a predeclared coefficient-estimation pool, `t_i` the frozen T0 code, `z` a token, and `p[i,z,k]` a frozen predictor's full-schema class probability. For labels `y_i` (task) or `s_i` (a protected target), define `ell[i,z] = -log(max(p[i,z,label_i], 1e-9))`. The frozen audit probability floor is part of this definition. Normalize unweighted and PWGTP weights separately: `w_i^U=1/n` and `w_i^W=PWGTP_i/sum_j PWGTP_j`. Then

`C^v[t,z] = sum_{i:t_i=t} w_i^v ell_task[i,z]` and `A_{r,a}^v[t,z] = sum_{i:t_i=t} w_i^v ell_attack[r,a,i,z]`.

For a row-stochastic channel `Q`, direct person-level expected-token loss equals `sum_tz C^v[t,z] Q[t,z]` or `sum_tz A^v[t,z] Q[t,z]`. This is a loss **after one token draw in expectation**, not the loss of averaged predictions. The matrices already include joint code mass; multiplying by another state mass is wrong. The task objective is `0.5*(C^U+C^W)·Q`, with U and W retained separately for reporting. `experiments/pcrl_task_aligned_cuts_v1/method.py` implements both the grouped coefficients and direct replay. Its input schema demands all labels lie in the declared full class order; missing labels and unsupported classes require an explicit upstream support decision, never a silent class deletion.

## P1 full-view fitted-risk programme

For each frozen attack `a`, role `r∈{A/SEX,A/RAC1P,AB/SEX,AB/RAC1P}`, and weighting `v∈{U,W}`, construct one cut on the **same coefficient rows and normalization** as its fixed D17 reference `rho[r,v]`:

`sum_tz A[r,a,v,t,z] Q[t,z] >= rho[r,v] - delta`.

Positive `delta` permits the fitted attack loss to fall below D17's fitted reference; negative `delta` requires higher loss. Pilot deltas are `−0.002, 0, +0.002` nats. The floor is a fitted-risk target, not a Bayes risk. `solver.py` checks `floor=rho−delta` when both fields are supplied, validates all matrices, and independently replays every cut. Before task minimization it evaluates all 17 constant maps and solves phase I, minimizing a common nonnegative floor violation `s` with `A·Q+s>=floor`. If the registered bank is infeasible, it returns that status and the minimum relaxation; an explicitly labeled descriptive fallback must call `relax_cuts` and cannot be counted as a registered privacy pass.

The fixed-bank channel update is a linear programme: minimize `0.5(C^U+C^W)·Q` over nonnegative stochastic rows and all retained cuts. HiGHS supplies a primal channel and dual marginals. The code reconstructs a numerical dual lower bound from the marginals with a reduced-cost guard and reports primal replay, raw status, repair size, and fixed-bank gap separately. This is a finite fixed-predictor certificate. It is neither a certificate of global adaptive attack optimality nor a population information guarantee.

For a bank `B_k`, solve the LP and the matched deterministic MILP on the **same bank**. Fit equal-budget inner-training response attacks against both channels, score their coefficients on a separate inner coefficient pool, add any cut whose violation exceeds `1e-5` nats against either channel, and retain all old cuts. Pilot exchange is capped at eight rounds, promoted exchange at twelve. Freeze and hash one final shared bank before an LP/MILP gap comparison. No new oracle violation found by the bounded search means only that the search stopped. `fit.exchange_round` fits and stores each response slate, verifies the old bank, retains its cuts, adds the violated union, and re-solves the LP. The deterministic control must then be re-solved on that exact new bank. The shared initial bank can supply any registered delta by changing only `rho−delta` floors; its predictor coefficients and frozen rho do not drift.

Initial A banks include their own H-only and common-17-token attacks. Initial AB banks additionally include same-source A token predictors and a B/H-only ancestor, both of which the coalition can legally run by ignoring some of its service view. For **each weighting separately**, the reference is the minimum inner-selection risk across all saved predictors from legal H-only and D17 routes, with a lexical tie break. AB's eligible routes are AB H/D17, A H/D17, and B/H. The U and W references may therefore use different predictors; each frozen reference is rescored on the common mechanism coefficient rows with its corresponding weighting. A token predictor transferred from historical Q or D17 to another channel is a fixed function of `(H_A,z)` under the **shared 17 action labels**; it is not an automatic transfer to a different token alphabet. All attack coefficients and their D17 reference floors use identical role-specific people, labels, full class order, weight normalization, and probability floor. The initial bank fit has zero exchange rounds and is not the final oracle result.

The initial optimization bank fits the inherited `standard` predictor slate uniformly for every source and role: logistic, exact and sampled histogram trees, and a 120-epoch MLP. This registered runtime choice retains multiple predictor families while delivering the first center point promptly. Independent final audits use the equally applied inherited `catchup` slate. Any stronger exchange attack is added through the same coefficient pool and old cuts remain present.

Replacing each row-simplex variable by `Q[t,z]∈{0,1}` gives exactly one token label per T0 state, hence the deterministic-map MILP for the same fixed attack bank. Its LP relaxation is the stochastic programme above. A fixed-bank integrality certificate requires a feasible stochastic objective **below** a valid deterministic global lower bound using the same frozen coefficients, thresholds and bank hash. A time-limited poor deterministic incumbent or a rounded channel does not establish such a gap.

## P0 and task alignment

P0 invokes the historical finite conditional-information solver with the original local `A/SEX` and `A/RAC1P` laws under U and W and budgets `0.005, 0.01, 0.02` nats. Historical `Q` at `0.01` is reused if its hash and inputs match. P0 and P1 target different privacy quantities; equal numeric values do not make them equivalent.

U0 uses the frozen 17-action decoder `g_z(H_A)` and its historical binary cost. U1 uses one common audit-like task decoder trained from allowed 2018 fitting resources on the fixed equal mixture of historical Q, D17 and uniform-token coverage, then frozen before crossed channel fits. Every U1 arm and matched control receives that same decoder and supervision. The independent fresh task probe remains the outcome; improvement in U1's own fixed cost alone is not a win. Before constrained U1 releases, the exact rowwise minimum of its fixed cost is named `D_U1`, while historical `D17` remains U0's minimum. For any unconstrained fixed linear cost, each stochastic row's cost is a convex combination of its entries, so `sum_z C[t,z]Q[t,z]>=min_z C[t,z]`; putting unit mass on a minimizer in every row attains the bound. This theorem does not preclude randomization helping under privacy constraints.

## Release and replay contract

`release.py` loads a frozen encoder only after SHA-256 verification, validates the 17-token channel, and can save `Q.npz` plus a hash manifest. `OneReleaseSession` samples one token per caller-held person ID and reuses that token for repeated calls with the same byte-identical `X_A,H_A`. It rejects an ID presented with changed inputs during a session. The default cache is process-local. A deployment can instead supply a private 32-byte-or-longer HMAC replay key: the ID, input digest and exact `(Q,encoder)` identity deterministically yield one pseudorandom categorical draw across restarts. Descriptive aliases of the same channel replay the same token. The same key must be retained privately; it is never serialized or returned. The deployment must bind a person ID to an immutable input snapshot and channel across restarts; otherwise the keyed draw can change. The HMAC mode uses a 64-bit discrete uniform and is a computational pseudorandom implementation, not a mathematical fresh independent draw. Independent repeated draws and cross-release composition are outside this one-token contract; neither an RNG seed nor replay key is written to the public artifact.

The stored `Q` and frozen code are public mechanism details. Internal exact audit code may compute `Q[t_i,:]`, but a person's hidden row is not sent with the token. Service columns are copied byte-identically. The frozen Linux x86 encoded arrays are scientific inputs; Mac float32 re-encoding must not replace them for fits or scientific comparisons.
