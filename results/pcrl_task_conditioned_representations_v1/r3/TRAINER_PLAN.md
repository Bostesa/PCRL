# R3 prefit execution plan

All jobs, including data-free fixtures and smoke timing, execute only through the coordinator's durable queue. No R3 subprocess fits or test invocation is authorized outside that queue.

The registered initial recipe is Adam at 0.0001, betas (0.9,0.999), epsilon 1e-8, weight decay zero, global gradient clipping 5, independent uniformly permuted task minibatches of 256, 20 continuation epochs with saved epochs 0/5/10/20. Every arm receives the same seed-specific task permutations, independent of privacy draw state. Source encoder arithmetic stays float32; folded deployed own-head arithmetic is float64. Gradient norm accounting converts every gradient to float64, over all active encoders and heads. Calibration uses both encoders and both heads for all compared joint families.

FIT folds 0/1 supply training, fold 2 supplies checkpoint/strength selection. Reference scaling uses a fixed training-role reference subset of at most 256 rows and refreshes at epoch starts. Privacy draws use distinct duplicate groups without replacement in each block and are independent of uniform task minibatches. Task cross entropy averages across people and sums the two task risks; no class reweighting or balanced privacy sampling affects task priors.

Every candidate records task metrics and the worst normalized FIT fold-2 deviation against the exact source U0 epoch zero, using 0.010 accuracy, 0.010 NLL and 0.005 summed Brier scales. This is a training-selection surrogate and does not admit any model under the original INNER gate. Fallback selection minimizes that worst deviation over both seeds, then total NLL, then registered strength order and epoch order. Utility continuations select minimum two-seed total NLL among common configurations whose worst normalized deviation is at most one, then epoch order; if none meet the surrogate, the fixed task-violation fallback is nominated. Protected nominees select the lowest registered FIT sensitive statistic among common configurations whose worst normalized deviation is at most one; ties use worst deviation, NLL, then registered strength and epoch order. If none meet the selection surrogate, the fixed task-violation fallback is nominated. The common configuration is a single (strength, epoch) for both seeds. The exact local twin is frozen at the selected joint configuration. All families, source epoch-zero references and diagnostic fallbacks are hashed and frozen before any new INNER task label access.

Normalization fixes 16 privacy draws and 16 independent uniform task draws. Task gradient uses CE alone; protection uses the complete sensitive loss excluding target utility. Median task and protection norms must exceed 1e-12 and remain finite; the coefficient per unit target ratio must not exceed 1e4. Failed calibration records diagnostics and disables affected fits. JOINT's coefficient is shared by exact LOCAL_TWIN and JOINT_UNCONDITIONAL; stronger local has a separate registered calibration. Sensitive-zero arms with target terms enabled reproduce U_TASKPOWER, and all-objective-zero arms reproduce U_NEW.

Forecast: two utility baseline families × two source seeds = four continuations; four kernel protection families × three strengths × two seeds = twenty-four continuations; RAW and two sequential families add eighteen configurations (six RAW and twelve sequential) before staged count adjustment. This totals 46 fitted configurations; the exact zero-update U0 reference requires no fitting. Timing smoke must determine resource feasibility before the complete registry is dispatched; both-seed JOINT+LOCAL_TWIN are prioritized. Sequential first stages train 20 epochs and save 0/5/10/20. Three second-stage branches start from the first-stage 5/10/20 checkpoints and train the second encoder/head for the matching 5/10/20 epochs, with the first encoder/head frozen. The four e/e nominees have exactly matched per-encoder updates. The prefix branches cost 55 aggregate encoder epochs, 37.5% more search exposure than the 40 aggregate encoder epochs of simultaneous fitting. This additional competitive-control opportunity is charged and reported. No science outcome influences scope or compute adjustment.

Confirmed admission: FIT training folds 0/1 have 10,223 rows and selection fold 2 has 5,211 rows. Uniform task batches therefore provide exactly 40 updates per epoch and 800 updates per encoder/head at epoch 20.
