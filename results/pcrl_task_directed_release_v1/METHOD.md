# Method and finite-model scope

The source path is historical allowlisted ACS covariates → historical fitted preprocessing/PCA32 and A0/J standardization → frozen supervised p(PCA32,H_A), b(H_A) → residual logit r → internal T0/Ttask/Trisk code → public Q and fixed action dictionary → **one sampled token** Z → recipient decoder g_z(H_A). Predictions, quantization, action resolution, mechanism estimation and finite probes can each contribute loss. None of their empirical differences alone is a Bayes information bound.

Teacher and risk/code fits are separate from mechanism-estimation households. The teacher chosen on internal training validation is the actual deployed model; there is no post-Q refit. Baseline b uses H_A only. Action offsets solve the soft-label stationarity equation sum_i w_i(sigmoid(logit(b_i)+a)-p_i)=0 within training residual-quantile groups, with the bound and clipping convention in AMENDMENT_1. Zero is always an action and the fixed absent-parent default.

For each mechanism-estimation population, d_w[t,z]=sum_(i:T_i=t) w_i CE(Y_i,g_z(H_Ai))/sum_i w_i. The minimized objective is sum_tz(.5d_U[t,z]+.5d_W[t,z])Q[t,z]. This is joint-mass cost, not conditional cost; state mass is not multiplied twice. Every teacher, action, row and weight is fixed before Q fitting.

For fixed p_w(s,c,t), a(s,c,z)=sum_t p_w(s,c,t)Q[t,z] and b(s,c,z)=p_w(s|c)sum_t p_w(c,t)Q[t,z]. Both are affine in Q, so sum rel_entr(a,b) is convex. Enforce each protected role under both U and PWGTP on the same row-stochastic Q. Local and coalition policies differ only in the added AB constraints. At zero budget, solve the equivalent linear equations. Ordinary convexity, feasible-set inclusion and privacy-funnel geometry are prior work; see NOVELTY_AND_ASSUMPTIONS.

Each refinement has parent map floor(t/2). Copying a T0 Q row to both children leaves costs and every modeled joint law unchanged when constructed on the same empirical rows. Unsupported children are tied to estimation-frequency weighted supported siblings; absent parents use zero action. These affine rules preserve that embedding. Independently recompute all losses/information after solving, and verify actual-data table aggregation and deployment row-copy equality. The fitted refined optimum cannot exceed T0, and the coalition fitted optimum cannot be below its local counterpart, except within the registered numerical certificate tolerance. These statements do not order held-out privacy or prove strict improvement.

Numerical policy is exported in finite.py: independent simplex/support/CMI/objective tolerances1e-7, nonnegativity/zero-equation tolerance1e-8; HiGHS zero LP, CLARABEL positive-cone solve, SCS fixed retry. Only cancellation-scale entire zero-equation rows may be removed using16machine-epsilon relative tolerance, with original-law CMI still checked. A feasible witness can be returned as such, not mislabeled a certified optimum. Failed or nonfinite objects are quarantined.

Only feature-derived service partitions enter C. Since I(S;Z|coarse(H)) need not control I(S;Z|H), attack all full recipient service vectors. The XOR counterexample is retained in tests. Publishing a Q row can identify its input state despite sampled-token privacy, as the supplied exact fixture demonstrates. The public mechanism does not rely on secret weights; repeated-token composition and per-person/population privacy are outside these finite empirical guarantees.

Expected single-release loss is sum_z Q[T_i,z](-log f(y_i|H_i,z)), with the same formula for attacks and utility. It is not -log(sum_zQ[T_i,z]f(y_i|H_i,z)). Train by conserved person-token weights and original-person batch/regularization scaling, with the explicit native-tree exception in AMENDMENT_1. All model choices use one balanced validation criterion; those same predictions supply both report weightings.
