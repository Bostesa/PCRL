# Reproducing the task-directed release study

This directory records a residence-supervised experiment on historically reused 2018 development cohorts. Reproduction does not turn those cohorts into new confirmation data. Do not open 2016. The scientific configuration is generated by `experiments/pcrl_task_directed_release_v1/config.py`; `CONFIGS.json`, `ALL_RELEASES.json`, the prospective protocol and dated amendments determine the study, rather than defaults from another worktree.

## Source and environment

Use the full research-branch SHA recorded in the final `HANDOFF.json`. The four historical source SHAs are in `ARTIFACT_DEFINITIONS.json` and `CONFIGS.json`. `ENVIRONMENT.json` records the actual Linux execution environment. Scientific workers each use one BLAS/OpenMP thread; the frozen resource schedule determines concurrency from physical RAM and measured complete-audit cost. Laptop swap is not part of that calculation.

From the repository root, with the recorded packages installed in an isolated Python environment:

```sh
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1
python -m pytest -q tests/pcrl_task_directed_release_v1
```

The standard-library exact fixture also runs without the scientific dependencies. Its source and verified rational output are retained under the owned experiment directory and `FIXTURE_VERIFIED.json`. The fixture is mathematical design evidence, not an ACS result.

## Private artifacts and explicit paths

Public Git contains aggregate reports, source, tests, configurations and hashes. Person-level expected losses, identities, labels, fitted predictions, teachers, attackers, probes, Q maps, empirical tables and split manifests remain in the private encrypted archive. `ARCHIVE_INDEX.json`, when publication completes, identifies its exact versioned objects and compressed hashes. Its private manifest identifies every file and hash. Verify both the compressed stream and every extracted member; `archive.verify_and_restore` rejects undeclared paths, duplicate members, sealed-year paths, symlinks, hash mismatches and overwrites.

Restore into a new task-owned directory. The original scientific root was `/opt/pcrl/work`; pass it explicitly as `original_root` when relocating saved artifact references. Pass the new root explicitly as `artifact_root`. Verification must never fall back to files in the original execution directory. The publication restore covers all study sources and global documents, all owned inputs and deployment maps, and the complete anchor-0 artifact tree. The other anchors are also verified in the archive stream. A full three-anchor reconstruction requires restoring all three anchor trees.

The owned input root is `results/pcrl_task_directed_release_v1/private/inputs`. Raw covariates are restricted to the ten named fields in `RELEASE_CONTRACT.md`. `inference.FrozenInputMap` reuses hash-pinned historical preprocessing/PCA and the saved standardizer without refitting. Its exported input maps are retained separately in `private/deployment_inputs/anchor_0`, `anchor_1` and `anchor_2`. `FEATURE_ONLY_INPUT_REPLAY.json` records the actual raw-to-PCA and unchanged-H checks.

## Execution order

The executed primary order is encoded in `scheduler.phases`: freeze the actual teacher; audit H; finish all 18 positive-budget T0 privacy channels with all roles; then finish the paired refinements, zero diagnostics, unconstrained channels, and matched historical and supervised controls. `run.prepare`, `run.ensure_map` and `run.audit_unit` use immutable receipts, hashes and task-owned locks. A failed unit is quarantined and diagnosed, not selected from favorable retries.

The following are the execution entry points, not authorization to reuse expired time limits or alter this completed study's registration:

```sh
python -m experiments.pcrl_task_directed_release_v1.scheduler
python -m experiments.pcrl_task_directed_release_v1.programme branch-A --resource-decision resource_decision.json
python -m experiments.pcrl_task_directed_release_v1.scheduler --extension A
python -m experiments.pcrl_task_directed_release_v1.scheduler --extension C
```

Optional extensions require their registered trigger, exact configuration registry and immutable resource schedule before the affected fits. An extension command without that evidence fails. A later fresh replication needs its own dated execution/resource registration; do not rewrite this study's original schedule or claim new outcomes were prospective under it.

After all scheduled fits and audits close, `programme.freeze` verifies completion, collects validation evidence, applies the fixed common-configuration selection rule, binds every accepted audit and inference source, and writes `SELECTION.json` and `CONTRASTS.json`. Commit that freeze before opening the current-run evaluation pool. Only then run:

```sh
python -m experiments.pcrl_task_directed_release_v1.scheduler --evaluate
python -m experiments.pcrl_task_directed_release_v1.reporting inference
```

Evaluation loads frozen models and selected recipes; it does not refit or select on evaluation outcomes. Both reporting weightings use the same selected predictions. The explicit contrast list determines the correction family. `uncertainty.paired_household_bounds` uses the same household multiplier wherever that household occurs and recomputes survey ratios within each replicate.

## Independent verification

With a complete restored study, replay into a new output directory:

```sh
python -m experiments.pcrl_task_directed_release_v1.verify \
  --artifact-root /absolute/path/to/restored-study \
  --original-root /opt/pcrl/work \
  --out-dir /absolute/path/to/new-verification-output \
  --include-evaluation
```

The verifier independently reconstructs frozen selection, contrast counts, features, chosen probabilities, expected log losses, fitted objectives and privacy constraints. It checks byte parity for H, common-ancestor cancellation, and sampled-wire simulation against exact single-release expectations. Partial representative restores use the explicitly scoped restored-unit verifier and do not claim to reconstruct missing anchors. `VALIDATION.md` records the actual completed replay and restore coverage.

`evidence.generate` renders aggregate tables only from receipt-bound machine evidence. `figures.render_figures` exports the four sensitive-endpoint tradeoffs under both weightings and the task-signal decomposition with a traceable point table. Descriptive frontiers and selected simultaneous comparisons remain separate.

No resume command is a substitute for completion. Any genuinely incomplete units and their reasons belong in the final run ledger; a closed negative study is complete.
