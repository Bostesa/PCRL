## Frozen service and support

P0 is the executable historical `U|JOINT|i8o64|l0.1|H-CLASS-TEMP`,
including raw 83-column teacher/router, partition, original global IDs,
class-temperature decoder and metadata. The permitted columns and class
orders are byte-bound through R1's source manifest. Its two banks contain
14/270 states for seed 0 and 13/299 for seed 1, with 4/9-bit codes.

Each recipient support contains identity plus at most three nearest states
with the same predicted class. Symmetric KL uses clipping 1e-12 and original
global-ID tie breaks. This is a newly instantiated P0 neighborhood; it is
not the whole release frontier. Both supports are fixed from the original
P0 inputs, including throughout sequential stage two. Central input is the
two P0 decoded vectors and fixed entropy/margin summaries; source IDs select
support. V-L uses only its own input. Raw scores never become learned
channel inputs. SEX is never a deployment input.

Every emitted wire contains the original schema, recipient, release ID,
global code ID, probability vector, decision, and public metadata: model ID,
source binding hash, bank hash and code length. These constant fields remain
byte-bound; no fine ID, input support position, coin, sampling root, original
source output or hidden fallback flag is appended. The public policy and
table are attacker side information. All varying emitted fields enter each
recipient reader and their aligned coalition reader.

## Protection losses

O-J minimizes the inherited empirical finite-law Bayes accuracy
`G_pair + .5*(G_r1+G_r2)`, summing the larger SEX probability mass at each
actual global code/tuple. The old objective already covered this finite
wire because decoded probabilities, decisions and constant metadata are
functions of code. No prior mean-output bug or causal diagnosis is claimed.

For each actual-wire reader j and view v,
`R_v,j(q)=mean_i sum_a q(a|x_i)*[-log f_v,j(SEX_i|wire_v(a))]`.
New central protection maximizes the minimum retained pair reader CE.
Constant-prior, smoothed categorical and nonlinear one-hot-code-plus-wire
64/32 readers fit in three duplicate-group-separated folds within FIT.
Three fixed reader/policy rounds retain earlier readers. Every retained
local reader separately must have `R_j(q) >= R_j(P0)-1e-10` on the identical
internal rows. This surrogate guard is not a final AUC guarantee. O-J uses
the same local reader schedule but retains its old pair objective; the
diagnostic is an objective and reader package comparison.

Float64 Adam is approximate nonsmooth max-min optimization, not an exact
oracle. Two fixed starts use 600 factor updates per arm in total, three
rounds, policy learning rate .01, penalty rho100, gradient norm5, cadence25.
Each complete arm has 108 trained reader fits and 54 constant-prior calls;
nonlinear readers use 50 weighted updates, learning rate .001 and penalty
1e-4. All costs, readers and policies use actual action laws, never a mean
probability vector substituted for the transmitted draw.
