# Local publication handoff

This research branch is local only. Its ancestor audit found identifying path
strings in inherited tracked history. No push, force push or history rewrite ran.
New code and aggregate files are checked separately for path hygiene; that does
not sanitize their ancestors.

A reviewable publication option is a file export containing this campaign's
public code, aggregate endpoint tables, protocols, source hashes and factual
handoffs, with no private models, person arrays or inherited Git history. The
review should include the mature source-code dependencies required by the
deployment adapters and resolve their own identifying-path findings before
publication. The versioned private snapshot remains an owner-only recovery
artifact. This option is a handoff, not an executed publication or a rewrite of
the research branch.

The local branch and source pins remain the authoritative development record.
Remote verification and off-device custody are separately pending.
