# Queue-owned independent replay interface

Run `python -m occupation_bottleneck_independent.replay --spec PRIVATE_CONFIG.json` as a `verification` queue unit. The root alone enqueues and executes. Register the exact config, code and every referenced source path/hash. Numerical operations authenticate the inherited queue slot before importing numerical libraries or touching scientific sources. Metadata configs are not science results.

Every config contains `unit_id`, `operation`, `public_output`. Pins use `{path,sha256}`. Outputs are created exclusively; failed versions remain preserved. `private_output` identifies a new private directory when saving numerical outputs. All INNER label paths require a canonical, committed `reporting_lock` pin; its status must be `ALL_READERS_FROZEN`, its owner `ROOT`, with candidate and reader booleans true.

`development`: `manifest` pin, optionally `banks` with `arm_id`, `seed`, label-free FIT-selection `release` pin and `scores` pin. Recomputes C3 FIT01 tables and FIT2 AUCs, frozen-score decision/confidence/feature contracts, supported strata. This operation needs only the FIT feature and three FIT label pins from the manifest, not INNER sources.

`refit`: `targets` each containing `target_id`, `arm_id`, `seed`, `reader`, `view` (default `pair`), ATT-frozen `orientation`, `model_seed`, `att_release` pin and label-free `inner_release` pin. Independently refits the frozen type using the inherited group split and scaling; returns ATT replay and saves private reader and label-free INNER score. The empirical positive orientation is chosen from ATT validation alone and compared with the target orientation. It is frozen with the refit output before INNER labels.

`audit`: optional arrays of `trajectory`, `geometry`, `banks`, `gradients`, plus optional `source_admission`. Trajectory entries have `inputs` and `summary` pins; source admission has `manifest` and `roster` pins. Geometry entries have `checkpoint`, `features`, `arm_id`, `seed`, `role`, and the frozen `rule` object; `public_geometry` is optional. Bank entries have `release`, `scores`, `freeze`, `arm_id`, `seed`, and `ATT_validation:true` for ATT scoring, or separately admitted `sex` pin for an assessment bank. Gradient entries have regenerated `tensors` and `summary` pins. The replay checks actual stored arrays, independent math and functional forwards. It does not infer independent refits from reader receipts.

For a true independent gradient regeneration add `gradient_regeneration`: entries have `manifest`, `checkpoint`, fixed full-role FIT `batch_indices`, optional runner `tensors` pin and `batch_number`. The independent worker performs its own functional encoder/head/critic forward and autograd with the exact saved normalization; it compares each flattened vector to the registered regenerated tensor when supplied. It performs no model/critic update. Legacy pickled `DiagonalReference` is replaced during deserialization by a neutral attribute-only class to avoid implicitly importing predecessor scientific code.

For independent C2 rank/timing summaries add `paths`: entries have `family`, `strength`, `seed`, and ordered `points` with `epoch`, saved `selection` pin, `bank_freeze` pin and `utility_summary` pin. The worker computes every consecutive transition, fixed within-path ranks, first observed occupation confidence/task-loss cost, and first local/pair recovery decline. Missing or constant ranks remain unavailable; source saved objective summaries stay distinct from regenerated gradients.

`assessment`: `reporting_lock`, `endpoint_registry`, `unit_input` pins and named `arrays` pins. Registry contains `K`, `replicates`, `bootstrap_seed`, `alpha` and `endpoints`; each endpoint has unique `endpoint_id`, `kind`, `threshold`, `direction` (`at_most` or `at_least`) and `paired_seeds`. For `mean_difference`, each paired-seed record names `left_table`, `left_key`, `right_table`, `right_key`, optional `sign`. Tables contain the actual row metric vectors. For `auc_envelope_difference`, it names `truth_table`, `truth_key`, `left_table`, `left_keys`, `right_table`, `right_keys`, optional `sign`; key lists include the frozen local-ignore aliases. The independent family size is the actual number of frozen endpoints. Both seeds use the same group draws and average inside each draw.

This interface can be adapted to an independently specified runner registry before global freeze. An interface adaptation must preserve the numerical definitions and complete endpoint count; it must not reduce multiplicity or alter thresholds after assessment.
