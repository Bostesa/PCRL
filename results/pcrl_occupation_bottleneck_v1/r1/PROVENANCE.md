## Guard and worker interfaces

`occupation_bottleneck.admission` is a standard-library metadata helper. It rejects barred historical assessment/HEAD/all-role paths and symlink ancestors. Its metadata operations do not hash checkpoints or person arrays.

`occupation_bottleneck.source.load_manifest(path, expected_sha256)` loads the reduced OB1 manifest. `load_role(manifest, seed, role, fields, reporting_seal=None)` opens only requested role-specific exports inside the new shared queue. INNER income, occupation and SEX are barred before hashing until the canonical ROOT reporting lock has status ALL_READERS_FROZEN, frozen candidate/reader flags, exact pinned bytes committed at HEAD, and a separately supplied role-label supplement. The prefit manifest itself always omits those labels. Requested arrays require exact archive field sets, row/group pairing, fixed class conventions, finite raw83, and the admitted ordered feature schema.

`occupation_bottleneck.admission_worker` is the queued numerical admission entry point. It replays both useful U0 references and Ucal on all admitted feature roles, checks exact source decisions and probability tolerance, verifies actual counts/group disjointness/FIT folds, hashes and restores all 84 packages, and independently compares all zero-update metadata aliases to source model tensors. It creates source bindings and FIT stratum accounting. No reader fit or new defense update is part of admission.

The private worker inputs are `--manifest`, `--manifest-sha256`, `--roster`, `--roster-sha256`; outputs are `--output`, `--coverage-output`, `--private-output`. The coordinator registers the worker under queue stage `admission`. This metadata assignment did not execute it.
