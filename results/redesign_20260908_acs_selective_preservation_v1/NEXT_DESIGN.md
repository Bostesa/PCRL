# One next method experiment: restrict the student's inputs

Test a fixed input restriction before utility-aware adaptation: feed the mapper **only the already frozen E teacher output**, retain persistent beta1 teacher matching and rho0, and compare matched C/D continuations. Include the same frozen S teacher as the input-control condition and a matched full-PCA32-input counterpart within this one finite experiment. This is one input-route intervention, not another coefficient or erasure-strength search. No fitting for it has been launched.

The motivation is the current controlled evidence. Removing reconstruction reduces attribute recovery, but all E/rho0 students regain linearly recoverable qE during continuation. Original PCA32 remains directly available to their mappers. The fixed teacher has much lower recovery and severe source costs; the learned student restores useful source predictions while also restoring protected-label predictability. Closing the raw-input route tests whether useful adaptation is possible using the erased interface itself. It does not assume qE is purely sensitive or infer causation from local gradient opposition.

Keep S because the current real-label teacher has no general pooled SEX advantage over shuffled erasure. Before future fitting, freeze paired initialization with the same starting released functions, architecture/input accommodation, source-label exposure, schedule, loss coefficients and final-iterate rule. The existing full-input outcomes remain historical references; a causal input-route comparison must not silently compare unmatched initializations. Reuse the same fixed teacher maps and cohort, reserve residential/commute outcomes, and retain direct E/S controls plus independent and saved-start audits. Apply the original source/residential/recovery criteria, both weightings and all support flags. Do not assume a stronger teacher or select another shuffle after outcomes.

Success would mean better finite-budget source/transfer prediction from the teacher inputs than the direct-teacher heads achieve without the current increase in real-attribute recovery, surviving matched independent and catch-up-inclusive audits. Failure to restore source utility is equally informative: the previous gains may rely on access to structure outside the intended interface. E already contains nonlinear protected-label information and finite-precision remnants, so restricting input is not a privacy certificate and cannot ensure that all usable leakage disappears.

This would test fixed permitted-input routes as a component for different purpose-specific releases. It would not by itself establish restrictions on combined access: separate outputs can expose complementary structure, and a future multi-purpose policy must evaluate the permitted and prohibited targets of their actual combination. The recommended experiment measures the component boundary; it does not claim that the coordination problem has been solved.
