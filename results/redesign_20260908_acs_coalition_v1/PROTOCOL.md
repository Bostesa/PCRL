## Losses, priors and optimization

All BCE heads retain original eligibility masks, each head's own eligible-example denominator, with zero contribution for an entirely missing minibatch and the fixed declared outer means. L_source = (mean(BCE_income,BCE_employment) + BCE_public)/2, equal PURPOSE weights, distinct from a three-task mean.
For each target, fit its fixed empirical representation-fitting prior entropy once without smoothing for gradient normalization, shared across local/coalition views. Target schemas SEX2, RAC1P9 and binary source2; all nine race classes and support flags remain. Observer updates minimize the original ordinary CE recipe (separate role networks; normalization only as declared for reversed forward losses); every role sees the same scheduled rows, masked per target.
Let ell(v,t)=masked CE(observer(v,t))/fixed fitting entropy(t).
L_A = mean[ell(A,public_coverage),ell(A,SEX),ell(A,RAC1P)].
L_B = mean[ell(B,income_binary),ell(B,civilian_at_work),ell(B,SEX),ell(B,RAC1P)].
L_ind=(L_A+L_B)/2.
M_A=mean[ell(A,SEX),ell(A,RAC1P)], M_B analogous, M_AB analogous coalition.
I: L_source-.1 L_ind.
Iplus: L_source-.1 L_ind-.1*(M_A+M_B).
J: L_source-.1 L_ind-.1*M_AB.
M_A+M_B is a SUM, never averaged again. Added coefficient is .05 per sensitive target/branch in Iplus and J. This matches nominal coefficients, not realized gradients, loss values, observer information or optimization difficulty. Opposing source coefficients stay fixed. Freeze observers during forward backprop but retain differentiation through their inputs. F protection reaches mapper coordinates; F heads receive ordinary source gradients. P protection also reaches probability-producing source heads.
Nine trained observer roles in ALL conditions: A/public_coverage, A/SEX, A/RAC1P; B/income_binary, B/civilian_at_work, B/SEX, B/RAC1P; AB/SEX, AB/RAC1P. No reserved observer.
Adam .001, batch 256, betas(.9,.999), eps1e-8, no weight decay/clipping, original schedules. Per seed: common two-branch source warmup 60 once; clone model and complete Adam to F/P. Each interface: observers warmup20 with forward+Adam frozen; clone full forward/observer/Adam/schedule into I/Iplus/J. Continue80 each with matched batches, three detached observer updates per forward update, fixed final epoch, no mapper validation selection. Interface forks have exact full-state equality. F/P share source-warmed forward state but their observer tensors legitimately differ with released dimension.
Diagnostics use the SAME first source-warmup fitting minibatch at initialization, common W, interface fork and every final: source, ordinary individual, extra-local and coalition mapper gradients per branch, raw and applied coefficients/norms; local A-to-B and B-to-A must be zero, coalition reaches both where nondegenerate; P head protection gradients checked. No optimizer step, RNG mutation or frozen-state change. No coefficient adaptation. Zero norm cosine undefined if reported.
