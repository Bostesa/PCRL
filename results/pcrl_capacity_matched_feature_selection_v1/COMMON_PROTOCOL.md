## Fit and selection

The two screen seeds are `0,1`; seed `2` is conditional on a valid nomination. Within each seed, fit equal 64×64 inherited task heads for every unique mask/purpose and full-83 F, with the fixed inherited H-GLOBAL scalar calibration family (one scalar per head/task, alpha in [0.25,4], bounded derivative bisection, no grid). Internal validation heads and final full-FIT heads use the same declared architecture and training budget. F is an active utility reference; U0 and Ucal remain separately pinned. The fitting worker first writes an AUC-free task table and independent T selection receipt **before its first FIT SEX read**. It then trains the fixed local RAW_SELECTED_ONLY and coalition RAW_UNION_ONLY search critics on fitting-role folds, joins the 25-pair table, and selects J and all controls. Search critics rank masks and are not final attacks.

The search critic slate is LogisticRegression(C=1, solver=lbfgs, max_iter=300) and HistGradientBoostingClassifier(learning_rate=.05, max_leaf_nodes=15, max_iter=64, max_depth=None, random_state=seed). Fit each on permitted whole-group fitting-role train and score on its held-out whole-group validation. Oriented AUC is max(AUC, 1−AUC); the fixed two-reader envelope is the larger value. Cache local scores only by exact selected raw mask and coalition scores only by exact canonical raw union; no complete-view score can use this raw-union cache.

M3's fixed rules `T, I, S12, S21, SHARED, T_U, I_U, S12_U, S21_U` and M2's `J` use the same bank, heads and fitting-role table. T independently minimizes each purpose's task validation NLL, with task-only receipt frozen before SEX critic access. Other rules apply inclusive task-validation utility caps against U0, Ucal and F and local search AUC no greater than T's corresponding local AUC +0.010. Sequential first steps use only local scores with feasible-completion lookahead, then freeze the first choice and optimize coalition score for the second; neither order is Taylor et al.'s exact published method. J jointly minimizes coalition search AUC subject to the same caps and local guards, then summed task NLL and mask hashes. Union-matched controls use J's fitting-selected actual union group count and encoded width, never its INNER outcome; feature identity need not match. Any rule choosing the same pair and identical fitted release is a valid alias and tie, not an excluded comparator.

## Fresh attack and scoring

M4's fixed final complete-view slate is `LR_C1`, `MLP_64x32`, `HGB_15x200`, `DA_MLP_64x32`, using inherited source factories and deterministic seed. On each exact canonical raw union, fit `RAW_LR_C1` and `RAW_HGB_15x200` once, transport their saved ATT/INNER score vectors only after exact source-column/byte/row checks, and include them in applicable complete-view envelopes. The coalition additionally inherits both local readers by ignoring the other recipient. Each reader uses a deterministic whole-group ATTACK_FIT_NEW fit/tune split; all tuning and orientation occur there. INNER_SELECTION never tunes a reader. Primary recovery is the maximum oriented INNER AUC across this frozen slate, with fixed-reader maximum recomputed in each bootstrap draw. The separate ATT-tune selected deployable reader is reported. V2 null, shuffled-SEX and planted-leak controls run for each distinct actual view, with inherited thresholds (exact constant .5, shuffle ≤.60, planted ≥.99); a failed control blocks its dependent endpoint. Each unit's role inputs are explicitly listed in the sealed private registry.

For every seed, recipient, task and rule, report accuracy, natural-log NLL, summed multiclass Brier, gain over a constant predictor, retention and per-class recall; suppress class cells with fewer than five people. Reference U0, Ucal and F predictions are bound by seed/role/hash. Accuracy cost is reference accuracy minus release accuracy, NLL/Brier costs are release minus reference. Inclusive per-task point caps are 0.010 accuracy, 0.010 nats NLL and 0.005 Brier against **each** reference. A complete utility conjunction needs both tasks and all three references. Show U0/Ucal/F conjunctions separately. No point estimate is a passed uncertainty clause.

Main strongest eligible control pool is T, I, S12, S21, compatible SHARED and applicable union-matched controls. Attribution pool is all union-matched controls plus main controls with the same actual recipient profile and J union size signature. Each control must meet point utility caps on every evaluated seed independently of J. Within each pool select the rule with lowest paired seed-mean coalition AUC; **only exact numerical equality** invokes the listed rule-ID tie order. Retain aliases, ineligible controls and failures in the full table. Coalition benefit is selected-control AUC minus J AUC; target ≥0.020. Recipient AUC worsening is J minus selected control; cap ≤0.010 each. Main and attribution comparisons are separate. Joint attribution requires simultaneous lower-bound coalition benefit ≥0.020 over both sequential orders and the strongest non-joint rule, with local caps and utility preserved. Same raw union means no raw-information reduction, whatever finite-reader differences appear.

## Inference, nomination and limits

Use 2,048 PCG64DXSM whole-group bootstrap draws, paired across all arms and seeds on the same INNER people. Recompute the fixed-reader AUC envelope within each draw, then the paired seed mean. The simultaneous family registers J versus **each of all nine control rules** for coalition and both local contrasts, plus every J/control task/reference utility clause, before any rule is selected or scored. An invalid or missing arm retains its registered slot with clauses marked UNRESOLVED; it is not converted into a favorable comparison. The critical value uses all defined clauses and never silently drops an observed failure. Use two-sided 95% maximum studentized absolute statistic. Upper-cap PASS requires simultaneous upper ≤ cap; VIOLATION requires lower > cap; otherwise UNRESOLVED. Lower-bound benefit/accuracy PASS requires lower ≥ target; SHORTFALL requires upper < target; otherwise UNRESOLVED. Intervals condition on fitted models/attackers and cannot correct historical Adult reuse.

The first real milestone is J versus T on seed 0 with full fitted heads, release views, fresh local/coalition attacks, V2 controls and saved endpoints. Then complete all valid two-seed rules. At most one frozen J configuration advances to seed 2 if each screen seed passes all point utility caps and each local no-worsening cap **against the main strongest eligible control selected across the paired screen seeds**; the attribution winner is reported separately and is not an extra nomination gate. Interval crossing does not itself prevent nomination. A task-ineligible J cannot be nominated. A valid simple control may be the strongest result. No best seed, reader, mask refinement or utility-threshold change follows INNER outcomes.
